# pages/ — 页面

| 页面 | 路由（建议） | 职责 | 长任务 |
|---|---|---|---|
| 落地页 | `/` | 事业运势主钩子，唯一对外入口；不做"什么都能算" | — |
| 登录注册 | `/auth` | 用户名 / 密码注册登录（**MVP 强制注册**，ADR-0007）+ captcha | — |
| 建档 | `/cases/new` | 生辰 / 性别 / 出生地 / 经纬度 / 真太阳时 + **主问场景选择** | — |
| 盘面 | `/cases/:id/chart` | 盘面渲染 + 降级提示（`degradedMethods`） | — |
| 断前尘问卷 | `/cases/:id/calibration` | 先经历**异步等待**（9 法串行 + 校验），再展示 5–10 条批量卡片 | ✅ |
| 报告 | `/cases/:id/report` | 综合解读 + 吉凶直说 + 末行免责 | ✅ |
| 追问修正 | `/cases/:id/revise` | 多轮修正对话，增量追加不覆盖历史 | — |
| 命理档案 | `/cases/:id/archive` | 档案查询与导出（结构化 JSON，ADR-0006） | — |

## 约束

- 未登录访问受保护页面 → 跳转 `/auth`（MVP 强制注册，ADR-0007）。
- 报告页与追问页**必须渲染末行免责**，且不可被折叠或裁剪。
- 长任务页面需统一的等待态：**显示「已完成 N/9」进度**、超时提示、失败重试入口（ADR-0005）。
- 进度数据来自 `GET /api/jobs/{id}`，纯代码轮询，零 token。
