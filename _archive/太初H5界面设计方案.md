# 太初 · 命理 H5 网页界面设计方案（星象式神秘奢华 · v1.2.4）

> 设计依据：《太初产品规划.md》《太初技术框架方案.md》（v2.4）
> 形态：线上 H5（移动优先），不做 APP / 小程序；轻量包装、独立 session
> 落地核心钩子：事业运势趋势参考
> 风格基调：**星象式神秘奢华**——以"深绒底 + 鎏金线 + 编辑级衬线 + 充裕负空间"营造文化中性、优雅克制的奢侈氛围；既规避纯科技冷感，也规避廉价算命广告观感与"满屏国风"
> 合规硬约束：不称"算命"、不承诺准确性、禁医疗/投资/司法、末行免责常驻
> 多文化内核：项目内部同时承载**国学命理 / 西式占星 / 塔罗**等预测手段，设计以"统一基底 + 多文化皮肤"承载，后期接入占星、塔罗时不改骨架、只换皮肤
> 版本变更（v1.2）：保留 v1.0 确认的全部配色 hex 与字体；视觉语言升级为**文化中性神秘奢华**；新增「统一奢侈基底 + 多文化皮肤」体系，使国学/占星/塔罗共享同一奢侈品牌质感而非处处国风

## 0. 设计理念与原则（从产品规范映射）

### 0.1 产品规范 → 设计含义映射表

| 产品规范（来源） | 界面设计含义 |
|---|---|
| 仅 H5、移动优先、不做 APP/小程序（规划 §1、框架 §1/R8） | 手机为唯一真实战场；桌面做差异化重排版而非简单放大 |
| 不主打"AI 新颖"、信任来自神秘感/权威感/被懂（规划 §3.2） | **去 AI 化 + 神秘奢华**：以深绒底/鎏金/衬线星盘建立权威与神秘，规避科技冷感 |
| 趋势/参考话术，不输出确定结论（规划 §3.2、框架 §7/R5） | 结果只用"趋势参考/可能性"；吉凶用 吉/凶/平 + 图标 + 文字 |
| 命理文化/国学运势定性，避免"算命"二字（规划 §3.3） | 品牌字统一"太初·运势趋势参考"；国学仅是多皮肤之一，不主导全局视觉 |
| 主钩子=事业运势（规划 §6.1） | 首页单点聚焦；第二阶段入口不进 MVP |
| 客群=35 岁职场女性"王姐"、焦虑需安抚（规划 §2.1/§7.1） | 视觉温暖平静、有陪伴感；星象意象给"被星空注视的安定"而非焦虑 |
| 断前尘 9 法串行可达数分钟（框架 §4.1/R16） | 设计星象式等待：星盘轨道 + 9 星逐一点亮，非裸 loading |
| 确定性排盘本地执行、仅解读调模型（规划 §6.2） | 文案强调"本地排盘·秒级""多流派综合·可修正" |
| 末行免责、输出侧硬过滤（框架 §7/R5） | 星印式免责常驻（通用封印意象，非国风专属）；关键结果下方 |
| 多预测手段（国学/占星/塔罗，规划与框架内核） | **统一基底 + 多文化皮肤**：同一奢侈品牌质感下，按手段切换签名色与母题 |
| MVP 多用户隔离、用户名/密码+captcha（框架 §3.2/R7/R10） | 注册/登录简洁克制，captcha 自然融入 |

### 0.2 设计四原则（v1.2 升级）

1. **神秘奢华，而非科技冷感，亦非国风堆砌**：以深绒午夜蓝为幕、香槟金线为饰、编辑级衬线为骨，营造"被星空注视"的优雅克制奢华；禁用霓虹、荧光、银灰冷光与算命小广告式撞色，也禁用龙凤、印章、书法笔触等过度国风符号霸屏。
2. **文化中性基底 + 多文化皮肤**：国学是手段之一而非视觉总纲。全站默认呈现**文化中性的神秘奢华**（深蓝 + 金 + 衬线 + 星象），仅在具体流派/手段页切换"皮肤"（签名色 + 母题 + 字体侧重），使占星、塔罗接入时不突兀、不违和。
3. **趋势参考，而非确定结论**：所有结论性 UI 用"趋势/可能性/参考"措辞与柔和视觉，杜绝宿命感与监管风险。
4. **留白即奢华**：以充裕负空间、极细分隔（金线）、低刺激暖调与克制动效建立高级感；移动端保持简洁骨架，桌面端以分区分层释放舒展层次。

## 1. 移动优先响应式布局结构

### 1.1 设计基线（双轨策略 + 皮肤不破布局）

- **移动端（≤768px）**：严格维持 v1.0 的**单列简洁骨架**——320px 基线验证，内容列内 4 列弹性栅格，8px 间距系统，圆角 12–16px，单层淡影。本版本不再更改移动骨架。
- **桌面端（≥992px）**：在响应式框架内做**差异化重排版与空间重组**——"星象剧场"双区布局：左侧/背景为星象沉浸区，右侧为更宽的内容工作区，内部采用多列栅格呈现层次。**不增加功能密度，只释放空间层次**。
- **皮肤不破布局**：无论国学/占星/塔罗皮肤，页面模块、栅格、断点**完全一致**；皮肤只改"签名色 + 装饰母题 + 字体侧重"，布局母版不变，保证工程一致性。

### 1.2 断点说明

| 断点 | 设备 | 布局行为 |
|---|---|---|
| **320px（基线）** | 小屏手机 | 单列；移动骨架；字号下限；主 CTA 全宽 |
| 375–430px | 主流手机 | 单列优化；卡片内边距 16–20px |
| 576px | 大屏/折叠 | 内部双列卡片（如问卷多选）出现，仍单列整体 |
| 768px | 平板 | 维持移动骨架（单列），仅放宽内边距 |
| **992px** | 笔记本 | **启动桌面差异化**：星象顶栏/侧栏 + 内容区双列网格初现 |
| **1200px+** | 桌面 | **完整星象剧场**：左星象沉浸栏（~340px）+ 右内容工作区（≤960px），内容区多列分层 |

> 关键取舍：**移动端不变，桌面端才舒展**。桌面以"分区 + 分层 + 负空间"制造高级感，而非堆功能。

### 1.3 主要页面模块清单

| # | 模块 | 核心功能 | 移动骨架 | 桌面差异化重排版（§1.6） |
|---|---|---|---|---|
| 1 | 落地页 Landing | 主钩子事业运势 + 主张 | 单列 Hero+CTA | 左文右星图，下方三列卖点 |
| 2 | 注册/登录 Auth | 用户名+密码+captcha | 居中卡 | 宇宙幕前窄卡，星点背景 |

| 4 | 排盘/断前尘等待 | 9 法串行进度 | 星象进度叙事 | 中央星盘轨道 + 侧方法状态列 |
| 5 | 问卷校准 Calibration | 5–10 条断言三态 | 断言卡流 | 双列断言网格 + 左 sticky 摘要 |

### 1.4 信息架构与导航

```
落地页
  └─ 注册/登录
       └─ 建档表单（生辰 → 地点 → 主问）
            └─ 断前尘等待（星盘轨道）
                 └─ 问卷校准（星点三态）
                      └─ 命盘/综合解读（星盘 + 趋势）
                           ├─ 修正对话（多轮）
                           └─ 命理档案（历史/回访）
```

- **移动端**：底部固定 Tab（首页/我的档案/设置）+ 流程页顶部极简进度条。
- **桌面端**：左星象沉浸栏承载品牌与全局导航（竖排 Tab/星图），主流程页用顶部细进度；右侧内容区保持单路径线性，不堆叠冗余导航。
- **手段切换（皮肤入口）**：在 Onboarding 主问处或结果页顶部提供"国学 / 占星 / 塔罗"等流派选择（胶囊切换），选择仅触发皮肤变量，不改变布局。

### 1.5 间距与圆角

- 栅格间距 16/24px；桌面内容区最大 960px，内部可切 12 列网格（gutters 24px）。
- 圆角：卡片 16px、按钮 12px、胶囊 999px；星盘/轨道用圆形。
- 阴影：仅单层极淡 `0 2px 12px rgba(26,33,56,.10)`，营造"悬浮于星空"而非科技悬浮。

### 1.6 桌面端差异化重排版（核心）

**布局母版 1：**「星象剧场」（≥1200px）
- 左 `340px` 沉浸栏：深绒午夜幕 + 星点 + 品牌字 + 当前"命盘星图"迷你可视化（随流程推进点亮）。承担导航与氛围，不挤占内容。
- 右 `≤960px` 内容工作区：内部 12 列栅格，按模块拆分双/多列。
- 992–1199px：左栏塌缩为顶部 `120px` 星象横幅（含品牌 + 进度星座），内容区双列初现。

**布局母版 2：**「宇宙幕 + 居中卡」（Auth/Disclaimer 等轻页）
- 整屏深绒幕，中央窄内容卡（象牙暖白）浮于星点之上，星印免责置于幕底。

**分模块桌面重排版细则：**

1. **Landing**：左右分栏——左 45% 主张文案（衬线大标"事业运势趋势参考" + 三连主张 + 主 CTA），右 55% 大型星象插画（星场 + 轨道环）。下方三列卖点卡：多流派综合 / 可修正 / 随时问。
2. **Onboarding**：左 38% 进度星座（建档步骤化为星点，金线相连，当前步高亮）；右 62% 表单卡（生辰→地点→主问分步）+ 流派胶囊切换。
3. **断前尘等待**：中央大星盘——同心轨道环 + 9 颗法星，按串行进度逐颗点亮（亮金=完成，鎏金=进行，深蓝=待命）；右侧竖列展示 9 法清单与状态；底部"正在为您综合推演…"叙事。
4. **Calibration**：左 30% sticky 摘要（已确认/待定计数 + 命盘微缩）；右 70% 断言卡**双列网格**（每行 2 张），金线分隔，三态操作。
5. **Result（重点）**：**左 50% 命盘星盘可视化** + **右 50% 综合趋势解读**（吉/凶/平 卡片，图标+文字+色，末行免责）。左右等高对齐，层次分明。
6. **Revise**：左 65% 对话气泡（用户/太初双色，太初气泡带星点底纹）；右 35% sticky 命盘摘要（当前星盘微缩 + 已确认断言）。
7. **Archive**：网格/瀑布卡片（每张=一次建档的星图缩略 + 时间 + 主问）；月度运势回访用带星节点的竖向时间线。

## 2. 配色方案 —— 奢侈品色彩策略（v1.0 配色 hex 全保留）

> **策略总纲（奢侈品牌式用色）**：以"**深绒基底 + 鎏金金属 + 单一克制签名色 + 充裕负空间 + 衬线**"建立高级感。深蓝与金是跨越文化的奢侈语言（午夜绒蓝≈高级成衣的 Noir，香槟金≈腕表/香氛的鎏金），本身不带国别；三套预测手段各有**统一基底之上的专属标识色——国学=朱砂红、西式占星=深空蓝、塔罗=琥珀**，共享同一套深蓝+金基底，呈现为**一个品牌下的不同系列**，而非三种风格打架。
>
> 总调性：**深绒午夜为幕 · 香槟金线为饰 · 象牙暖白为体 · 签名色点睛**。低刺激、有尺度感与神秘重量。

### 2.5 星象式视觉应用（文化中性，全皮肤可用）

- **深绒幕（Cosmic Field）**：桌面左栏/宇宙幕母版以墨蓝 900→800 作深场（可极轻径向加深，克制不炫），承载星象氛围，不用于移动正文底。
- **星点（Starlight）**：金 500/300 细点（1–2px）稀疏铺于深场，疏密有致，模拟星图；可作 hover/进度微动（opacity 0.2–0.6 呼吸）。
- **金线星座（Constellation Hairline）**：1px 金线连接星点，用于进度、分隔、装饰，替代粗分割——这是跨文化的奢侈细工语言。
- **星盘/轨道（Astro Ring）**：同心圆环（金线/墨蓝）作等待态与命盘可视化主元素；国学用星盘、占星用黄道十二宫环、塔罗用天球环，母题不同但几何同源。
- **留白即奢华**：深场之上以象牙暖白卡悬浮，大量负空间，不堆装饰。

### 2.6 配色禁用清单

- ❌ 霓虹蓝紫渐变、荧光绿、金属银灰冷光（科技冷感）。
- ❌ 高饱和营销红撞色（算命小广告感）。
- ❌ 金色大面积背景；朱砂/深空蓝/琥珀仅作各自皮肤标识与全站通用免责印，**不作跨皮肤全站铺底**；琥珀亮色作底须配深墨字。
- ❌ 移动端正文底用深绒幕（保持象牙暖底，护眼简洁）。
- ❌ 龙凤、祥云、书法笔触、印章边框等过度国风符号霸屏；国学元素只在国学皮肤内作为签名点缀，不默认铺满全站。

## 3. 字体方案（v1.0 字体保留，权重重构为"西文衬线主导的奢侈感"）

### 3.1 中英文搭配（v1.2 重构）

| 用途 | 中文 | 西文 | 理由 |
|---|---|---|---|
| 标题/品牌/大数字 | 思源宋体 Noto Serif SC（600/700） | **Cormorant Garamond（主导衬线）** | **西文衬线立编辑级奢侈感（高级成衣/腕表画册同源）**，中文宋体作优雅呼应而非主角，整体避免"满屏宋体"的国风压迫 |
| 正文/表单/对话 | 思源黑体 Noto Sans SC（400/500） | Inter / System Sans | 黑体小屏可读、现代克制 |
| 数字/年份/时辰 | — | Cormorant Garamond（衬线数字）/ 罗马数字 | 古籍刻度韵味，亦呈西式占星罗马历 |

> **关键修正（去国风化）**：v1.0 以中文宋体为标题唯一主角，易显"国学馆"气。v1.2 改为**西文 Cormorant 衬线主导标题与品牌字**，中文宋体退为优雅陪衬——这是跨文化的奢侈品排版逻辑（大量奢侈品牌以拉丁衬线为视觉骨架，本地语言做协同）。中文限两种、西文限两种（2+2）。

### 3.2 字号层级（8px 模快，12–48px）

| 级别 | 字号 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| Display | 32px | 1.25 | 700（衬线） | 命盘主标题、落地页主张 |
| H1 | 28px | 1.3 | 700（衬线） | 页面主标题 |
| H2 | 22px | 1.35 | 600（衬线） | 区块标题 |
| H3 | 18px | 1.4 | 600（衬线） | 卡片/命盘分项 |
| Body-L | 16px | 1.6 | 400（黑） | 解读/对话 |
| Body | 14px | 1.6 | 400（黑） | 表单/列表 |
| Caption | 12px | 1.5 | 400（黑） | 辅助/时间戳 |
| Disclaimer | 11–12px | 1.5 | 500（黑） | 末行免责（≥4.5:1） |

### 3.3 字重规范与皮肤侧重

- 字重 400 常规 / 500 中等 / 600 半粗 / 700 粗；禁用 800/900 过粗（避叫卖感）。
- **皮肤字体侧重**（仅调整各语言出场权重，不改字号层级）：
  - 国学：中文宋体出场多（标题、干支、卦名），西文 Cormorant 用于年份/数字。
  - 占星：Cormorant 主导（星座名、罗马数字、拉丁术语），中文黑体少出镜；优先显示 ☉♈ 等星座符号。
  - 塔罗：Cormorant + 装饰衬线（如牌名用 Cinzel 风格）主导，中文宋体作牌面译文陪衬。

### 3.4 字间距与行高

- 标题 `letter-spacing:.02em`；正文行高 1.6；星盘数字/干支可居中。
- 奢侈感细节：Display 级标题可放 `letter-spacing:.04em` 显沉稳；西文全大写小标签（如 "METAPHYSICS / ASTROLOGY / TAROT"）用 `letter-spacing:.18em` + 金线分隔，呈编辑级栏目感。

## 5. 核心组件与微交互（星象式 · 皮肤感知）

### 5.1 组件清单（设计 token 优先，支持 `--skin-*` 变量）

- **按钮 Button**：主按钮=各皮肤 `--skin-accent` 填充（文字用 `--skin-accent-ink`：朱砂/深空蓝/玉青底用浅字、琥珀底用深墨 #1F1F26）；次=墨蓝描边；金线高亮仅用于"开始测算"主 CTA。全宽/48px（移动）；桌面可内联。**品牌字/标签用西文衬线小字**（如 "BEGIN" / "开始"）呈栏目感。
- **卡片 Card**：象牙暖白浮于星幕，16px 圆角，单层淡影，**金线描边/分隔**替代粗边；命盘卡用深蓝暗角 + 金线勾边。
- **星盘可视化（皮肤感知）**：国学=星盘、占星=黄道轮、塔罗=天球环；几何同源、签名色各异（见 §4.4）。
- **进度/等待 Progress**：**星盘轨道 + 9 星逐亮**（亮金=完成/鎏金=进行/深蓝=待命），配"综合推演…"叙事；骨架屏占位。
- **断言问卷卡**：金线分隔，三态「确认/否认/修正」用对应皮肤标识色（朱砂/深空蓝/琥珀）或墨蓝（图标+文字）。
- **星印免责 Disclaimer**：通用星印常驻页脚/幕底；可展开完整免责。
- **流派切换 Capsule**：Onboarding/结果页顶部"国学 / 占星 / 塔罗"胶囊，切换仅触发皮肤变量。
- **【皮肤感知强化 · v1.2.2】固定顶部主题横幅（Fixed Theme Banner）**：移除独立 mode-banner 条；改由**随页面滚动固定的顶部栏本身**承担主题信号——移动端 `.topbar`、桌面端沉浸栏顶部 `.rail-head` 均用 `--skin-banner` 实色 + `--skin-banner-ink` 文字（月银/琥珀亮底时文字转深墨 #1F1F26）+ 金线压边，**切皮肤即整条换色、滚动常驻**。三皮肤**顶栏横幅色**（`--skin-banner`）：国学=朱砂红 #B23A3A、西式占星=月银 #C9CBD3、塔罗=紫晶 #5B4B8A；**内部标识色**（`--skin-accent`）保持：国学=玉青 #3E7C6B、占星=深空蓝 #2A3A5C、塔罗=琥珀 #C9A24B（见 §2.7）。
- **【主题色系统性铺陈 · v1.2.2】**：标识色除横幅外，统一作用于——① 主按钮 `.btn-primary`（开始测算 / 发送）与皮肤切换 active 态；② 卖点卡左描边+图标底、命盘"吉"卡左描边与淡彩底（`--skin-accent-soft`）；③ hero 与命盘区的**主题色辉光背景点缀**（`radial-gradient` 低透明度）；④ hero 主张胶囊、沉浸栏模式胶囊。原则：**页面底色（宣纸米白）+ 深空星幕恒定 = 统一基底；主题辨识度靠固定横幅 + 按钮 + 色块 + 背景辉光的多层级铺陈，避免元素全部融为单一背景色**。
- **Toast**：成功/警示用皮肤签名色，0.2s 淡入。

### 5.2 微交互参数（克制）

- 按钮 hover `scale(1.05)`、active `scale(0.95)`，200–300ms，`cubic-bezier(.4,0,.2,1)`。
- 仅动画 `transform`/`opacity`；星点呼吸 `opacity` 循环（≤2s，尊重 `prefers-reduced-motion`）。
- 转场 200ms 淡入；长任务星盘轨道动画，**零 LLM**（呼应纯代码轮询）。
- 动效克制，保 1.6G 受限设备顺滑。
