## 0. 总体美术方向

### 0.1 风格定位（Q 版人物）

- Q 版可爱治愈风：线条柔和、圆润、低饱和撞色，与全站「高贵 / 奢华 / 内涵」基调调和而不跳脱。
- 三枚人物分别对应三模块气质：
  - **国学**：Q 版人物**打坐**，静谧禅意，可着汉服 / 道袍，配小鸟 / 蝴蝶飞落身上。
  - **西式**：Q 版人物**仰望星空**，深蓝紫星夜神秘学氛围，周围划过连线星座 / 卡牌。
  - **MBTI**：Q 版人物**躺摇椅**摇晃，慵懒松弛。
- 人物主体**不画文字**（文案一律前端 DOM 叠字）；点击热区由前端包按钮，美术不产出可点击态。

### 0.2 统一色板

- 沿用 `docs/美术素材表.md` §0.2 的 `:root` / 皮肤变量色板（国学暖米金 / 西式深蓝紫 / MBTI 靛青渐变系）。

### 0.3 输出规范（先读）

| 项 | 规范 |
|---|---|
| **格式** | 人物 / 小元素 = 透明底 **PNG 或 WebP+Alpha**（24-bit alpha）；背景图（§3）= JPG/WebP 无透明；不做 Lottie（沿用：无矢量管线） |
| **倍率** | 统一按 **@2x 及以上超采样**：本表「出图尺寸」为最终文件像素，前端按逻辑尺寸（@1x CSS px）缩放 |
| **画布/安全区** | 透明素材主体距画布边缘 ≥4% 画布宽（防切）；PWA 图标按各规格安全区（见 §2 #4）；背景图铺满无安全区 |
| **命名** | 全小写英文 + `-` 分隔，数字两位 `01` 起；帧序列 `<basename>-<nn>.png`。清单注明循环性 `loop`/`once`/`hold` |
| **目录** | 交付根目录 `frontend/public/art/`：Q 版动画 `art/module-mascot/`、PWA 图标 `art/pwa/`、背景图 `art/bg-slots/`（见 §4） |
| **体积** | 人物/小元素单文件 ≤ **300KB**；整段帧精灵图 ≤ **600KB**；PWA 图标 ≤ **300KB**；背景图 ≤ **800KB** |
| **交付物** | 每个素材：最终文件 + 命名/循环性说明 + **锚点清单**（若前端要叠加/起算动画点，如小鸟落点、星座连线起点，需以画布百分比给出） |

### 0.4 动画实现约定（美术交付据此出图）

- **主路线（推荐，沿用第二轮「静态单图 + CSS 合成」）**：各模块交付 1 张 **Q 版人物主图**（透明底静态）+ 可选 **小元素**（小鸟 / 蝴蝶 / 星座连线 / 卡牌，各自独立透明 PNG）；呼吸浮沉、摇椅摇晃、元素飞来划过等循环均由**前端 CSS keyframes** 合成（`loop`）。美术无需整段动画绘制，素材可复用、体积小、移动端易降级。
- **可选替代**：如美术管线支持且需求方想要更「成片」效果，可交付「整段循环**帧序列精灵图**」（建议 N 帧 @ 12fps，`<steps()>` 播放，`loop`）；须在清单注明帧数与循环点。
- 开关：受功能设置「动画与抽卡模拟」（REQ-066①）控制——关闭时前端跳过动画、仅显示静态人物或不显示；装饰不得遮挡操作与主按钮。

## 2. 必备素材规格卡

### #1 国学 Q 版打坐人物（+ 小鸟 / 蝴蝶）

- **画面**：Q 版人物盘腿打坐、双目微闭或平和，静谧禅意；可着汉服 / 道袍，配色接国学暖米金系。
- **主图交付**：透明画布 480×600，人物主体高 ≤560、宽 ≤400，距边 ≥4%；PNG/WebP α，≤300KB。
- **循环元素（可选 1a）**：小鸟 ×1、蝴蝶 ×1 各 128×128 透明 PNG；元素独立于人物，便于 CSS 编排「绕行→飞落人物肩/头→停留→再飞起」循环。
- **循环性**：主图外加呼吸浮沉（上下 2–3px、周期 3–4s）由 CSS；元素 loop。
- **锚点清单**：人物肩部 / 头顶落点（画布百分比）供小鸟 / 蝴蝶定位。

### #2 西式 Q 版仰望星空人物（+ 连线星座 / 卡牌）

- **画面**：Q 版人物仰首望星，背景氛围深蓝紫星夜（主体仍透明，星空氛围由前端渐变或可选背景 #5 承接）；神秘学气质。
- **主图交付**：同 #1（480×600 透明 PNG/WebP α）。
- **循环元素（可选 2a）**：连线星座 ×1（192×192，可含连线点阵）、小卡牌 ×1（128×128，背朝外即可），绕人物划过 / 轮转由 CSS。
- **循环性**：人物微仰（轻微呼吸）CSS；星座/卡牌 loop。
- **锚点清单**：星座 / 卡牌轨迹起止点（画布百分比）。

### #3 MBTI Q 版躺摇椅人物

- **画面**：Q 版人物半躺摇椅、姿态松弛，配色接 MBTI 靛青渐变系。
- **主图交付**：同 #1（480×600 透明 PNG/WebP α；摇椅含在人物图中）。
- **动效**：优先「静态主图 + CSS 左右小角度摇晃」（loop）；若想要更生动可交付**摇椅 2–3 帧序列精灵图**（同画布 `steps()` 循环，注明帧数、循环点、@fps）。
- **循环性**：loop。

### #4 PWA 应用图标套装

| 项 | 尺寸 | 格式 | 说明 |
|---|---|---|---|
| 常规图标 | **512×512** | PNG | 不透明，品牌主色底 + logo；`art/pwa/icon-512.png` |
| 常规图标 | **192×192** | PNG | 同设计缩小版；`art/pwa/icon-192.png` |
| maskable | **512×512** | PNG | 主体（logo/图形）控制在 **≤80% 安全区**、四周留白铺满底色（Android adaptive 会裁圆/圆角） |
| apple-touch-icon | **180×180** | PNG | 不透明、**不带圆角**（iOS 自动加圆角），主体居中占满约 90% |
| 启动屏（可选） | 由开发给尺寸 | PNG | 背景色 + 居中 logo（无文字） |

- **风格**：以太初品牌 logo / 主题元素（如「太初」标识或卦象/星象抽象图形）为主，简洁、小尺寸可辨识；配色接全站主题色。
- **交付**：`icon-192.png` / `icon-512.png` / `icon-maskable-512.png` / `apple-touch-icon-180.png`（+ 可选启动屏）。
