# 太初产品形态调整与变现可行性评估

> 状态：基于现有产品流程图（docs/流程图.mmd）与三项形态调整设想的变现可行性评估
> 日期：2026-09-07

## 1. 现有形态回顾（已实现功能）

依据流程图，产品已包含三大模块：

- **① 国学预测**：九法合一解读、生肖流年、临时起卦（六爻 / 梅花 / 小六壬 / 灵签）；深度断卦为付费 LLM 即时扣费。
- **② 西式占卜**：星座（星盘）、塔罗、雷诺曼；星座 / 塔罗深度解读为付费 LLM 即时扣费。
- **③ MBTI**：16 型人格测试（60 题 / 直选），结果回写档案。
- 全站已有用户协议、隐私条款、免责声明；**无任何变现通道**。

核心付费点均为「LLM 即时扣费」，但缺乏收款机制。

## 2. 形态调整设想

1. 前端以文字展现国学知识，以星座与 MBTI 信息为主，偏向趣味娱乐。
2. 将「用 LLM 预测」改换表述。
3. 用户体验路径埋深。

## 3. 变现通路评估

### 3.1 支付类变现（小金商户助手 / 个体户商户号）

调整后可显著改善过审概率。

- 改动 1 将产品从「算命预测工具」重新定位为「趣味性格测评 + 国学文化内容」，更贴合小金支持的「线上虚拟服务 / 咨询 / 文化内容」类目。
- 改动 2 的措辞调整（趋势参考 / 解读 / 分析，非「预测结果」）降低表述风险，与平台审核口径一致。
- 个体户经营范围（文化咨询 / 软件开发）亦更好匹配。

**结论**：支付变现的可行性与包装合规度提升，是小金 / 个体户更顺的走法。

### 3.2 广告类变现（优量汇 / 穿山甲 / 微信流量主 / AdSense）

调整**不能解锁**广告变现，原因双重：

- **形态墙**：上述广告联盟均面向小程序或 APP，需企业资质 + 软著 + 应用市场上架；太初当前为纯 H5 网页，连接入资格都不具备（唯一接网页的 AdSense 又禁占卜 / 算命 / 占星）。
- **内容墙**：即便稀释为趣味向，命运 / 占卜类在广告联盟仍属敏感；腾讯广告明文「命 / 运 / 缘 / 八卦 / 五行 / 周易 / 易经」不支持投放，仅接受趣味互动、娱乐解读非预测类；AdSense 禁占卜算命占星。

**结论**：广告变现对当前形态为死路，形态调整无法救活（除非另起小程序 / APP + 企业资质，属另一笔投入）。

## 4. 关键风险提示

### 4.1 「星座」仍是禁区

微信小程序页面审核规范 3.2.4 将「算命、抽签、**星座运势**」并列列为禁投的测试类内容。若「以星座为主」仍做星座运势预测，在微信生态内仍踩禁区；只有做成「星座文化 / 星座性格科普」（非运势预测）才相对安全。**MBTI 为真正安全区**（趣味性格测评）。

### 4.2 门面稀释 ≠ 实质合规

若仅改前端文字、保留起卦 / 塔罗 / 九法合一等实质预测功能，属「半吊子」：

- 对支付（小金）：可能过（小金审类目与商品命名，不深审功能实质），但被投诉或监管追查时实质命理暴露即危险；
- 对微信封链：分享至微信仍可能因实质命理被限流。

### 4.3 「埋深路径」是错误战术

将体验路径埋深以规避审核属掩耳盗铃：

- 微信审核规范 3.1.4 要求隐藏 / 付费功能不得含违规内容，测试号须完整呈现体验；
- 用户投诉或监管一追即穿，且「规避审核」会升级为恶意认定。

正确做法是改表述定位（趋势参考 / 趣味测评 / 文化科普），而非隐藏功能。

## 5. 结论与建议

- 三项调整能解锁**支付变现**的合规包装（小金 / 个体户更顺），但**无法解锁广告变现**（形态墙 + 内容墙双死）。
- 建议：保留实质功能，对外统一定位为「国学文化 / 趣味性格测评」，走支付变现（小金被拒不纠缠 → 个体户商户号）；不碰广告。
- 落地优先级：先完成 H5 充值 → Webhook 加积分联调，量出单位经济，再定载体升级阈值。
