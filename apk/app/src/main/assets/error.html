本地服务启动失败

应用里的 Python 本地服务没能在 20 秒内就绪，所以暂时打不开界面。 这个服务是打包在 APK 内部、只在手机本机上运行的 127.0.0.1:8765， 不需要联网，也不需要官方服务器。

也就是说：问题出在本机服务没能起来，不是网络问题、也不是官方服务停了。

先试这两步

  1. 完全退出应用（在最近任务里把卡片划掉），然后从桌面图标重新打开，等几秒。
  2. 还是不行的话，卸载后重新安装这个 APK；新安装的第一次启动会解压 Python 运行环境，通常要慢几秒。

还是失败，就看日志

手机用 USB 连电脑，开启「USB 调试」，在电脑上执行：

adb logcat -s python.stdout python.stderr

重点看这两个标签：python.stdout 与 python.stderr。 它们分别是 Python 服务的正常输出和报错输出，启动失败的原因（缺少依赖、端口被占用、脚本报错）几乎都会出现在 python.stderr 里。

如果想连 Android 侧的报错一起看，可以改用： 

adb logcat -s python.stdout python.stderr AndroidRuntime

常见原因

  • Python 运行环境解压尚未完成，或设备存储空间不足。
  • 安装包里的 Python 服务文件缺失（例如打包前忘了同步资源）。
  • 本机 8765 端口被占用（少数情况下会被系统或其他应用占用）。
  • 安装的是不支持的 32 位 CPU 老设备：内置的 Python 3.13 只有 64 位版本。
这个问题不会自动恢复，需要你手动重开或重装应用。排查时请以 python.stderr 的实际报错为准。
