## 四、统一做法（不许自创）
| 场景 | 统一做法 |
|---|---|
| 加载中 | Skeleton 骨架屏（text / circle / rect / page，shimmer 扫光 1.5s）；短提示走全局单例 `toast(msg, 2600)`（standards/05 §3.3、§3.5） |
| 失败 | **失败禁止静默失败**（太初守则：重试设硬上限、连续同类错误快速中止、失败原因落错误字段供前端展示）；有状态弹窗参照 ShareFillModal 三态（成功 / 加载 / 失败）范式（standards/05 §3.2） |
| 需要确认 | 一律走 ModalBase 通用弹窗基座（ESC / 遮罩点击关闭、背景滚动锁定；宽弹窗传 `width`，左对齐传 `align="left"`），禁止再手写 `modal-mask`（standards/05 §3.1） |
| 空态 | 列表 / 档案空态统一用 Empty 空状态组件（技术债 P2，部分页面已有）；不新造空态形态（standards/05 §6） |
| 样式 | 一切视觉属性用 CSS 变量：皮肤色必走 `--skin-*`，动效必走 `--dur`/`--ease`，**禁止硬编码色值 / 尺寸**；间距走 `--space-*`、阴影走 `--shadow-*`（token 族待节135 阶段A 补全，standards/04 §1.2） |
| 组件编码 | Props 解构 + 默认值，禁 `props.xxx` 散点读取；按钮带 `aria-label`、图片带 `alt`；新组件先查本表并登记（standards/05 §1.2、§5） |
| 文案 | 一切 UI 文案走 `data/ui-copy.js` 的 `TC_COPY.ui` 总表（新增先登记 key）；**禁止 `toast('中文')` / JSX 内联中文 / 自建文案词典**；`admin.html` 后台文案同源（节135 阶段C） |
| 图标 / 美术 | 图标走 `Icon`、位图走 `--art-*` 令牌；**禁止内联 SVG / emoji 图标**；资源路径一律根绝对 `/art/*`（BUG-009） |
| 数据 | 牌阵 / 术语卡 / 配对等静态数据走 `data/*.js` 单一来源；**禁止视图内复刻映射**（如「花色→颜色」，节135 阶段D 归一） |

## 五、红线
- 不许硬编码颜色 / 间距（用设计值，见 §一）
- 静态资源必须根绝对路径 `/vendor/*`（BUG-009 教训：相对路径在深层分享路由 404、被当 text/html 执行；`--art-*`、`/data/*` 同理，一律根绝对路径）
- 单文件超限必须拆：入口壳 `frontend/public/index.html` <2000 行；单 `.js`/`.css` <5000 行（节110 解耦后标准，规范见 §六）

## 六、前端拆分规范（节110 解耦 · 阶段0 定下，后续各阶段遵守）
> 目标：`frontend/public/index.html` 22046 行 → 「入口壳 + `css/*.css` + `js/*.js`」，免构建不变。

1. **命名**（kebab-case，同 standards/01）：
   - CSS：`css/tokens.css`（`:root` 令牌 + 皮肤）、`css/components.css`（reset + 壳 + 通用组件 + 盘面）、`css/pages.css`（页面/业务样式）。更细的 pages-<域> 拆分如需再拆留待后续。
   - JS：`js/components.js`（ModalBase/Icon/DisclaimerFooter/SkinSwitcher/toast/轨道/精灵 等通用件+共享工具，**必须早于 views 加载**）；`js/views-<域>.js`（视图，阶段3）。全局状态+api+文案别名+埋点+App 路由+挂载 留在 `index.html`（阶段4 骨架）。
2. **加载顺序**：见 `导航.md` §7.1（vendor → data → globals → components → views-* → app）。
3. **precompile 适配（关键）**：拆出的 `.js` 只放**已预编译的普通 JS**（从 index.html 原样搬出），**禁止再写 JSX**——precompile 门禁只扫描 index/admin 两个 HTML 内联块；且 `@babel/preset-react` 未在任何 package.json 声明（node_modules 只有 `@babel/core`），新 .js 内的 JSX 无法被门禁编译。JSX 只允许留在 index.html 骨架。**红线不变**：禁止浏览器端 `<script type="text/babel">` 实时转译。
4. **资源路径**：拆出的 .css/.js 内 `/vendor/*` `/art/*` `/data/*` 一律根绝对路径（BUG-009）。
5. **分阶段**：0 建体系✅ → 1 拆 CSS✅（css/tokens+components+pages.css）→ 2 拆通用件✅（js/components.js）→ 3 拆视图✅（js/views-<域>.js，按域逐节；已拆 views-guoxue.js=黄历 AlmanacPage/太乙 TaiyiPage/皇极 HuangjiPage、views-xishi.js=西式 HUB XishiHubPage/塔罗 TarotPage/雷诺曼 LenormandPage/星座 AstrologyPage、views-mbti.js=心理 HUB MbtiHubPage/人格 MbtiPage/免登录分享 MbtiSharePage、views-zodiac.js=生肖 ZodiacPage/生肖关系图标/生肖三关系弹窗、views-cases.js=档案列表 CasesPage/建档弹窗 RenameModal·CaseContactModal·ShareFillModal/解读流程 WaitingPage·CalibrationPage·PredictPage·RevisePage·TopicPage/档案详情 ArchivePage/9 法命盘渲染/分享帮填 CaseSharePage、views-divination.js=临时起卦 DivinationPage/六爻/梅花/小六壬/六壬/金口诀/奇门/文王圣卦、views-onboarding.js=登录注册 AuthPage/建档引导 OnboardingPage、views-home.js=首页 LandingPage/积分/配对/导航/设置 SettingsPage、views-guoxue-tools.js=国学工具 NinePickPage/NamerModal/GuoxueHubPage/GuoxueToolsPage、views-agent.js=太初先生 AgentPage）→ 4 收敛（入口壳 <2000 行；单 .js/.css <5000 行）。每阶段 git 留底 + 跑 precompile 门禁 + 用户亲验。
6. **单一事实源**：权威入口仍是 `frontend/public/index.html`；`frontend/src/` + Vite 脚手架已归档至 `_archive/前端-vite-ts-参考实现/`（见 §二「前端权威入口」）。
