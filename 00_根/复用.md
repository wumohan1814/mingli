## 四、统一做法（不许自创）
| 场景 | 统一做法 |
|---|---|
| 加载中 | Skeleton 骨架屏（text / circle / rect / page，shimmer 扫光 1.5s）；短提示走全局单例 `toast(msg, 2600)`（standards/05 §3.3、§3.5） |
| 失败 | **失败禁止静默失败**（命理守则：重试设硬上限、连续同类错误快速中止、失败原因落错误字段供前端展示）；有状态弹窗参照 ShareFillModal 三态（成功 / 加载 / 失败）范式（standards/05 §3.2） |
| 需要确认 | 一律走 ModalBase 通用弹窗基座（ESC / 遮罩点击关闭、背景滚动锁定；宽弹窗传 `width`，左对齐传 `align="left"`），禁止再手写 `modal-mask`（standards/05 §3.1） |
| 空态 | 列表 / 档案空态统一用 Empty 空状态组件（技术债 P2，部分页面已有）；不新造空态形态（standards/05 §6） |
| 样式 | 一切视觉属性用 CSS 变量：皮肤色必走 `--skin-*`，动效必走 `--dur`/`--ease`，**禁止硬编码色值 / 尺寸**；间距/阴影新代码优先 `--mingli-sp-*` / `--mingli-shadow-*`（节136 A 已按 standards/04 v1.2 补全；旧令牌保留不动）。**散色门禁**：tokens.css 之外现存 0 处 `#hex`/`rgb()`，新增即被 `precompile.js` 拦截（基线 `scripts/hardcode-baseline.json` 只许减不许增，节136 B） |
| 组件编码 | Props 解构 + 默认值，禁 `props.xxx` 散点读取；按钮带 `aria-label`、图片带 `alt`；新组件先查本表并登记（standards/05 §1.2、§5） |
| 新增面向用户的文字 | 先分类再归口，**禁止散落在 .js 业务逻辑里**：① 界面词（按钮 / 标签 / 提示 / 错误信息）→ `ui-copy.js` 的 `ML_COPY.ui.<模块>`；② 正文内容（卦辞 / 牌义 / 释义 / 名词 / 配对文案）→ `data/content/<领域>/<领域>-zh.js` 挂 `CONTENT.<领域>`，并在 index.html 业务脚本前加一行 `<script>`，业务文件 `const 别名 = CONTENT.路径` 引用。**后端托管正文不要在前端重建副本**：MBTI 16 型描述（`backend/app/mbti/data/`）、观音灵签 92 支（ssgw-data）、占星解读（natal API）均由后端下发（节135 C/D/E 结论），其多语言需后端层面另议；`admin.html` 后台文案同源走 ML_COPY |

## 五、红线
- 不许硬编码颜色 / 间距（用设计值，见 §一）
- **脚本顶层解引用的全局别名，必须在更早的 `<script>` 里定义**：`UI_COPY`（= `ML_COPY.ui`）在 ui-copy.js 之后的独立内联脚本中提前定义（index.html），content/*.js 与 js/*.js 均在其后加载。曾因别名定义在更晚的主引导脚本里，7 个文件顶层常量加载即抛 ReferenceError、整文件静默失效（节105 遗留，节135 修复）；新增同类全局别名同此规则
- **改数据 / 业务脚本后必跑全量 `node --check`**（js/、data/、data/content/）：免构建无构建期语法拦截，浏览器对经典脚本的 SyntaxError 只报一条且整文件不执行；语法过了还要验顶层常量 / 组件 typeof 真实存在（语法过 ≠ 顶层运行时过）
- 静态资源必须根绝对路径 `/vendor/*`（BUG-009 教训：相对路径在深层分享路由 404、被当 text/html 执行；`--art-*`、`/data/*` 同理，一律根绝对路径）
- 单文件超限必须拆：入口壳 `frontend/public/index.html` <2000 行；单 `.js`/`.css` <5000 行（节110 解耦后标准，规范见 §六）

## 六、前端拆分规范（节110 解耦 · 阶段0 定下，后续各阶段遵守）
> 目标：`frontend/public/index.html` 22046 行 → 「入口壳 + `css/*.css` + `js/*.js`」，免构建不变。

1. **命名**（kebab-case，同 standards/01）：
   - CSS：`css/tokens.css`（`:root` 令牌 + 皮肤）、`css/components.css`（reset + 壳 + 通用组件 + 盘面）、`css/pages.css`（页面/业务样式）。更细的 pages-<域> 拆分如需再拆留待后续。
   - JS：`js/components.js`（ModalBase/Icon/DisclaimerFooter/SkinSwitcher/toast/轨道/精灵 等通用件+共享工具，**必须早于 views 加载**）；`js/views-<域>.js`（视图，阶段3）。全局状态+api+文案别名+埋点+App 路由+挂载 留在 `index.html`（阶段4 骨架）。
2. **加载顺序**：见 `导航.md` §7.1（vendor → data → globals → components → views-* → app）。
3. **precompile 适配（关键）**：拆出的 `.js` 只放**已预编译的普通 JS**（从 index.html 原样搬出），**禁止再写 JSX**——precompile 门禁只扫描 index/admin 两个 HTML 内联块；且 `@babel/preset-react` 未在任何 package.json 声明（node_modules 只有 `@babel/core`），新 .js 内的 JSX 无法被门禁编译。JSX 只允许留在 index.html 骨架。**红线不变**：禁止浏览器端 `<script type="text/babel">` 实时转译。
4. **资源路径**：拆出的 .css/.js 内 `/vendor/*` `/art/*` `/data/*` 一律根绝对路径（BUG-009）。
