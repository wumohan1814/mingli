## 3. 契约与数据（重要）

- **`method-result v2` / `chart.json` 是跨模块唯一协商点，禁止私自改字段**（改字段须走 ADR / standards）。
- **错误码分段**（已核实；原文见 `_archive/破竹迁移/测试知识库-已废弃-测试组角色.md` §2.4，已归档；实现 `backend/app/errors.py` code_to_http）：

| 段 | HTTP | 例 |
|---|---|---|
| 1xxx 通用（含 1002 不存在） | 400 | `ERR_NOT_FOUND=1002` → 400 |
| 2xxx 认证鉴权 | 401 / 403 | — |
| 3xxx case / 档案 | 404 | case 不存在 |
| 4xxx 排盘 | 422 | — |
| 5xxx LLM / 积分 | 502 | `5002 余额不足` |

- 断言「资源不存在」按 body `code` 判断（如 `code == 1002`），不要按 REST 直觉断言 HTTP 404——那只在 3xxx case 段成立。
- 关键接口 / 数据字典细节 → **`docs/standards/03-接口与数据字典.md`**（不在此展开）。

## 4. 红线（命理 AGENTS.md 原样，违反即返工）

1. **领域术语禁止混用**：`session`（JWT 会话）≠ `case`（命理档案）≠ `job`（异步任务）≠ `phase`（`duan-qian-chen` / `prediction`）；`方法/法`（8 法）≠ `主模块` ≠ `主问`。
2. **成本红线**：排盘 / 校准打分为确定性计算零 LLM；仅「解读 / 校验 / 修正对话」调 LLM；逐法扣费 + revise/query 即时扣费，排盘 / 校准不扣（余额口径见 REQ-085：1 元 = 10,000 tokens）。
3. **多用户隔离（硬约束）**：JWT 取 `userId` 注入所有查询，任何 SELECT/UPDATE/DELETE 必带 `user_id`；否定用例（A 访问 B 的 caseId → 403/404 不泄漏）列入测试 / 验收。
4. **唯一事实源**：档案以数据库为唯一事实源（`charts.chart_json` 全量落库，REST 投影裁剪）。
5. **契约与规范**：`method-result v2` / `chart.json` 契约禁止私自改字段；规范变更须同步 `standards/07-版本迭代记录.md` 并在 PR 描述引用；ADR 一旦 Accepted，推翻须新建 ADR 并标 `Superseded by`。
6. **前端红线**：权威入口只有 `frontend/public/index.html`（+ `admin.html`）；`frontend/src/` 已归档不参与运行；改 JSX 必须跑 `node frontend/scripts/precompile.js`（拆出的 .js 禁止写 JSX，见 `复用.md` §六）；静态资源必须根绝对路径 `/vendor/*`（BUG-009 教训）；后端门禁 `cd backend && python -m pytest -q` 全绿。
