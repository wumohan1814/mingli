## 一、层级总览（有几层 / 从哪进哪）

① 首页（落地页）——三大模块宣传入口 + 左侧导航按钮 + 顶部 Banner
   ↓ 点击宣传块 / 导航进入
② 三大功能域（登录后各功能先「选档案」；无档案先进建档——建档强制门）
   ②-a 国学预测 → 国学 Hub：命盘·八法合一 / 问事·即时起卦 / 择吉与时势 / 生肖流年
   ②-b 西式占卜 → 西式 Hub：星座 / 塔罗 / 雷诺曼 / 配对解析
   ②-c MBTI → 人格测试（大五 OCEAN，300 题 5 点量表）/ 结果含五维 + 四字母对照 / 免登录分享
   ↑ 各功能结果与档案绑定
③ 档案层——档案管理列表 → 档案详情（建档 / 查看 / 修改 / 删除 / 分享帮填）
④ 账户层——登录注册 / 王先生会话 / 功能设置 / 余额（右上角菜单）
⑤ 后台层（管理员专用）——报表 / 用户 / 余额调整 / Prompt 管理台 / 素材热更 / Agent 运维通道

## 二、每层有什么

### 第①层 首页（落地页 · 节140 T3b 改版为意图页）
- 作用：第一眼入口，白话意图分流（新手零门槛）+ 回访区 + 探索全部方式。
- 有什么：**6 意图卡**（问件事 / 了解我自己 / 我和TA / 挑日子取名 / 看流运 / 随手抽，正文来自 `CONTENT.catalog.intents`）→ 意图推荐页 `/intent/:key`（推荐带理由 + 「我自己挑方式」逃生舱）；**回访区**（登录后：继续上次 / 我的命盘 / 本月流运）；**「探索全部方式」→ /explore**（标签筛选 + 方法卡墙，来自 `CONTENT.catalog.methods`）；左侧导航 + 顶部 Banner（右上角余额 / 菜单）+ 全局页脚（免责声明 / 用户协议 / 隐私政策）。（节145：原「三只 Q 版化身动画」整块已删，进「王先生」会话改走顶部 Banner「对坐谈心」入口）
- 位置（给 Agent）：路径 `/`（LandingPage）+ `/intent/:key`（IntentPage）+ `/explore`（ExplorePage），视图在 `frontend/public/js/views-home.js`；目录数据 `frontend/public/data/content/catalog.js`。旧三模块落地页与 HUB 壳层待节140 T3d 拆除。

### 第②层 三大功能域

（a）国学预测（国学 Hub，路径 `/guoxue`）——4 张场景大卡：
- 命盘·八法合一（`/jiufa`）：选档案 → 排盘 → 8 法解读（八字格局 / 八字大运流年 / 八字神煞纳音 / 八字婚姻财运 + 紫微斗数 + 七政四余 + 奇门终身局 + 五运六气）→ 断前尘 / 校准 / 预测 / 追问。西占已退出本流水线（节139）；档案详情「占星盘」tab 与西式占卜独立链路保留。
- 问事·即时起卦（`/divination`）：六爻 / 梅花易数 / 小六壬 / 观音灵签 / 大六壬 / 金口诀 / 奇门时家，起卦免费、深度断卦付费。
- 择吉与时势（`/guoxue/tools`）：黄历择日（免档案）/ 八字起名 / 双人配对（八法配对、八字配对）/ 时势推演（太乙神数、皇极经世）。
- 生肖流年（`/zodiac`）：免费引流玩法，档案驱动。

（b）西式占卜（西式 Hub，路径 `/xishi`）：
- 星座（`/astrology`）：本命星盘 + 太阳 / 月亮 / 上升三格 + 恋爱 / 朋友 / 上下级三关系 + 本命深度解读（付费）。
- 塔罗（`/tarot`）：78 张牌、19 种牌阵，两段式取牌 / 读牌，抽牌免费、综合解读付费。
- 雷诺曼（`/lenormand`）：36 张牌、7 种牌阵，与塔罗同一套两段式机制。
- 配对解析：双档案配对（本命星盘维度，付费）。

（c）MBTI（`/mbti`）：大五人格（OCEAN）测评（300 题 5 点量表，节123 起题库为 IPIP-NEO-300；节124 起前端 5 点量表 + 结果页五维 + 四字母对照换算带边界标注）+ 档案绑定（节125：判型不回写档案，用户「保存/自填」才写入，来源标注）+ 免登录分享链接（他人填写后结果回写档案）。

### 第③层 档案层
- 作用：全站数据的「主人」——命理档案是唯一事实源，星座 / MBTI / 八法共用同一档案体系。
- 有什么：档案管理列表（`/cases`，CRM 行式：档案名 + 生日 + 手机号 / 邮箱 + 查看 / 修改 / 重命名 / 删除）；档案详情（`/cases/:id`：出生信息、占星盘、MBTI 心理测试、历史记录）；统一建档表单（档案名选填 + 出生信息 + 手机号 / 邮箱选填）；「分享帮填」一次性链接（访客免登录代建，档案归发起者）。
- 位置（给 Agent）：`frontend/public/index.html` 档案视图 + `backend/app/api/cases.py` 等。

### 第④层 账户层
- 作用：身份、余额与个人设置。
- 有什么：登录 / 注册（`/login` · `/register`，手机号 + 图形验证码）；余额 ¥（右上角菜单顶部展示，可点进消费明细：项目中文标签 + 档案名，1 元 = 10,000 tokens）；王先生会话（`/agent`，「对坐谈心」，带档案上下文 + 跨会话长期记忆，按 token 计费）；功能设置（`/settings`：动画 / 默认模式 / Banner 导航 / 分享表单 UI / 背景图 / 牌面图 / 王先生共 7 个开关）；购买充值入口（暂隐藏，待商户认证后放开）。
- 位置（给 Agent）：`backend/app/auth/`、`backend/app/credits/`、`backend/app/api/agent.py` 等。

### 第⑤层 后台层（管理员，`/admin/*`，admin.html）
- 作用：运营与运维的中枢，C 端用户不可见。
- 有什么：数据报表（埋点中文映射）；用户管理 / 余额调整（充值或扣减，留审计）；Prompt 统一管理台（文件类 prompt 列表 / 编辑 / 版本回滚 / 热生效）；素材管理（背景图与蒙版 + 塔罗 / 雷诺曼卡面热更）；错误报告与服务健康；OpenClaw Agent 运维通道（查看类 + 高风险写操作）。
- 位置（给 Agent）：`backend/app/admin/` + `frontend/public/admin.html`。
