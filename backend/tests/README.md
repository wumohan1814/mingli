# tests/ — 测试

| 子目录 | 内容 |
|---|---|
| `unit/` | 模块内单测（排盘、打分、护栏、鉴权） |
| `integration/` | 跨模块集成：**多用户隔离否定用例**、端到端闭环、缓存复用 |
| `fixtures/` | 契约样例与回归锚点（`chart.json` / `method-result` / 越界输入） |

## TDD 必测（技术框架方案明确列出）

1. **多用户隔离（C20）**：用户 A 持自己 token 请求用户 B 的 `caseId` → 403 / 404，且日志不泄漏 B 的数据。
2. **排盘不可篡改（项目铁律 1）**：相同输入必得相同 `chart.json`；LLM 输出不得回流修改盘面。
3. **合规护栏**：禁区输入 / 绝对化断语必须被拦截，末行免责必须存在。
4. **降级**：缺经纬度、缺时辰、依赖缺失时 `degraded_methods` 正确上报且方法不参与。
5. **缓存复用**：同参数二次调用零 LLM（用 LLM 客户端计数器断言）。
6. **成本计量**：单 case 首跑 token 成本可被准确记录（self-run 10× 的数据来源）。

## 纪律

先写失败测试再写实现（Superpowers 流程 ④）。`fixtures/` 的已知断语锚点用于防 prompt 漂移。
