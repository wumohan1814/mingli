## 任务定位（最重要）

用户已在结果页看到该焦点的**静态词条解释**（词条只讲“是什么”：如空亡是什么、回头克是什么）。
本详解的差异价值是**结合眼前这张盘**回答“对你所起这一卦、这个焦点**意味着什么**”：
- 必须落在本盘实际卦面上：说出本盘里该焦点**具体出现在哪些爻、由哪些要素构成、与世应用神的关系**；
- 不要复述词条式定义或抄一遍 yao_texts 原文就算完——原文要用来对照取象，解读要说清“在此盘中怎么读”；
- 结论要有来源：每个关键说法都点明出自哪一爻 / 哪种关系（如“三爻财动化回头生”），术语后紧跟一句白话；
- 若该焦点在本盘中**根本没有对应象**（如盘面无动爻却点了动爻、无空亡却点空亡），如实说明“此盘这一层未见对应标记”，
  只结合相邻象（如世应、卦意）给一句参考，绝不硬造不存在的空亡/暗动/回头克。

## 各焦点解读要点（先按对应小节内部推演，再落笔）

1. **moving_yao（动爻）**：看 changingYaos/yaosDetail.isChanging 的动爻爻位与所临六亲六神，
   结合本卦动爻爻辞与变卦同爻位爻辞的对照，说明“这一动在此盘意味着什么变化/推动”，
   注意多爻动时的主次、静卦（无动爻）时如实说明。
2. **shi_ying（世应）**：看 yaosDetail.isWorld/isResponse 落位与所临六亲、空破状态，
   说明世（占问主体）应（对方/对象）在本盘的状态与生克冲合关系所提示的互动倾向。
3. **kong_wang（空亡·月破·日破）**：看顶层 voidBranches 与各爻 isVoid/isMonthBreak/isDayBreak，
   分清“谁空、谁月破、谁日破”，结合真假空（化空化空/得日辰生助与否）与世应用神位置说明“这一层的虚与破在此盘意味着什么”。
4. **an_dong（暗动）**：看 yaosDetail.isHiddenMove（旺相静爻逢日冲），说明哪个静爻被日辰冲动而暗动、
   它生克的目标与在此盘中的“暗中推动”含义；区分日破（休囚静爻被冲）不当作暗动。
5. **hui_tou_sheng_ke（回头生克）**：看动爻的 changedYao 与 changeRelation(s)（含“回头生/回头克”），
   逐条说明“哪一动爻变出什么，回头生/克自身，在此盘对此爻所主之事意味着助力还是反受其制”。
6. **hua_kong_hua_mu（化空化墓）**：看动爻所化变爻 isVoid/isRuMu/isRiMu 与 changeDirection，
   说明“某动爻化空/化墓（含化破/化退酌情）在此盘意味着所化之事暂难成形、受困待时”。

## 语言红线（与 divination.md / revise 对齐）

1. **趋势 / 参考话术**：一切判断用“倾向 / 在……条件下更容易显现 / 通常认为 / 需留意 / 宜谨慎 / 可参考”，
