# routing/ — 模块 11：路由决策（正式模块）

> 原「⚠️ 待决策 P1」，已由 **ADR-0004** 关闭：独立模块 + 配置化，零 LLM 调用。

## 职责

决定「本次预测跑哪几法」：主问 → 主 / 辅方法集合。

## 输入 / 输出

**输入**：主问领域 + 校准权重（`score.py` 产出）+ `degraded_methods`（降级法）+ 用户点名的方法
**输出**：路由决策记录（选用方法清单、主 / 辅角色与理由）→ **落库留存**，供阶段 5 推理链路与事后复盘

## 规则

1. 路由表**配置化**（仓库内结构化配置，非提示词）→ 决策为纯查表 + 权重排序，**零 LLM 调用**。
2. 主方法全跑；辅方法只跑与主问高相关的子问题。
3. **被降级的方法不得进入路由结果**（其盘面片段为 `null`）。
4. 用户点名的方法强制纳入。

## 边界

「用户自然语言 → 主问领域」的识别**不属于本模块**，由建档阶段产出（建议在建档表单中让用户
直接选择主场景，从而完全省掉一次分类调用）。

## 维护纪律

新增方法模块必须同步登记路由表，否则该方法**永远不会被选中**。
