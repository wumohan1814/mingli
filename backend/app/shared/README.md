# shared/ — 公共能力

跨模块复用的非业务能力。所有模块都可依赖 `shared/`，`shared/` **不依赖任何业务模块**。

| 能力 | 说明 |
|---|---|
| 配置 | 环境变量加载与校验（见 `docs/standards/04` §3） |
| 日志 | 结构化日志；**禁止打印用户生辰、断言内容等敏感字段** |
| DB | 连接、userId-scoped repository 基类、迁移入口 |
| LLM 客户端 | 模型调用封装 + **token 计量**（R9 成本闸门唯一数据源，按方法模块级统计） |
| 鉴权工具 | JWT 签发 / 校验、密码哈希、刷新令牌 |
| 限流 | 计数与锁定（供网关使用） |
| 错误 | 统一错误码与 REST 信封构造 |

## 纪律

- 任何"所有模块都要用"的逻辑先放这里，避免各模块重复实现导致行为漂移。
- 新增能力需同步 `docs/standards/02-技术栈清单.md`。
