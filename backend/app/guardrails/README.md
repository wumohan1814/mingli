# guardrails/ — 模块 9：合规护栏（横切）

**双层护栏**（R5）。本模块是第二层（输出侧兜底），横切内嵌于各模块返回前，**不独立部署**。

## 生成侧（第一层）

- `prompts/` 中的 method-prompt 与阶段 5 模板强制"趋势 / 参考"话术。
- 路由层拦截禁区主问（医疗 / 投资 / 司法）。

## 输出侧（本模块，兜底）

| 检查 | 行为 |
|---|---|
| 禁区检测 | 命中医疗 / 投资 / 司法预测 → 拦截并改写为趋势话术 |
| 确定结论检测 | 命中绝对化断语 → 改写为"趋势 / 参考"表述 |
| 末行免责 | 强制追加：「命理仅供参考，不替代医疗、法律、投资等专业意见。」 |
| 占卜门控 | 非"一事一占"场景不返回占卜类结果 |

## 依赖

禁区词表与话术模板来自 `product/compliance/`，**改词表必须同步本模块实现与回归用例**。
判定机制（关键词表 vs LLM 分类）见待决 ADR-09。

## 测试

越界输入必须被拦截——这是合规生死线，回归用例不可跳过（技术框架方案 §11 建议建 fixtures 锚点）。
