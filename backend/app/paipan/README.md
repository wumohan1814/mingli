# paipan/ — 模块 4：排盘基础模块

**确定性计算，零 LLM。** 三个能力，依据 ADR-0001 **全部自研**：

| 能力 | 产出 | 说明 |
|---|---|---|
| 排盘 `paipan` | `chart.json`（唯一事实源） | 自研胶水层，调用开源引擎 |
| 切片 `slice` | `slices/<method-key>.json`（9 片，每法只取自己片段） | 自研映射逻辑 |
| 打分 `score` | 契合度与权重，幂等写入校准记录 | 自研三因子实现 |

## 依赖分层（ADR-0001）

| 层 | 归属 |
|---|---|
| `lunar-python`（八字历法）、`iztro`（紫微）、`mingyu-core`（占星 / 七政 / 奇门） | **引入**（开源库） |
| 排盘胶水、降级逻辑、切片、打分 | **自研**（本模块） |
| `reference/mingli/` 中的脚本与提示词 | **仅参考**，不 import、不打包 |

> `paipan` 的 Python 胶水层需通过 `subprocess` 调用 Node 侧的 iztro / mingyu-core，
> 部署镜像必须同时具备 Python 3.13 与 Node 22。

## 硬护栏（项目铁律 1）

一切干支、十神、神煞、纳音、藏干、大运、流年、起运、紫微星曜宫位四化等**只由代码产出**，
LLM 不得心算、重排、"修正"或"润色"任何数值性盘面内容。`chart.json` 是后续所有阶段的唯一事实源。

## 降级

- 缺经纬度 → 占星 / 七政 / 奇门 / 五运六气段为 `null`，方法不参与并记入 `degraded_methods`，
  且**不得进入路由结果**（ADR-0004 规则 3）。
- 缺时辰 → 前三柱低置信（`bazi.pillars.hour = null`），断前尘只做年 / 月级断言。
- 依赖缺失 → 对应段 `null`，**严禁脑补**。

## 打分公式（自研，兼容 mingli 语义）

契合度 = 0.5×命中率 + 0.3×命题质量 + 0.2×依据链完整度；`weight = 0.4 + 0.6 × 契合度`；无反馈方法权重 0.5。

> 「命题质量」依赖各法的 `<key>.validation.json`（缺失恒取 0.5）——由 `../validation/` 在
> **断前尘阶段**产出（ADR-0002）。预测阶段不校验，该因子不更新。

## 回归基线（ADR-0001 代价）

自研后需自建排盘回归基线：各法的排盘与切片结果快照进 `tests/fixtures/`，
（节139 后切片为 8 法；`chart.json.western` 仍由排盘生成，供西占占星盘展示），
任何引擎升级或逻辑改动都需回归通过。
