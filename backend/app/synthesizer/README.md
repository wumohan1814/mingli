# synthesizer/ — 模块 5：主模块（跨方法合成器）

**两阶段聚合职责统一归主模块**（R11 / C23）。

## 职责

| 阶段 | 行为 |
|---|---|
| 断前尘 | 订阅 8 法 `MethodAnalysisCompleted` → 按 `confidence_level` 筛出 `high` / `medium` 且落在近 20 年的断言 → 按 `domain` 分组、每领域留最有信息量者 → 合成 **5–10 条问卷断言**返 H5 |
| 预测 | 按 `score.py` 权重 + `confidence_level` 做**阶段 5 合并裁决**（不投票、不二次解读）→ 发布 `SynthesisCompleted` → 吉凶直说 + 末行免责 |

## 聚合窗口（C19，按 phase 区分）

- **断前尘（串行）**：第 8 个 `MethodAnalysisCompleted` 到达即合成；窗口 **5min**，仅作单法卡死保护
  （超时则已完成法参与合成、缺法标记 `degraded` 并提示）。
- **预测（并行扇出）**：等齐主 / 辅法（或降级集合），窗口 **60s**，超时同样降级。

## 纪律

- **不机械投票**：不以"3:2"定胜负，契合度高者优先。
- **识别同源重复**：八字格局 / 大运流年 / 神煞纳音同源自 `bazi`，一致不算独立印证。
- **置信档纪律**：`speculative` 不参与定论、只作参考；`low` 只作参考或条件分支。
- **不二次解读**：不得重新推演干支 / 星曜，只对已有盘面与各法结论做裁决。
- 仅全盘 / 多方法场景触发；**单方法直问 bypass 主模块**。
