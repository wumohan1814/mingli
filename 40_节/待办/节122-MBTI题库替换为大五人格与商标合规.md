- ⭐ **Agent 建议取舍**：**默认完整版；快速版作为"没时间"的分流选项**，并在结果页**标注所用档位**，避免历史对比时困惑

## 4.1.2 🆕 多档位的最终执行方向（用户 2026-09-11 第三轮裁决）

用户原话：
> "把官方完整的题量，每个档位的题量都抓取下载下来，然后生成一个文案需求：1. 有中文 120 题的，就使用中文官方的 120 题。2. 没有的，就提文案需求，然后我去把官方的内容进行翻译。"

→ 即：**不砍档位，全都要**；**中文缺口由用户自己承担翻译**。Agent 的活缩成两件：

1. **抓取**：把官方**每个档位的完整题项**抓下来落盘（含题号 / 英文原文 / 维度 / 层面 / 计分方向）
2. **出需求**：写一份**中文文案需求（翻译工单）**，让用户照单翻译

**产出物（已按此执行）**：
- `40_节/待办/节122-题库原件/`（抓取落盘：各档位 JSON + `README.md` 记录来源与字段完整度）
- `40_节/待办/节122-题库中文文案需求.md`（翻译工单）

### ⚠️ Agent 必须提醒用户的三点（诚实标注，不替用户拍板）

1. 🚨 **多档位 ≠ 同质的多档位** —— **只有 120 题档位"有据"**（官方中文 + 五维 α ≥ .799）；其余档位是「**来源合法，但中文信度无据**」（自译 = 又回到我们这次要逃离的"自研无据"状态）。→ **这个差异必须在结果页对用户标明**（否则同一产品里，一档有信度背书、另一档没有，却长得一样）。
2. 🚨 **档位越多，四字母映射越麻烦** —— 不同档位算出的大五分不同、据以映射的四字母也可能不同（§4.1.1 末尾的"历史可比性"问题会随档位数放大）。
3. ⚠️ **IPIP 官方那句免责同样适用于我们自己翻的档位** —— "翻译准确性未经 IPIP 项目方核实"（§1.2）。
4. ✅ 但**合规性是干净的**：IPIP 明文允许 **edit / translate**（§1.1）→ 翻译产物是**我们自己的**，**不涉及任何第三方许可、无需通报**。

## 4.2 计分

- 5 点 Likert：正向题 `1–5` 计分，反向题 `6 − x`（IPIP 官方计分说明页：`newScoringInstructions.htm`）。
- **维度分** = 该维全部题项之和 → 归一到 **0–100**（**内部量**，供映射与条形图）。
- **层面分**：**计算但不在页面上展开**（§1.3：层面 α 低，展示即伪精确）。
- **⚠️ 不给人群百分位 / 不给"超过 X% 的人"**（§1.4：常模 N=131 不成立）。
  呈现建议：五维**条形图 + 档位文字**，并在说明里写明 ——
  > "本图表示**你在本量表各维度上的得分**，不是你在人群中的排名。"

## 4.3 四字母映射（⚠️ **前提经核查后已被削弱 —— 方案必须相应降级**）

### 4.3.0 🚨 三条硬约束（**独立核查取到的原文事实，推翻了我最初的"线性映射"设想**）

1. **`N`（神经质）没有对应维度** —— McCrae & Costa (1989) 摘要是「**four of the five**」；三处独立原文均确认。→ **映射只能用 O / C / E / A 四个**（正好对四字母，**N 只作展示，不参与换算**）。
2. **四维并不独立** —— **J–P 与 S–N 互相相关**、**C 同时与 T–F 相关** → **"一个字母由一个维度独立决定"的前提不成立**；按维度分别卡阈值，产出的字母会**互相牵连**、可靠性低于表面。
3. **不存在"大五 → 四字母"的标准化换算规范**，**也不存在其准确率的同行评议评估**（多库检索落空 —— 核查员标注的**最大空白**）。且该文**否定"二分类型"本身**、**质疑 J–P 维度**。
   - ➕ **2026-09-11 补充**：用户提供了 **Arneson (2016) 的四个 r 值**（§4.3.1）→ **我们有了"一个来源的相关强度"**，但⚠️ **这与"有一套经过验证的换算方法"是两回事** —— **该空白依然存在**，所以映射仍只能定位为「**对照参考**」。

> **→ 结论：这是一条"没有标准答案、也没有已知准确率"的路。** 所以**绝不能**把它包装成"换算结果"，只能包装成"**对照参考**"；**也不能编一套看起来很精确的公式冒充科学**。

### 4.3.1 映射设计（✅ **已拿到权重** —— 用户 2026-09-11 提供）

#### 权重表（用户抄录自 Arneson (2016) 表格）

| MBTI 维度 | 对应大五维度 | **r 值（区间）** | **r²（大五能解释的比例）** | 强度判定 |
|---|---|---|---|---|
| **E–I** | 外向性 Extraversion | **−0.74 ~ −0.79** | **.55 ~ .62** | 🟢 **强** |
| **S–N** | 开放性 Openness | **0.65 ~ 0.72** | **.42 ~ .52** | 🟢 **强** |
| **T–F** | 宜人性 Agreeableness | **0.44** | **.19** | 🟠 **中弱** |
| **J–P** | 尽责性 Conscientiousness | **0.49** | **.24** | 🟠 **中弱** |

> ⚠️ **来源与诚实标注（不许混淆）**：
> - 数值由**用户 2026-09-11 抄录**自 Arneson (2016) 的表格（权利人 MBTI Facts 页 / CPP 白皮书）
> - ⚠️ **Agent 未能亲自取到原文表格** —— 该页面上这张表是**图片**；Furnham 2022 的 OA PDF **工具不支持 `application/pdf`**；SCIRP 论文页 **403**；Wikipedia 与 `r.jina.ai` **网络不可达**。→ 因此数值属「**用户提供 · Agent 未亲验原文**」，登记与引用时按此标注
> - ✅ **但"方向"这一半是 Agent 亲验的**：四条对应关系出自**权利人自己的 MBTI Facts 页原文**（§1.6）

#### 🚨 符号不许照抄 —— 这是实施时的头号坑

用户抄录的 **E/I 一栏带负号**（−0.74 ~ −0.79）。⚠️ **这不足以判断"正号该给 E 还是 I"** —— 符号取决于**原作者把哪一端当正向计分**（很可能他计的是 I 端）。
→ **照抄一个来源不明的负号，会把 E 和 I 整体翻转**（用户测出来是 E，我们显示 I）。

**规则（写死，不许改）**：
1. **只取 `|r|` 当"强度"**
2. **方向一律用 §1.6 权利人确认的四条关系来定**：**外向性高 → 偏 E｜开放性高 → 偏 N｜宜人性高 → 偏 F｜尽责性高 → 偏 J**
3. **落地验证（必做，两次）**：造一份「极高外向性 + 高开放性 + 高宜人性 + 高尽责性」的**假答卷** → 四字母必须是 **ENFJ**；再造一份全低的 → 必须是 **ISTP**。**任一不符 = 符号反了，停下修。**

#### 换算公式

> 单预测变量的**标准化**回归中 `β = r`，所以直接把 `r` 当权重乘上去是标准做法（不是我们自创的）。

```
z(某维倾向) = r × z(该维对应的大五维度分)
z > 0 → 取该维左字母 ｜ z < 0 → 取右字母 ｜ |z| < 阈值 → 标「边界」
```

- **N（神经质）不参与** —— 四个 r 里没有它 → 与 McCrae & Costa 摘要 "**four of the five**" **自洽**（§4.3.0）
- **区间值（0.74~0.79 这类）** → **取中值计分**；**区间宽度 = 文献间的分歧程度**，可作为"边界阈值适度上调"的依据（S–N 区间宽度 0.07，比 E/I 的 0.05 更宽）

#### ⭐ r² 直接给出「边界」标注的量化门槛（**R 值最有价值的地方**）

| 维度 | r² | 含义 → 产品规则 |
|---|---|---|
| **E–I** | .55 ~ .62 | 大五能解释一半以上 → **相对可信，边界少标** |
| **S–N** | .42 ~ .52 | 能解释约一半 → **相对可信，边界少标** |
| **T–F** | **.19** | ⚠️ **八成以上的变异大五解释不了** → **这个字母本来就该更常标「边界」** |
| **J–P** | **.24** | ⚠️ 同上 → **更常标「边界」** |

→ 🔑 **把「节121 · 甲 · 不打分」的保守取向，从"理念"落成了"可计算的规则"**：**不是我们对所有字母一样谦虚，而是按文献证据对各维度"分级谦虚"**。这比"全部标边界"更有说服力，也更有用。

#### 其余设计要点

- **🆕 允许"不是单一类型"**（因 §4.3.0 第 2 条：四维不独立）—— 当多个维度同时落在边界区，**结果页直接说"你的画像介于 X 与 Y 之间"**，**不许硬凑一个四字母**。
- **呈现**：只给字母 + 边界标记（如 `I N T P`，其中 T 标「边界」），**不给每维百分比**。
- **必须同时给的两句**：①"这是**对照参考**，不是测评结果"②"与 The Myers-Briggs Company 的 MBTI® 测评**无关联、未经认证**"（§3.2 脚注）。
- **🔑 为什么仍然要保守**：§4.3.0 第 3 条 —— **不存在"大五→四字母"的公认换算规范，也没有其准确率的同行评议评估**。我们有的只是**一个来源的相关强度**，**不是一套经过验证的换算方法**。「甲 · 不打分」的立场要求我们**不把不确定性伪装成确定性**。
