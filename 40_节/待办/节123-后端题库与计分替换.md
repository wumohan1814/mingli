## 必须遵守的硬规则（**从节122 摘，一条都不许漏**）
- 🔒 **官方中文页与计分键页编号完全不同** → **一律按题面文本匹配，绝不按 `item_no` 匹配**（按题号只有 2/120 对得上）
- 🔒 **符号不许照抄** —— 只取 `|r|` 当强度；方向用权利人确认的四条关系（外向性高→E｜开放性高→N｜宜人性高→F｜尽责性高→J）→ **必做 ENFJ / ISTP 双验**
- 🔒 **r² 分级标"边界"**：E–I .55~.62 / S–N .42~.52 相对可信；**T–F .19 / J–P .24 → 更常标「边界」**
- 🔒 **允许"不是单一类型"**：多维度同时落在边界区时，输出「**介于 X 与 Y 之间**」，**不许硬凑四字母**
- 🔒 **两个方向陷阱**：IPIP-50 第 4 因子官网叫 `Emotional Stability`（`+` = 神经质**低**），Mini-IPIP 第 IV 因子叫 Neuroticism（`+` = 神经质**高**）→ **方向相反，不可统一处理**
- 🔒 **零 DDL**：复用 `mbti_results` 已有的 JSON 列；**确需加列必须先回头找用户**
- 🔒 **不做历史数据兼容**：旧 MBTI 形状的 `scores_json` / `answers_json` 不兼容、不迁移。**本地旧测试数据直接删除**；**线上部署时，若已有用户存在人格测试相关记录（`mbti_results` 行 + `cases.mbti_type`），一律删除，当做该用户从未做过人格测试处理**（2026-09-12 用户裁决：当前无有价值数据，全为测试账号）
- 🔒 **不给人群百分位**（中文"常模"只有 N=131 学生样本）
