## 一、为什么需要这份工单（一句话）

**官方托管的中文只有 120 题这一档；其余档位在 IPIP 官网只有英文。** IPIP 属公有领域、官方原文明确允许 **edit / translate**（`00_根/来源.md` §一），所以**我们自己翻译完全合法**——但**翻译质量直接决定这个量表还成不成立**，所以要有硬规范。

## 三、交付物与格式

**请在**本目录**各 JSON 文件的副本上填写 `text_zh` 字段**，不要改动任何其他字段。

```json
{
  "instrument": "ipip-neo-300",
  "item_no": 1,
  "text_en": "Worry about things.",
  "text_zh": "为很多事情感到担心",     // ← 只填这一项
  "dimension": "N",                   // N/E/O/A/C —— 不要改
  "facet": "n1",                      // 层面 —— 不要改
  "keying": "-",                      // 计分方向 —— 不要改
  "source_url": "https://ipip.ori.org/..."
}
```

- ✅ **只填 `text_zh`**。题号 / 维度 / 层面 / 计分方向 / 英文原文**一律不要动** —— 它们是计分与映射的依据。
- ✅ 若某题你判断**中文语境不适用**（见 §五），**不要删、不要改写语义**，而是：`text_zh` 填你的建议译法，**并在最后单独列一份「需替换题项清单」**（题号 + 理由 + 你的替换建议）交给 Agent 处理。

## 四、翻译规范（硬性要求）

### 4.1 术语一致性（**最重要**）

**所有档位的术语一律以官方 120 题中文版的用词为准** —— 因为同一个产品里，不同档位对同一概念必须叫同一个名字。

**五个维度（已有官方中文用词，直接用）**：

| 维度 | 官方中文 |
|---|---|
| N | **神经质** |
| E | **外向性** |
| O | **开放性** |
| A | **宜人性** |
| C | **尽责性** |

**30 个层面**：⚠️ **官方 120 题中文版已给出其中的中文名**（已实取到的一部分，如 **N1 焦虑 / N2 愤怒 / N3 抑郁 / N4 自我意识 / N5 放纵 / N6 脆弱性 / E1 友好 / E2 合群性 / E3 自信 / E4 活跃度**）。
→ **要求**：**完整层面术语表由 Agent 从官方中文 120 题里提取后补全**（不要自己另起一套叫法）；**在补全之前，请先不要动层面相关的用词**。

### 4.2 句式

- **第一人称自述句**（描述"我"的行为/感受），与官方中文档一致，例：`为很多事情感到担心`、`很容易交到朋友`、`能成功完成任务`
- **句末不加句号**（官方中文档内大部分不加；**统一不加**）
- **不要出现"你"** —— 题干里已有指导语，题项本身一律是"我"
- **长度**：建议 **不超过 14 个汉字**（官方中文档实测多在 4–12 字；过长会撑破移动端一行）
- **保留原意粒度**：一题只说一件事。**不许把两句话合成一句**，也**不许删掉限定词**（例如 `predominantly` / `often` / `easily` 这类程度副词**不能丢**，它们影响与英文版的可比性）

### 4.3 5 点李克特的选项用语（**固定，不许改**）

官方指定：**非常不准确 / 不太不准确 / 适中 / 比较准确 / 非常准确**
官方指导语（**可直接复用，不用自己编**）：
> 接下来的题目是用来描述人们行为的语句。请你使用 1-5 分的打分（1 分为非常不准确，5 分为非常准确），来表明这些语句是否能准确描述你。请按照你当前的实际情况描述自己，而不是你希望自己未来能成为的样子。你应当诚实地描绘自己。你的回答将被绝对保密。

### 4.4 反向题（`keying = "-"`）的特殊要求

**反向题的语义方向不能翻反。** 例：`Am always prepared.`（正向，C 维）与 `Jump into things without thinking.`（反向）—— 后者翻成中文后**必须仍然读起来是"缺乏计划"**，且**不要为了"好看"改成褒义/贬义**。
→ **自检方法**：把译句读一遍，问"这句说的行为是多的好还是少的好？"—— 与英文原句的倾向必须一致。

### 4.5 ⚠️ 两个"方向陷阱"（**翻到这两个量表时务必看**）

**陷阱①：两个量表的"第 4 个因子"方向相反**
- **IPIP-50** 官网原话是 **"Emotional Stability"（情绪稳定性）** → 该表 `keying:"+"` = **情绪稳定性高 = 神经质低**
- **Mini-IPIP-20** 官网第 IV 因子**就叫 Neuroticism** → 该表 `keying:"+"` = **神经质高**
- → **翻这两档时，中文必须让"字面倾向"与各自英文原句一致**，**不要为了对齐而统一改成同一种说法**。⚠️ 我们的代码若把两者当成同一个"N"处理，**会把其中一个算反** —— 所以**译文的倾向必须留在原文倾向那一侧**，由代码层解决方向。

**陷阱②：官方中文页的题面 ≠ 计分键页的题面**
例：官方中文页第 28 题英文是 `View myself as predominantly liberal politically.`，而计分键页 O6 是 `Tend to vote for liberal political candidates.`
→ ⚠️ **所以"官方中文题 → 30 个层面"的映射不能想当然**，Agent 正在做 120 题全量逐题比对。
→ **对你的影响**：你自译的档位，**请严格照该档位"计分键页"的英文题面翻译**（不要照中文页的措辞），否则同一道题的两种中文会打架。

### 4.6 ✅ 翻译母本**已定**：300 题池（用户 2026-09-11 裁决）

实测：**IPIP-NEO-60 的 60 题不在任何一版 120 里**（与 Johnson-120 重合 51/60、与 Maples-120 重合 58/60），但**完全在 300 题池里（60/60）**。
→ **翻译母本取 300 题池**（Goldberg，30 层面 × 10 题）：**能套官方中文的（Johnson-120 那 120 题）直接套**，**其余自译**；⚠️ 快速版 60 题里**那 9 条官方中文不存在的**（`Am easily intimidated.` 等）必须**另行翻译**。
→ ✅ 好处：**翻一次，长短两版通用**。

> 🔒 **另有一条硬规则（§4.5 陷阱②的延伸）**：官方中文页与计分键页**编号完全不同**（按题号对齐只有 2/120 相同，按**题面文本**能对上 117/120）→ **两页之间一律按题面匹配，绝不用题号匹配**。

## 五、文化适配（**本次必须走一遍**）

### 5.1 已知问题题项（**已核实 · 2026-09-11 由 1 条扩为 3 条**）

| # | 官方中文题号 | 英文原文 | 官方中文 | 问题与处置 |
|---|---|---|---|---|
| 1 | **28** | `View myself as predominantly liberal politically.` | 「认为自己在政治方面非常自由开放」 | 🚫 **政治** —— 中文语境语义不对等（`liberal` 无对应词），高度敏感 → **同层面替换** |
| 2 | **88** | `View myself as predominantly conservative politically.` | （同一层面对的配对题） | 🚫 **政治** —— **与第 28 题互为配对**，**必须一起换**，否则 O6 层面只剩相反的半边 |
| 3 | **58** | `Believe that there is no absolute right or wrong.` | （道德相对主义表述） | 🟡 **道德相对主义** —— 比政治题温和，**建议一并复评** |

> ⚠️ **重要**：这 3 题**同属一个层面 `O6`（开放性·价值观）**，而 O6 一共只有 4 题 → **一次性要换掉 2 题（一半）**。
> → **替换必须从 IPIP 300 题池里挑「同层面 O6」的题**，不要随便找一道 O 维的题顶上（会破坏层面结构）。
> → **这正是"文化适配必须逐题走一遍"的实证**：只靠"找敏感词"会漏掉**成对出现的政治题**。

### 5.2 走查时请重点标记这几类

遇到就**标记出来、不要自己拍板**（交由 Agent 与用户决定是否替换）：

- **政治**（政党/意识形态/政治立场）
- **宗教**（信仰、宗教活动）
- **性 / 亲密关系**
- **酒精 / 药物 / 成瘾行为**（如 `Go on binges`）
- **法律 / 违法**（如 `Break rules` 这类）
- **医疗 / 精神健康**（如涉及抑郁、焦虑的临床表述 —— ⚠️ **注意：N 维题项本质就是负面情绪，不能因此全删**，只需评估**表述是否可能被读成医学诊断**）
- **体型 / 外貌评价**
- **特定国家/地区/民族**的具体指涉（如 `Sympathize with the homeless` 这类社会议题题）

> ⚠️ **重要**：**标记 ≠ 删除**。删题会破坏每个层面"4 题/10 题"的计分平衡。**正确做法是"同层面替换"**（从 IPIP 那 3,320 条里选同层面的另一题）。
