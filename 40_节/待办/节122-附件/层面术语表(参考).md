## 说明与待确认项

1. **题项层面对应（facet）**：本目录英文档（`ipip-neo-300.json` / `ipip-neo-60.json`）已带 `facet` 字段；`ipip-50.json` / `mini-ipip-20.json` 无层面（仅维度）。本表供 UI 展示层面标签时统一用词。
2. **命名来源**：IPIP-NEO 国际标准命名的中文通行译法，与上表 §4.1 示例完全吻合，非另起叫法。
3. **待确认**：官方中文 120 题页（`ipip-neo-120-zh.json`）本身不印 facet 字段；若需把「官方中文题面」逐条绑到上表层面，可待 Agent 用 §6.3 的「题面文本匹配」方案（117/120 可确定 + 3 条人工裁定）补全后再行对齐。
4. **O6 价值观层面**：见 `需替换题项清单.md` —— 该层面在 300 题池中政治 / 宗教 / 司法题高度密集，UI 标签可用「价值观」，但题项本身建议按清单处理。
