## 二、形制说明（给代码 session）

- **两态同轮廓**：同一月牙/半月路径（强拱上缘 + 近直下缘 + 圆钝端部），缩放一致、可完全重合；仅内部明暗不同。
- **长轴水平、左右镜像对称**；可视比例约 **2.6 : 1**（含留白的画布 192 × 80，内容 bbox 约 x:7–184, y:5–70，四周透明留白 ≥ 4px @2x）。
- **无自带阴影 / 无光晕 / 无背景 / 无文字 / 无具象宗教形象**——落地阴影按 spec 由代码 CSS 叠加。
- **配色**按 spec §6.1 取值：朱漆 `#B3261E→#C8442E`（高光 `#E0705C`，暗部 `#7E1B16`）；木色 `#A97A3C` 系（脊线高光 `#D4B06A`，暗侧 `#4C2E12`）；描金边 `#B8893E`（约 0.75px @2x，仅遮罩内）。
- 平面态下沿有 **6px @2x 暗色侧壁带**（`#4C2E12` 渐入），保证缩略尺寸下「平 vs 隆」可辨。
