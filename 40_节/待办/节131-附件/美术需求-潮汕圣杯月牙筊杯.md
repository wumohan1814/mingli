## 一、背景：这是什么功能

用户在 App 里选「潮汕圣杯」，心里默念一件事，**掷两枚筊杯**落地，看两块落面组合出一个答复：

| 组合 | 名称 | 含义 |
|---|---|---|
| 一平面 + 一凸面 | **圣杯** | 应允（可以 / 是） |
| 两块都是平面 | **笑杯** | 神明笑而不答，问题不清，需再问 |
| 两块都是凸面 | **阴杯** | 不允（不可以 / 不是） |

这是**潮汕、闽南、台湾一带真实存在的民俗问事方式**，不是游戏化抽奖。演出要「像真的在掷筊」，但**不迷信化、不戏谑**。

**筊杯的现实形制（可作考据依据）**：竹或木削制，**半月形 / 月牙形**（形似一弯新月、腰果），一面是**平整的平面**，一面是**圆隆的凸面**；常见长约 10–12 cm、宽约 3–4 cm、厚约 2 cm（**长 : 宽 ≈ 2.5–3 : 1**）。多为**朱红漆面 + 原木侧面**，也有通体原木或描金边的做法。

> 允许参考真实筊杯照片与庙宇实物图确认形制，但**不得直接描摹、抠图或使用任何他人图片**（版权红线）；最终必须自行绘制原创图形。

## 二、现在是什么样（要改掉的东西）

- 演出是全屏深色舞台（近黑的墨底 + 一点金/紫的暗光），中间横排**两枚 62 × 62 px 的圆形铜钱**。
- 铜钱做的是「硬币式左右翻转」，正面/背面只靠**「平面」「凸面」两个汉字**区分。
- 问题：形制不对（铜钱 ≠ 筊杯），而且**去掉文字就分不出两态**，与「掷筊」的真实观感差得远。

---

## 三、要变成什么样（目标描述）

- 两枚**月牙形筊杯**横排在舞台中央，间距约 26 px（两枚总宽约 218 px，舞台宽度足够）。
- 进入页面后自动演出：两枚杯**先后被抛起、沿长轴翻滚（像翻跟斗，不是像硬币左右翻面）、落地**，先落一枚再落一枚；落定后**各露一面**，组合出三态大字（圣杯 / 笑杯 / 阴杯）。
- 每枚杯落地时的角度会有轻微随机的倾斜与位置差（由代码做），**美术只需画「正向朝上」一张**，不要出多角度。
- 透视：**以俯视正投影为主**（略可按 3/4 微俯，但必须能在 96×40 px 内辨认轮廓）。**不要大透视、不要夸张厚度。**

## 四、交付物清单

### 4.1 必交（2 张）

| # | 文件名 | 内容 | 画布 | 说明 |
|---|---|---|---|---|
| 1 | `shengbei-flat.webp` | **平面朝上**（阳面）：平正面向上，能看到朱漆平面 + 下沿一点侧面厚度 | 192 × 80 px 透明底（另附 288 × 120 @3x 更佳） | 这一态在画面上是「一张红色的、扁的月牙木片的正脸」 |
| 2 | `shengbei-convex.webp` | **凸面朝上**（阴面）：圆隆的背脊向上，看不到平面 | 同上 | 这一态是「一弯木色的月牙背脊」，沿长轴有一条柔和高光 |

**硬要求**
- **两枚杯长相完全一致**（同一件物的两个状态），只是朝上的面不同；两图轮廓必须能完全重合（同一外形，只有内部明暗与颜色不同）。
- **透明底**，杯体四周留 **2 px（@2x 即 4 px）透明留白**，不要贴边裁切。
- 长轴**水平**、居中对称；不要自带阴影、不要自带光晕（落地阴影由代码用 CSS 加）。
- 平面态请**保留一点可读的侧壁厚度暗示**（下沿 4–6 px @2x 的暗色侧面），这样「平」和「隆」在缩略尺寸下才分得开。

### 4.2 选交（1 张，有余力再做）

| # | 文件名 | 内容 | 画布 |
|---|---|---|---|

> 说明：这张**本期不一定接线**（结果页当前仍以文字呈现），属于「先备着、下一轮可能用」。做与不做都不影响本次验收。

## 五、验收：两态必须一眼可辨（最重要的一条）

请按这三项自检，任何一项不过就不合格：

1. **缩略测试**：把两张图缩到 96 × 40 px，放在**近黑深底**上看 —— 能立刻指出哪张是平面、哪张是凸面。
2. **黑白测试**：转成灰度 —— 两态仍有明显**明度差**（平面 = 中间调大色块；凸面 = 中间一条亮脊 + 两侧暗），不能「去色就一样」。
3. **并排测试**：两枚随机并排（一平一凸 / 两平 / 两凸）—— 组合关系一眼看得出来，不需要文字说明。

## 六、视觉风格约束（配色与材质）

整体是「宋代雅致 + 朱漆金线」的中式质感，界面**浅色纸面**与**深色演出舞台**都有，但**只在深色舞台上出现**，所以**优先保证深底可读**。

### 6.1 用色（可直接取用）

| 部位 | 建议色值 | 说明 |
|---|---|---|
| 平面态主色（朱漆） | `#B3261E` → `#C8442E` | 朱砂红漆面；高光约 `#E0705C`，暗部约 `#7E1B16` |
| 凸面态主色（竹木） | `#A97A3C` → `#7A4D22` | 暖褐木本色；脊线高光 `#D4B06A`，暗侧 `#4C2E12` |
| 描金边线（两态共用） | `#B8893E` / `#9C6E2E` | 可选细描边（约 1 px @2x），用于在深底上勾出轮廓 |
| 侧面厚度（平面态下沿） | `#7E1B16` → `#4C2E12` | 让「平」的厚度感可读 |

### 6.2 材质与光

- 材质：**竹木 + 漆**。可以有极淡的木纹（凸面）与漆面细腻的微反光（平面），**不要写实纹理贴图、不要脏旧做旧、不要裂纹掉漆**。
- 光位：光源**左上 45°**（与舞台既有光效一致）；不要环境反射、不要 HDR 复杂高光。
- 风格：**扁平偏矢量 + 柔和渐变**，允许 1–2 层柔和明暗，**不要写实 3D 渲染**。

### 6.3 🚫 红旗（做了必返工）

- 🚫 画成**圆铜钱 / 硬币 / 圆盘 / 贝壳 / 元宝 / 饺子 / 香蕉 / 腰果**（必须是清晰的**月牙/半月木片**）。
- 🚫 图里**写任何字**（不刻「圣」「阴」「阳」「福」「囍」，也不要有符号/花纹刻字）—— 文案由界面渲染，图里带字会无法本地化、且与三态命名冲突。
- 🚫 出现**神明、人脸、眼睛、手势、符咒、庙宇**等具象宗教形象。
- 🚫 **实拍照片质感**、脏污做旧、复杂投影、外发光光晕。
- 🚫 图片**带背景**（必须透明）；带白底或白描边（深底上会出现白圈）。
- 🚫 戏谑化处理（表情、卡通脸、拟人），这是真实民俗，措辞与画风都保持**庄重**。
- 🚫 只靠**颜色**区分两态（见 §五 黑白测试）。

## 七、命名与交付方式

- **文件命名**：全小写 + 连字符，如 `shengbei-flat.webp`（不要空格、中文、版本后缀）。
- **交付三份**：① 运行图 WebP（透明通道）② PNG 母版（300 px 以上长边，留档用）③（如有）SVG 矢量源 + 分层源文件（PSD / AI / Figma 导出）。
- **落库位置**（由代码 session 放置，美术按此命名交付即可）：

```
运行图：frontend/public/art/shengbei/shengbei-flat.webp
        frontend/public/art/shengbei/shengbei-convex.webp
        frontend/public/art/shengbei/shengbei-pair.webp   ← 选交
母版：  _archive/美术-素材原件/art/shengbei/*.png
```

- **代码侧接入方式**（美术无需执行，仅供理解约束）：会新增两个美术令牌 `--art-sb-flat` / `--art-sb-convex` 指向上面两张 WebP，翻转轴由「圆币左右翻」改为「沿长轴翻滚」，所以**必须交正俯视、长轴水平的图**。

## 九、给美术的一句话总结

> 画**两枚一模一样的月牙形木制筊杯**（半月形、长宽比约 2.4:1、透明底、正俯视、长轴水平）：一张是**红漆平面朝上**，一张是**木色凸背朝上**；缩到 96×40 px、放在黑底上、去掉颜色，都要能一眼分出哪面朝上。不要字，不要人脸，不要照片感。
