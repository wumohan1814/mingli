## 3. 黑盒已锁定的算法口径（先照此实现，再逐项复核）

四柱口径与 `src/capabilities/xiaoliuren/index.js` 一致（README §4）。
实测基准样例：2024-06-15 10:30 +08:00 → 甲辰/庚午/庚戌/辛巳，昼占，月将申，占时巳，贵人丑，旬空寅卯。

1. **月将**：同大六壬——按**已交中气**取（雨水后亥、春分后戌、谷雨后酉、小满后申、夏至后未、大暑后午、处暑后巳、
   秋分后辰、霜降后卯、小雪后寅、冬至后丑、大寒后子）。实测 2024-06-15 → 申 ✓。边界（交节精确时刻）必须探针定死。
2. **地分（四种起课方式）**：
   - `time`：地分 = **占时支**；`calculation.inputBase = 地支序数`（子=1…巳=6），`inputBaseSource='占时地支序数'`。
   - `branch`：地分 = `params.branch`；`inputBase = 该支序数`，`inputBaseSource='指定地分'`。
   - `number`：地分 = `((params.number - 1) mod 12) + 1` 对应的支（实测 37 → 1 → 子）；`inputBase = 原数字`，`inputBaseSource='用户数字'`。
     **必须探针覆盖 0 / 负数 / 小数 / 12 的倍数 / 超大数**，与旧实现逐例对齐。
   - `random`：实测 `{method:'random', seed, replay}` 抛错「seed、replay 与自定义随机源只能提供一种。」
     **你要探针找出旧实现可接受的形态**（试 `{method:'random'}`、`{method:'random', seed:12345}`、
     `{method:'random', replay:true}`、`{method:'random', random:<数组或函数>}` 等），并据此决定：
     若用**种子**可复现，就反推其 PRNG（常见的 `mulberry32`/`seedrandom`/LCG 逐一试），做到同 seed 同结果并进夹具；
     若无法在预算内复现，**诚实报告**为未解决差异，并在夹具里**不放** random 条（在 `notes[]` 写明原因）。
3. **将神**：月将加时（月将压在占时支宫上）后，取**地分宫上方**的天盘支，即
   `将神支 = 地分支 + (月将 - 占时支)`（顺行 12 支）。实测：月将申加时巳，地分巳→将神申、地分午→酉、地分子→卯 ✓。
   将神**遁干** = 五子元遁（见 §3.5）。
4. **贵神**：昼夜贵人起例（同大六壬十干昼夜贵人表）+ **排至地分**：
   `贵神 = 十二贵神[(地分支 - 贵人支) mod 12]`，顺序（顺）：贵人→螣蛇→朱雀→六合→勾陈→青龙→天空→白虎→太常→玄武→太阴→天后。
   实测：庚日昼占贵人丑，地分巳 → (巳6-丑2)=4 → 勾陈 ✓；地分午 → 5 → 青龙 ✓；地分子 → (子1-丑2) mod 12 = 11 → 天后 ✓。
   `noblemanDirection` 实测为 `顺布`（**昼夜是否都顺布、还是夜占逆布，必须探针覆盖 10 日干 × 昼/夜 20 例**）。
   贵神**本属干支**（写死进 rules）：贵人己丑、螣蛇乙巳?、朱雀丙午、六合乙卯、勾陈戊辰、青龙甲寅、天空戊戌、
   白虎庚申、太常己未、玄武壬子、太阴辛酉、天后癸亥 —— **以探针实测（`calculation.guiShenRule` 里会写出「贵神本属X支Y」）为准逐条核对**。
5. **五子元遁**：日干定子时干（甲己→甲子、乙庚→丙子、丙辛→戊子、丁壬→庚子、戊癸→壬子），顺推 12 支。
   **人元** = 遁至地分支之干（实测庚日地分巳 → 辛 ✓）；**神干** = 遁至贵神支；**将干** = 遁至将神支；
   `positions.*.stem` 就是这些遁干，`stemElement` 是遁干五行。
6. **五行归属（`element` + `elementBasis`）**：地分 `按地分支`；将神 `按月将支`；贵神 `按贵神本属`；人元 `按人元干`。
   实测：贵神勾陈（本属辰土）→ element 土 且 elementBasis `贵神本属` ✓。
7. **阴阳（`yinYang`）**：地支阴阳（子阳、丑阴、寅阳…）/ 天干阴阳，按各位置的取法逐项对齐实测。
8. **月令旺衰（`seasonState`）**：与月支五行的关系（旺/相/休/囚/死），逐例对齐（**不要照抄本说明的生克方向，用探针校准**）。
   实测基准：月支午（火），火→旺、土→相、木→休、水→囚、金→死（这是实测样例的取值，据此反推即可）。
9. **`isVoid`**：该位**地支**是否落日柱旬空（实测庚戌日 → 旬空寅卯）→ 落入则 true，且 `constraints` 追加 `落日旬空`。
   `support`/`constraints` 内容实测为 `月令旺`/`月令相`/`月令休`/`月令囚`/`月令死`/`落日旬空`（顺序按实测）。
10. **阴阳发用（`yinYangUse`）**：统计四位（地分/将神/贵神/人元）的阴阳计数 →
    `pattern`（二阴二阳 / 三阳一阴 / 三阴一阳 / 纯阳? / 纯阴?）与 `usePosition`。
    实测：二阴二阳 → 将神为用；三阳一阴 → 以唯一阴位为用（该例唯一阴位是将神）。**全部组合必须探针穷举定死**（含纯阳/纯阴的取用规则）。
    `isVoid` = 用位是否旬空。
11. **五动 / 三动（`movements`）**：实测已见 `鬼动（地分克人元）`、`妻动（人元克地分）`、`财动（将神克贵神）`、`官动（贵神克人元）`。
    **五动的第 5 个、以及「三动」的全部名称与触发条件必须探针穷举**（建议按 四位五行组合穷举 5^4=625 种或按实际干支组合大规模抽样，
    收集 `movements[].name/from/to/relation` 的取值集合与触发条件），**顺序按实测**（同一次课多个动爻的排列次序也要对齐）。
    `trigger` 是「{from}{元素}克{to}{元素}」形式的结构化短句（如 `地分火克人元金`），`source` 是固定出处句
    （实测 `《六壬神课金口诀古本》“五动爻诵”`，三动的 source 以实测为准）。
12. **`bihePoem`**：由四位五行组合决定的歌诀（实测量：`二金为刑，互见争斗刑伤折损`、`四位五行周流，无极偏比合之患`）。
    必须穷举四位五行组合与旧实现对照，把表写死进 rules（**属文案→进关键字段？见 §5 的裁定：进关键字段**，
    因为它由五行组合确定性决定、且是短句标识；若穷举后仍对不齐，按 §5 降级条款处理并诚实报告）。
13. **`calculation.*`**：11 键的结构字段（`inputBase`、`inputBaseSource`、`noblemanDirection`）进关键字段；
    其余是「口径句 + 数值」拼接文本，**也进关键字段**——它们的模板要逐条反推（探针打印多个样例比对格式即可），
    例：`时间起课以占时巳为地分`、`数字起课以37归一为1，对应地分子`、`顺布至地分得勾陈，贵神本属戊辰土`、
    `昼占贵人起丑，从贵人起十二贵神排至地分巳`。

## 4. 参数契约与入口

```
generateJinkoujueCore(params)   // params = { method, customDate?, branch?, number?, seed?, replay?, random?, now? }
```
- 夹具 `input` = `{params:{...}}`；登记表 `toLegacyInput`/`toCoreInput` 都把 `params` 原样或按位置传（已接线）。
- `time`/`branch`/`number` 都需要**四柱**，故都要求 `customDate`（**探针确认旧实现缺 `customDate` 时是否回落当前时间**；
  若是回落，本内核一律抛 `PaipanInputError`，并在夹具 notes 里登记为有意分歧）。
- `customDate` 接受 `Date | ISO 字符串 | epoch 毫秒`。缺必填输入抛 `PaipanInputError`，绝不猜测。
- 输出形状 = 旧实现 stripInternal 后的形状；`meta = {engineVersion:'0.1.0-mingli', schemaVersion:'1.0.0', algorithm:'jinkoujue', calculatedAt, inputHash, resultId}`。
- 四段管线：① `normalizeInput`（起课方式归一 + 地分求解）② `resolveCalendar`（四柱 + 月将 + 昼夜 + 贵人）
  ③ 判定层分段函数（`buildPositions` 四位 / `computeRelations` / `resolveYinYangUse` 发用 / `computeMovements` 五动三动 / `computeBihePoem`）
  ④ `assemble`。**必须分函数**：构局、贵神将神装配、发用判定、动爻判定、命名各自独立（索引小错会放大成全链路错配）。
