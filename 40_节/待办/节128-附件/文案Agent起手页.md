# 四、四步起手（**做完第 3 步就交付，不要等 46 条**）

### 第 1 步 · 立「术语总表」的**最小版**
- **产出**：`文案交付/术语总表.md`
- **范围**：⚠️ **只覆盖这一路** —— 四柱 / 十神 / 五行 / 干支 / 神煞 / 大运 / 流年 / 十二宫 / 星曜 / **真太阳时 / 均时差 / 夏令时** …→ **约 30–50 条**，**不要一次做 500 条**
- **格式**：`术语名 ｜ 别名/拼音 ｜ 一句话大白话定义 ｜ 涉及哪些法`
- ⚠️ **纪律**：**术语的"名字"是公有领域，但"解释文字"必须自己写**
- 末尾标注：**「本版只覆盖八字/紫微这一路，后续按需扩」**

### 第 2 步 · 采**公网古籍的"最小集"**
- **产出**：`文案交付/古籍来源清单.md` + `文案交付/C-术语与数据表/classic-*.json`
- **范围**：⚠️ **只采这一路要用的**（如 滴天髓 / 穷通宝典 / 子平真诠 / 紫微相关古籍 / 干支历法类）
- **每条必记**：**书名 / 篇名 / 来源 URL / 采集日期**
- ⚠️ **三类区分**（任务书纪律 3）：古籍原文 ✅ 可采｜**现代白话转写** 🚫 不采（自己写）｜**现代整理的结构化表** 🚫 不抄表（从古籍自己整理）

### 第 3 步 · 写**这一路**的文案（**先 6 条通用件，再 8 条专属**）
| 顺序 | 条目 | 主题 |
|---|---|---|
| 1 | **A16 / A14 / A17 / A18** | 小的通用件先做（2+3+1+2 KB） |
| 2 | **A13** | ⭐ **禁巴纳姆表达层**（26 KB，通用件里最重） |
| 3 | **A12** | 引导与行动建议（15 KB，⚠️ 守甲·不打分） |
| 4 | **A1 / A2 / A3** | 八字：主框架 / 流派说明 / 运势框架（7+16+3 KB） |

| 7 | **C1 子集 / C2 / C3** | 术语词典（**只做这一路的子集**）/ 神煞表 / 干支五行十神表 |

- **格式**：按任务书 **§6.2**（每条一个 JSON，含 `basis` 依据 + `meta.self_check`）
- 📌 共约 **14–16 条**（不是 46 条）

### 第 4 步 · **交付并等验收**
- **交付时写一份** `文案交付/第1期-交付说明.md`：做了什么 / 没做什么 / 依据是什么 / 自检结果 / 自己觉得哪里还不确定
- ⭐ **然后停下等父 Agent 与用户验收** —— **不要自己往下铺开**
- 验收看的是：**质量够不够、成本（时间/token）大概多少、有没有走偏**
