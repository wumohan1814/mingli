## 三、注入纪律（后续各法照此，防 prompt 膨胀）

1. **只注入底座新增价值**：voice（A16）、分歧并列（A2）、术语表口径（C1/C2）、证据层口径（B11）——base.py 已有（反巴纳姆/L1–L5/收敛/置信度）一律不重复。
2. **契约段原样保留**：输入字段 / 硬护栏 / 断前尘 / 预测 / 输出格式 / 话术红线，只增不删不改字段引用。
3. **体量控制**：注入段用精简版（3–6 条/段），整文件控制在 ≤5KB 字符量级（当前四法 3.4–4.4K 字符，未膨胀）。
4. **单一事实源**：生产运行时 = `method-prompts/*.md`（admin 热改/回滚照常作用于它）；文案底座 = 文案 copy 的来源。**改 copy 走底座 → 按本表重做映射 → 更新 .md**；改契约直接改 .md（记录到本文件）。
