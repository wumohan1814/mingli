# D1 · 自研版命理解读能力说明

> 本文对标原 `packages/core/README.md` 的定位，但为**自研重写**，不含原 AGPL 文本。说明「太初」命理解读能力能做什么、不能做什么、口径如何统一。

## 1. 能力范围

| 模块 | 能力 | 底层依据 |
|---|---|---|
| 八字 | 四柱排盘、十神、大运流年趋势解读 | A1/A2/A3 + B11 + C1/C3 |
| 紫微 | 十二宫与星曜、四化趋势解读 | A4/A5 + B12 + C1 |
| 星盘 | 本命/推运/合盘意象解读 | A6 + B2 + C1 |
| 塔罗 | 牌阵解读（正逆位＋位置融合） | A10 + B9 + C5 |
| 雷诺曼 | 抽牌＋位置＋组合解读 | C6 + B10 |
| 六爻/梅花/奇门/六壬/金口诀/小六壬/灵签 | 断卦框架与证据层 | A7/A20 + B3–B8/B10 + C4/C7/C9/C10 |

## 2. 统一口径（节121 · 甲·不打分）

- 不输出吉凶总分、百分比、匹配度、契合度数字。
- 输出定位为「趋势参考 / 自我觉察」，非定论、非预测。
- 不替医疗、投资、婚恋、司法、人身安全等重大决定下结论。
- 应期只给阶段（季/年/运），不给具体日期。
- 所有解读末行附免责（见 D4）。

## 3. 提示词装配

一次解读由「通用前置(A16/A18) + 方法主框架(A1–A6/A10/A7/A20) + 证据层(B) + 数据表(C) + 表达层(A13/A12) + 场景(A15/A11) + 装配(A17/A19)」按 `A19` 流水线组装。高风险问事插 `A9` 安全路径。

## 4. 数据来源纪律

- 术语名、卦名、签诗、星名等属公有领域传统文化，可采集/自建。
- 现代白话解签、现代规则表一律自写，不抄 AGPL 仓库。
- 古籍原文从公网公有领域（维基文库/中国哲学书电子化计划）采集，来源链登记（见 `古籍来源清单.md`）。

## 5. 不在范围内

- 第三方星历（caelus 等 vendor）、地名树、算法实现代码 —— 由工程线自理。
- 界面/样式文案（见 D2）。
