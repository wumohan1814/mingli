# D3 · 错误 / 降级提示

> 对标原 `providers.md` 的降级原则（借思路，不抄文本）。给出命理解读服务的错误码与降级文案，**不恐吓、不伪装确定性**。

## 1. 错误码与文案

| 码 | 场景 | 给用户的话（不越界） |
|---|---|---|
| E001 | 输入缺失（生辰/问事不全） | 「还差一点信息：请补充〔字段〕，我才能生成趋势参考」 |
| E002 | 生辰越界/格式错 | 「这个日期看起来不太对，请核对后重试」 |
| E003 | 排盘引擎不可用 | 「排盘服务暂时歇口气，稍后再来」 |
| E004 | 模型超时 | 「这次生成超时了，可以换个问法或稍后再试」 |
| E005 | 问事触高风险类别 | 「这类问题我作不了定论，建议咨询持证专业人士（医疗/法律/财务）」 |
| E006 | 数据源缺失（如签诗未采） | 「这路的签诗数据还在补全中，暂不能解，换个方法试试？」 |
| E007 | 速率限制 | 「你问得太勤啦，歇一会儿再来」 |

## 2. 降级原则

- **不假装成功**：排盘/模型失败就如实说，不返回空泛吉签。
- **不恐吓**：错误文案中性、温和，不写「今日不宜」「犯冲大凶」。
- **给出路**：每条错误都附可操作下一步（补信息/换方法/稍后）。
- **口径统一**：降级文案也不出现评分数字；末行仍可附 D4 免责。

## 3. 日志（不面向用户）

内部记录错误码＋方法＋时间戳，供工程线排查；不得把内部报错原文直接暴露给用户。
