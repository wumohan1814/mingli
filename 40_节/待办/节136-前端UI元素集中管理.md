## 集中方法（六层单一来源 · 红线）

| 层 | 唯一来源位置 | 收口禁止 |
|---|---|---|
| 设计令牌 | `css/tokens.css` | 硬编码色值/间距/阴影 |
| 皮肤（6 主题） | `tokens.css` 的 `[data-skin]` | JS/视图复刻主色 |
| 文案 | `data/ui-copy.js`（`TC_COPY.ui`） | `toast('中文')` / 内联中文 / 自建词典 |
| 通用组件 | `js/components.js` | 手写 `modal-mask` / 自建弹窗 |
| 图标美术 | `--art-*` + `Icon` | 内联 SVG / emoji |
| 数据 | `data/pairs.js` / `term-cards.js` | 视图内复刻映射 |

## 分阶段执行（每阶段 = 一节，不混塞）

- **阶段 A · 令牌补全**（零视觉变化，先打底座）：`tokens.css` 补 `--space-*` / `--shadow-*`；在 `frontend/scripts/precompile.js` 追加「禁止新增硬编码色值」grep 门禁。
- **阶段 B · 色值回收**（清 P1）：`pages.css` / `components.css` / `admin.html` 硬编码色 → `tokens.css`（复用已有或新增语义 token，如 `--metal-gold-*`、`--tarot-suit-*`）。
- **阶段 C · 文案回收**（清 P2，与 节105 REQ-128 协同）：44–46 处 toast / 整屏内联 / `components.js` 小词典 → `ui-copy.js`；`admin.html` UI_LABELS → 后台文案中心或共享 `ui-copy.js`。
- **阶段 D · 一致性归一**（清 P3）：花色映射三处合一；JS 复刻主色 → `--skin-*`；内联 SVG / emoji → `Icon` 或 `--art-*`；`SkinSwitcher` 补全 6 skin 并解除 `display:none`。
