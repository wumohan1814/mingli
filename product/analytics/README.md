# analytics/ — 度量与单位经济

## 第一优先级：单位经济

《太初产品规划》§6.3：先自建闭环、自行跑 10 次，量出单次 token 成本，定价才有底。
R9 把该闸门前置到开发期，与开发并行。

### self-run 10× 记录要求

| 指标 | 口径 |
|---|---|
| 单 case 首跑全盘成本 | **断前尘 phase + 预测 phase 的 LLM 总成本**（¥） |
| 缓存后边际成本 | 命中缓存后的单次追问成本（¥） |
| LLM 调用次数 | 分析 + 校验分别计数（见待决 ADR-01） |
| 端到端耗时 | 断前尘串行总耗时（决定是否需异步化，见待决 ADR-04） |

起步阈值建议 ¥0.3–0.5/case，**必须实测校准后回填**（owner：用户）。
