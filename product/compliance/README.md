# compliance/ — 合规红线

产品的生死线。任何对外文案与模型输出都不得越过此目录定义的边界。

## 已确定的红线（源自《太初产品规划》§3 / §4）

- **内容定性**：命理文化 / 国学运势 / 事业运势分析，避免"算命"二字。
- **禁区**：不涉医疗、投资、司法预测。
- **不承诺"准"**：采用"趋势 / 参考"话术，不输出确定结论。
- **不主打"AI 新颖"**：命理信任来自神秘感 / 权威感 / 被懂，AI 标签是减分项。
- **末行免责**（固定）：命理仅供参考，不替代医疗、法律、投资等专业意见。
- **支付**：合规由持牌内容平台承担，项目方仅为内容方；MVP 不接支付。
