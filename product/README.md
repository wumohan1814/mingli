# product/ — 产品层

> 需求、合规、度量与素材。这一层是**为什么做**与**做到什么程度**的唯一来源，工程实现不得与之冲突。

| 子目录 | 内容 |
|---|---|
| `prd/` | 需求文档：MVP / Phase2 功能范围、用户流程、验收标准 |
| `compliance/` | 合规红线：话术规范、禁区词表、免责模板、占卜门控规则 |
| `analytics/` | 度量：埋点方案、单位经济实测（self-run 10×）记录、留存与复购 |
| `assets/` | 落地页文案、投放素材、图例与图标源文件 |

## 与工程的关系

1. `compliance/` 中的禁区词表与话术规范是**后端合规护栏的输入**，改词表需同步护栏实现。
2. `analytics/` 的单位经济实测结论直接决定 `TAICHU_COST_GATE_MODE` 档位与后续定价。
3. `prd/` 的验收标准需可映射到 `backend/tests/` 的用例。
