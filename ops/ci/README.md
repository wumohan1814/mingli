# ci/ — 持续集成

## 流水线阶段（建议）

1. **lint**：Python（ruff）、TypeScript（ESLint / Prettier）
2. **test**：后端单测 + 集成（**含多用户隔离否定用例**）、前端单测
3. **build**：前端产物 + 后端镜像
4. **publish**：推送镜像到部署节点

## 门禁

- 合规护栏回归用例失败 → 阻断发布（合规是生死线）。
- 多用户隔离否定用例失败 → 阻断发布。
- LLM token 计量用例失败 → 阻断（成本闸门数据源不可信）。
