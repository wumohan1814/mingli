# monitoring/ — 监控与告警

## MVP 必监控

| 指标 | 用途 |
|---|---|
| 单 case LLM token 成本（按方法模块） | **R9 成本闸门的唯一数据源**，超阈告警 |
| 接口错误率与 P95 延迟 | 断前尘长任务需单独看 P95 |
| 登录失败 / 锁定计数、注册量 | 防爆破与机器注册（R10） |
| 降级方法占比（`degraded_methods`） | 依赖缺失或经纬度缺失的规模 |
| 合规护栏拦截次数 | 护栏是否频繁触发，提示 prompt 需调整 |
