# ops/ — 运维与部署

| 子目录 | 内容 |
|---|---|
| `docker/` | 容器化：Dockerfile（Python 3.13 + Node 22）、compose、镜像构建说明 |
| `ci/` | CI 流水线：lint、测试、构建、镜像发布 |
| `env/` | 环境变量样例（`.env.example` 为唯一来源） |
| `scripts/` | 运维脚本：备份、回滚、数据订正、忘记密码人工处理 |
| `monitoring/` | 监控与告警：健康检查、token 成本看板、错误率 |

## 部署目标

香港 / 新加坡轻量云节点（免 ICP 备案、离岸管辖较宽松、国内访问延迟低）；H5 静态资源走 CDN；
MVP 单进程单实例，DB 同节点托管。

## 硬约束

1. 镜像必须同时包含 **Python 3.13 与 Node 22**（排盘引擎依赖）。
2. 环境变量只允许 `.env.example` 入库；密钥走部署平台的密钥管理。
3. 每次发布前对照 `docs/standards/04-环境与部署说明.md` §6 上线检查清单。
4. 备份与回滚脚本必须可实际执行并定期演练——无主体阶段一封归零的成本极高（产品规划 §4.4）。
