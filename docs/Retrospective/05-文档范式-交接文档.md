# 文档范式 · 交接文档

> 定位：跨 session 的**唯一记忆载体**。会话上下文不跨 session，只有落盘可传。
> 规则：**每 session 结束更新"状态快照 + 待办(带 owner) + 勿回滚护栏"；新 session 先读交接再动手。**

## 1. 规则

1. **唯一黑板**：交接文档是"当前状态快照"，此前所有 session 内容已完成交接，之后从本 session 分叉继续。
2. **三类必填**：①状态快照（当前阶段 / 进度 / 已完成）②待办（带 owner）③勿回滚护栏（运维注意事项单列一节）。
3. **每轮追加**：每个 session 收尾在"轮次记录"追加一段"本轮做了什么 + 待对方做什么"。
4. **权威清单**：交接时给"权威清单"（权威运行件 / 权威文档），并逐项核对文件 / commit 存在性；发现冲突当场标"以 X 为准"。
5. **归档**：过时文档移入归档目录并附说明，不直接删除。

## 3. 填写要点

- **状态快照要能"无上下文续做"**：下一个 session 只读这一份就能知道现在到哪、下一步做什么。
- **待办必须标 owner**：只说"待做"没用，要写清谁做（开发 / 测试 / 用户 / 需求管理员）。
- **护栏单独一节**：把"改回去就会坏"的运维配置、环境约束、禁手单独列，防止后人回滚踩坑。
- **轮次记录是审计账本**：每轮"做了什么 + 待对方做什么"，是协作可追溯性的来源。
