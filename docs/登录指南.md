# 太初 · 登录指南（面向产品 / 运营）

> 适用读者：不写代码的产品负责人与运营人员。本文只讲「怎么登录、登录后能做什么、出问题怎么办」。
> 本文不包含任何真实密码、API Key 或密钥信息。

太初目前有 **两个相互独立的入口**，账号体系不互通、别搞混：

| 入口 | 地址 | 给谁用 | 账号从哪来 |
|---|---|---|---|
| 前端（C 端，用户站） | https://taichu.xyz | 普通用户 | 用户自己在网站上注册 |
| 后台（管理端） | https://taichu.xyz/admin.html | 你（运营 / 管理员） | 开发者在后台账号体系里开通 |

> 本地 / 测试环境：前端为 `http://localhost:8000`，后台为 `http://localhost:8000/admin.html`。

---

## 一、前端（C 端）：注册与登录

### 1. 注册新账号（首次使用）

打开 https://taichu.xyz，按下面步骤操作：

1. **切到注册**：页面默认停在「登录」，点下方的 **「没有账号？去注册」**。
2. **填用户名**：长度需在 3–64 位之间。用户名就是以后登录用的账号，请记牢（注册不填手机号或邮箱，**没有找回通道**）。
3. **设密码**：至少 6 位（最长 128 位）。
4. **确认密码**：把上一步的密码再输一遍，**两次必须完全一致**，否则提交会被拦住。
5. **填图形验证码**：输入图片上的 4 位字母 / 数字。**看不清就点一下图片，会换一张新的**（页面下方也有「看不清？点击图片刷新」提示）。
6. **勾选协议**：勾上「我已阅读并同意《用户协议》和《隐私政策》」（协议文字可点开阅读）。不勾选无法注册。
7. 点 **「注册」**。

注册成功会**自动登录**并跳进「档案列表」，同时页面提示赠送积分到账：

- **注册即送 220 积分**（1 积分 ≈ 1000 token，220 积分约 22 万 token）。
- 参考口径：约可支持 **9 次断前尘「首跑」+ 3 次追问**（每次实际消耗随生成内容长短浮动）。

**注册注意事项**
- 用户名不能重复：已被占用的用户名会提示「用户名已存在」，换一个即可。
- 验证码 5 分钟内有效、**只能用一次**；输错或超时会提示「验证码错误或已过期」，此时会**自动换一张新图**，重新输入即可（字母不区分大小写）。
- 密码系统只存加密摘要，任何人都看不到明文——所以务必自己保管好。

### 2. 登录（老用户）

1. 打开 https://taichu.xyz，填 **用户名 + 密码**，点「登录」。
2. 登录成功后进入 **「档案列表」** 页面，你可以：
   - 点 **「+ 新建档案」**，开始一份新档案的推演；
   - 点已有档案，**继续**查看 / 追问之前的内容。

**登录注意事项**
- 连续输错密码 **5 次**，该用户名会被临时锁定 **15 分钟**（页面会提示剩余时间），等一会儿再试，或联系管理员处理。
- 登录状态会保存在当前浏览器里：**已登录的用户再次打开网站，会直接进入档案列表**，不会再问密码。想换账号时，在页面点 **「退出登录」** 再重新登录即可。
- 退出登录入口在推演 / 档案相关页面的操作区（「退出登录」文字按钮）。

## 二、后台（管理端）：登录与使用

### 1. 登录后台

1. 打开 **https://taichu.xyz/admin.html**。
2. 输入后台账号与密码，点登录。
   - 目前默认账号：`admin`。
   - 密码：**由管理员自行掌握，本文不展示任何明文密码**。
3. 登录成功后，页面右上角会显示**当前角色**。

**后台账号与 C 端用户账号互不相通**，用户在前端注册的账号不能登录后台。

### 2. 后台角色与权限

后台分三个角色，按权限从高到低：

| 角色 | 中文说明 | 能做什么 |
|---|---|---|
| `admin` | 超级管理员 | **全部功能**：报表、用户档案、提示词管理，以及积分分发、换 key、重置密码 / 重置档案等全部运维动作 |
| `operator` | 运维 | 运维操作：**手动分发积分、更换 LLM key、重置用户密码、重置用户档案**；**不含提示词编辑** |
| `viewer` | 只读 | **只读报表**：查看报表与用户档案，不能做任何修改 / 写操作 |

> 说明：以上是产品定义的权限口径。实际开通账号、分配角色、调整权限由开发者负责——需要新增运营账号时，向开发者申请即可（在后台账号体系中配置角色）。

### 3. 登录后主要功能一览

后台左侧有三大菜单（默认落在「报表」页）：

**① 报表（运营看数）**
- **概览**：每天的业务请求量、活跃用户数（DAU）、新注册数——看整体盘子。
- **漏斗**：用户转化链路「注册 → 建档 → 排盘 → 断前尘完成 → 校准提交 → 预测完成」每一步的人数——**看用户在哪里流失**。
- **LLM 成本**：每天大模型调用次数与 token 消耗——看钱花在哪、成本控制。
- **错误**：错误事件数与服务器端 5xx 错误数——系统是否稳定、有没有用户受影响。
- 报表默认展示近 7 天，可按需切换时间范围（1–90 天），MVP 阶段以表格形式展示原始数据。

**② 用户（查个案、处理投诉）**
- 按用户名搜索 C 端用户 → 查看该用户的所有档案列表 → 点开任意档案看完整内容（建档信息与状态）。
- 用于客服场景：用户反馈解读有问题时，运营据此定位是哪份档案、哪个环节。

**③ 提示词（调整解读风格）**
- 查看 / 编辑 9 个流派的方法提示词（八字 ×4、紫微、西占、七政、奇门、五运六气）。
- **保存后立即对新的推演请求生效**。此项需编辑权限（按上文角色口径，仅 `admin`）。

**运维与积分（能力说明）**
后台还具备以下**高危写能力**，供运营 / 管理员按权限使用（只读账号不可见 / 不可执行），系统会记录操作审计：
- **积分手动分发**：给指定用户补发 / 调整积分（如补偿、活动赠送）。
- **换 LLM key**：更换大模型 API Key（改后需重启后端才生效）。
- **重置用户密码**：C 端用户忘记密码时，重置后把新密码线下告知用户。
- **重置用户档案**：把某份档案的推演结果清空、回到待推演状态（用户与积分保留），用于结果异常时让用户重跑。
- 提示：这些动作的**页面入口以系统当前版本实际展示为准**；当前版本如未见对应按钮，可直接联系开发者代为执行。

## 三、常见问题（FAQ）

**Q1：注册时验证码看不清 / 提示「验证码错误或已过期」？**
点验证码图片刷新换一张；验证码仅 5 分钟内有效且只能用一次，输错会自动换图重输。若始终加载不出图片，请检查网络后刷新页面重试。

**Q2：登录提示「用户名或密码错误」？**
先确认用户名有没有注册过、密码有没有输错（注意大小写与多余空格）。连续输错 5 次会被锁定 15 分钟，页面会提示剩余时间。

**Q3：密码忘了怎么办？**
- **C 端用户**：注册只留了用户名 + 密码，**没有自助找回 / 自助改密**。请引导用户联系运营，由管理员在后台执行「重置用户密码」，再告知临时密码。
- **后台账号**（如 `admin`）：无法自助找回，**请联系开发者重置**（需在服务器端操作）。

**Q4：提示「积分不足」？**
断前尘、预测、追问都会按 token 消耗积分。档案 / 解读相关页面顶部会显示当前积分余额，点进去可看积分明细。**目前线上自助充值暂未开放**，余额不足时请用户联系运营，由管理员在后台手动赠送 / 补充积分。

**Q5：打开网站没让我登录，直接进了档案列表？**
说明上次登录状态还在（浏览器记住了）。点页面上的「退出登录」，之后就会回到登录页，可以换账号。

**Q6：后台登录后只有「报表」，看不到其他菜单？**
你的账号是 `viewer`（只读）角色。需要更多权限（如提示词编辑、运维操作）时，让开发者调整角色或另开更高权限账号。

**Q7：网站或后台打不开？**
先确认地址是否正确：前端 https://taichu.xyz，后台 https://taichu.xyz/admin.html；再检查是否断网 / 换了网络。仍打不开请联系开发者排查服务器状态。

**Q8：后台账号安全上要注意什么？**
后台密码请勿与任何 C 端注册密码相同；只通过上面给出的官方地址登录，谨防仿冒站点；不要在群聊、文档里明文传播后台密码或 API Key。
