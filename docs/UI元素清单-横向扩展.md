> 用途：供 UI / 前端 / 美术独立使用。对应后端实现见 `docs/架构设计-横向扩展.md`。

## 1. 首页导航（左侧竖排按钮栏）

> 取代原浮动胶囊方案。首页 = 左侧 3 个互斥按钮 + 主内容区。

### 1.1 布局与形态
- **位置**：页面**左侧垂直排列 3 个互斥选择按钮**，从上到下依次为 ① 国学预测 · ② 西式占卜 · ③ MBTI 人格测试。
- **形状**：按钮**左侧贴合页面边界**（`left: 0`，无左边距、无左圆角），**右侧圆角**（`border-radius: 0 12px 12px 0` 级别），形似「附着在左边缘的竖向标签条」。
- **宽度/高度**：竖条按钮，宽度约 56–64px（仅容竖排文字 + 图标），高度约 96–120px；三个按钮之间留 8–12px 间距。

### 1.2 交互（三态）
| 状态 | 视觉 |
|---|---|
| 默认（未选中） | 贴边平铺，无位移、无强阴影；底色为该模块 accent 的**低饱和/暗化**版本（示意，最终以设计稿为准） |
| 悬停（未选中） | 轻微右移 2–4px 提示可点 |
| **选中** | **向外凸起浮起**：整体向右位移（`translateX(+8~12px)`）+ 投影（`box-shadow: 4px 4px 16px rgba(0,0,0,.28)`）+ 底色提亮为该模块 accent 全饱和度；形成「从左侧墙面上浮起」的立体感 |

- **互斥**：三个按钮**单选**，任意时刻仅一个处于「选中」态，其余回到「默认贴边」态。
- **联动**：点击按钮即选中，并**同步切换页面全局背景颜色**（更新 `<html data-skin>` / CSS 变量）：
  1. ① 国学预测 → 玉青 `#3E7C6B`
  2. ② 西式占卜 → 紫晶 `#5B4B8A`
  3. ③ MBTI 人格测试 → 靛蓝 `#4A5BB5`

### 1.3 主内容区联动
- 点选按钮后，右侧主内容区渲染对应模块的首页内容：
  - ① 国学预测 → 国学 HUB 页（§2.1）
  - ② 西式占卜 → 西式占卜 HUB 页（§2.2）
  - ③ MBTI 人格测试 → MBTI 模块页（§7）
- 三个入口的登录要求不变（国学/西式需登录；MBTI 可直接进入答题，保存结果时需登录）。

### 1.4 实现提示（前端）
```css
.nav-rail { position: fixed; left: 0; top: 50%; transform: translateY(-50%);
            display: flex; flex-direction: column; gap: 10px; z-index: 40; }
.nav-rail button {
  border: none; border-radius: 0 14px 14px 0; /* 左贴边、右圆角 */
  width: 58px; padding: 16px 6px;
  transition: transform .18s ease, box-shadow .18s ease, background .18s ease;
  writing-mode: vertical-rl; /* 竖排文字 */
}
.nav-rail button.active {
  transform: translateX(10px); /* 向外凸起浮起 */
  box-shadow: 5px 4px 18px rgba(0,0,0,.30);
}
```
- 皮肤切换沿用现有 `data-skin` 机制：`document.documentElement.dataset.skin = 'guoxue' | 'xishi' | 'mbti'`，全局背景色由 `--skin-accent` 驱动。

## 4. 临时起卦页（按方法）

### 4.1 通用流程
选择已有档案（case 选择器）→ 选起卦方式 →（按需收集 seed）→ 起卦 → 卦象/课式/签文结果页。

| UI 元素 | 说明 |
|---|---|
| 档案选择器 | 现有「档案列表」卡片复用，选中即 `case_id` |
| 起卦方式宫格 | 7 宫格（六爻/梅花/小六壬/大六壬/金口诀/奇门/灵签），MVP 前 4 个可用，其余置灰「敬请期待」 |
| seed 输入 | 六爻=报数/摇卦；梅花=报数；小六壬=当前时间（只读展示） |
| 起卦按钮 | 主按钮，触发后骨架屏 → 结果 |

### 4.2 各方法结果视觉
| 方法 | 核心视觉 | 数据（示意） |
|---|---|---|
| 六爻 | 6 行爻线（初爻→上爻），老阴/老阳/少阴/少阳用不同符号 + 变卦 | `generateLiuyao` 的爻象/动爻/卦名 |
| 梅花 | 上卦/下卦 + 动爻 + 体用生克 | `generateMeihua` 的卦象/体用 |
| 小六壬 | 六掌诀圆盘（大安/留连/速喜/赤口/小吉/空亡），落点高亮 | `generateXiaoliuren` 的掌诀位置 |
| 大六壬 | 天地盘 + 四课三传 | `generateLiuren` 课式 |
| 金口诀 | 课体四柱（人元/贵神/将神/地分） | `generateJinkoujue` |
| 奇门时家 | 九宫格（九星/八门/八神/四干） | `generateQimen(scope='hour')` |
| 观音灵签 | 签筒抽签动画 + 签号 + 签诗 | `drawRandomSign` 签文 |

- **通用结果页**：顶部「卦象/课式主视觉」+ 中部「断语/签文/宜忌」+ 底部按键「[可选] 深度断卦（付费）｜ 重新起卦 ｜ 回到档案列表 ｜ 回到首页」。
- 「深度断卦」= 唯一 LLM 时刻，按钮带积分消耗提示（对齐现有充值/积分提示样式）。

## 5. 西式占卜：塔罗 / 雷诺曼

### 5.1 塔罗 · 卡面美术规范（用户另行生成）
| 项 | 规范 |
|---|---|
| 尺寸 | 竖版 3:5，建议 600×1000px（2x 1200×2000） |
| 套数 | 78 张（大阿卡纳 22 + 权杖/圣杯/宝剑/钱币 各 14） |
| 命名 | `major_<两位序号>_<中文名>.png`（如 `major_01_愚者.png`）；小阿卡纳 `wands_01_权杖王牌.png` 等（suit: wands/cups/swords/pentacles） |
| 背面 | `card_back.png`（同尺寸，紫晶底 + 星月纹） |
| 正逆位 | 逆位 = 前端 `transform: rotate(180deg)` 即可，无需单独图 |
| 占位 | 美术未到前用「卡名 + 花色配色底 + 大阿卡纳罗马数字」CSS 卡面 |

- **花色配色**（小阿卡纳）：权杖=火红 `#C96A3B`、圣杯=水蓝 `#3B7BB0`、宝剑=风灰 `#8A93A6`、钱币=土金 `#C9A24B`；大阿卡纳=紫晶 `#5B4B8A`。

### 5.2 塔罗 · 抽卡流程页
| 步骤 | UI 元素 | 数据 |
|---|---|---|
| 1 方向选择 | 爱情/事业/财运/综合/成长（卡片单选） | `question` 存后端 |
| 2 牌阵选择 | 单张 / 三张(过去现在未来) / 爱情 / 事业 / 选择（对应库内 `single/three/love/career/decision`） | `spreadType` |
| 3 抽卡 | 背面扇形/横排牌堆，逐张点击翻牌（翻牌动画：Y 轴翻转 + 正逆位随机旋转） | `interactiveSamples` 交互抽牌 |
| 4 结果 | 卡面 + 牌位名 + 正逆位 + 关键词标签 | `cards[].{name,position,reversed,keywords,element,archetype}` |

- **牌位名**（来自 `tarotSpreads`，如三张=「过去/现在/未来」）显示在每张卡上方。
- **关键词标签**：`keywords`（逗号拆成标签数组，如「新开始/冒险/纯真」）+ `element`（火/水/风/土/大阿卡纳）+ `archetype`（如「数字三的发展阶段」）用小字显示。
- **底部按键**：「[可选] 综合解读（付费）｜ 重新抽卡 ｜ 回到档案列表 ｜ 回到首页」。

### 5.3 塔罗 · 解读结果（可选 LLM）
- 布局：牌阵缩略图（小卡横排）+ 分段解读正文（主线 / 牌位联动 / 结论，来自 `buildTarotSpreadTask` 框架）+ 末行免责。

### 5.4 雷诺曼（36 张小牌）
| UI 元素 | 说明 |
|---|---|
| 卡面 | 36 张小牌（骑手/三叶草/船/房子…），美术复用塔罗风格（紫晶底）；美术未到前用「牌名 + 序号 + 花色配色」CSS 占位 |
| 抽牌流程 | 选择牌阵（单张 / 三张 / 九宫格）→ 逐张翻牌（动画同塔罗） |
| 结果页 | 卡面 + 牌位名 + 关键词标签 + **相邻牌组合语义**（确定性，不走 LLM） |
| 底部按键 | 「[可选] 深度解读（付费）｜ 重新抽牌 ｜ 回到 Hub ｜ 回到首页」 |

- 数据：`drawLenormandSpread(spreadType, options)` 返回牌面 + 关键词/主题，前端做「牌位 + 关键词 + 相邻牌」确定性组合文案。

## 6. 星座预测页

### 6.1 星盘圆图（SVG wheel，纯前端自绘）
- **数据**：`natal.planets[]`（`longitude` 黄经 + `sign` + `degree` + `formatted`）、`natal.houses[]`（宫头黄经）、`natal.angles[]`（四轴）、`natal.aspects[]`（`body1/body2/type/actualAngle/closeness`）。
- **画法**：
  - 三同心环：内环=宫位（12 宫按宫头黄经均分，逆时针）、中环=星座（12 星座刻度）、外环=行星符号（按黄经落点）。

  - 中心标注上升 ASC / 天顶 MC。
- **星座符号**：♈♉♊♋♌♍♎♏♐♑♒♓；**行星符号**：☉☽☿♀♂♃♄♅♆♇ + 上升 ASC/天顶 MC。
