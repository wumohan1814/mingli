### S01 · 64 卦「大意」库（本卦 / 变卦共用正文；静卦显示 S06 静卦文案）

> 用途：免费解读区「本卦大意」「变卦大意」。每段为现代白话趋势参考式大意；卦辞/彖/象/爻辞**原文**按需作引用附录（S08），本库不含全文引用。
> 写法统一：局面 + 宜 / 留意。以下按通行卦序。

1. 乾：纯阳刚健、动力充沛之时。宜自强进取、把握主导；留意勿恃强冒进，刚极则折。
2. 坤：厚德载物、顺势承接之局。宜包容配合、按部就班；留意只宜跟随辅佐，不宜强自出头。
3. 屯：初始维艰、万事起头难。宜扎稳根基、缓步经营；留意仓促冒进反生蹉跎，蓄力待发为佳。
4. 蒙：蒙昧初开、有待启发之象。宜虚心求教、先明理再行动；留意忌自以为是，草率定论。
5. 需：云上于天、时机未至。宜耐心等待、养精蓄锐；留意急躁抢进易遇险，待条件成熟再行。
6. 讼：争执分歧、立场相左之象。宜先和解沟通、减少对抗；留意争讼费时费力，能退则退。
7. 师：兴师动众、以众行事之局。宜严明有序、依规而行；留意须师出有名、节制用众。
8. 比：亲附团结、择善而从之象。宜亲近正道、彼此呼应；留意所亲须正，警惕盲从。
9. 小畜：力量尚微、小有积蓄。宜小步推进、积少成多；留意暂不宜大举扩张，待力足再动。
10. 履：如履虎尾、谨慎而行之象。宜守礼持敬、步步为营；留意处危知惧方能转安。
11. 泰：天地交泰、上下通顺。宜乘势而为、广开局面；留意泰中有否极之机，居安思危。
12. 否：天地不交、上下隔塞。宜收敛自守、明哲待时；留意闭塞终将过去，不宜强求通达。
13. 同人：与人同心、协力共事。宜坦诚协作、求同存异；留意须辨明同道，防表面和气。
14. 大有：大有所获、光明丰盛。宜善用所得、谦以守成；留意盛时易骄，德位相配方能长久。
15. 谦：谦逊持中、卑以自牧。宜低调务实、礼让于人；留意谦者终受益，骄者先受损。
16. 豫：欢愉振奋、顺势而动。宜借势而起、见机行事；留意乐极易生惰，动前先安内。
17. 随：随顺时势、择善而从。宜灵活随缘、跟对方向；留意随不可失主见，谨防随波逐流。
18. 蛊：积弊待整、拨乱反正之象。宜直面旧疾、果断整饬；留意革弊须有章法，忌半途而废。
19. 临：阳长阴消、亲临其境之局。宜顺势推进、关怀下位；留意盛极将转，早作绸缪。
20. 观：观仰省察、反观自照。宜静心观察、审时度势；留意看人先看己，谋定而后动。
21. 噬嗑：咬合决断、清除梗阻之象。宜明断是非、扫除障碍；留意用刚须有度，戒苛急。
22. 贲：文饰润色、讲究形式之象。宜得体修饰、注重形象；留意文不胜质则虚，本末勿倒。
23. 剥：剥落侵蚀、阴盛阳衰。宜谨守根基、蓄力待时；留意不利进取之时，守成为上。
24. 复：一阳来复、生机回还。宜把握转机、从头起步；留意初复力微，宜养不宜躁。
25. 无妄：不妄为、守正而行。宜顺理而动、诚意正心；留意守正则吉，妄动生灾。
26. 大畜：大为积蓄、厚积待发。宜多学多蓄、克制当前；留意蓄足自然可发，不必急于一时。

30. 离：光明依附、洞察明达。宜附丽正道、以明处事；留意过明易苛，防刚火伤人。

### S02 · 六亲释义（5 条，词条卡 / 术语 hover）

1. 父母爻：生我护我者——主长辈、文书、房产、根基、保障。白话提示：凡与「庇荫、凭证、承托」相关之事看父母。
2. 兄弟爻：同我比肩者——主同辈、合作者、竞争、破耗、分利。白话提示：涉及「分财、同行、往来」多论兄弟。
3. 子孙爻：我生者——主晚辈、子女、技艺、福气、解忧、医药。白话提示：逢忧疑困扰，子孙为解忧之神。
4. 妻财爻：我克者——主财利、物资、妻室、可支配之产。白话提示：谋财问利，先观妻财状态。
5. 官鬼爻：克我者——主事业、官职、压力、是非、疾患。白话提示：问事业吉凶与忧患之事看官鬼。

### S03 · 六神释义（6 条）

1. 青龙：主喜庆、文书、贵人、酒食宴乐；多与正面喜庆之事相系（趋势参考：逢青龙多主顺遂喜气）。
2. 朱雀：主口舌、文书信息、声音表达；宜留意言谈文书与是非口舌。
3. 勾陈：主田土、迟缓、牵绊、旧事；多与拖延、牵连相关，宜耐心处理。
4. 螣蛇（腾蛇）：主虚惊、缠绕、变化不实；遇之多留意疑虑幻觉、反复之象。
5. 白虎：主刚猛、伤病、快速、肃杀；与急变、伤病面相关，宜谨慎守正。
6. 玄武：主暗昧、隐蔽、隐私、盗失；多与暗处之事相关，宜防隐忧。

### S04 · 世应基础含义（免费解读区「世应」卡）

- 世爻 = 占问的主体方（当事人自己或所代表的一方）；应爻 = 主体所面对的对象、对方或所问之事的一端。
- 白话示例：问出行，世为我、应为目的地与彼方；问合作，世为我方、应为对方；问自身状态，世为当下处境。
- 世应相生合多主和顺投契；相冲克多主隔阂对抗；世空应实或应空世实，皆有侧重，需结合动变细看（细处由深度解读承接）。

### S05 · 常用占断术语短释（词条卡；数据展示处 hover 可复用）

1. 旬空（空亡）：日柱所值旬内无此支，该爻如落空——主该事暂不落实、虚位待填。趋势参考：旬空之事常需出空后才有眉目。
2. 月破：爻支被当月所冲——主当月经受冲击、效力减损；月过之后渐复。
3. 日破 / 日冲：被当日所冲——当日多生变动、被催促；冲实或冲空另有别论。
4. 暗动：静爻被日辰冲动而暗自发用——主暗流已动、事在悄悄变化。
5. 回头生 / 回头克：动爻化出的变爻反过来生/克自身——化回头生多为助力回馈；化回头克多主反受其制，宜留意。
6. 化空 / 化破 / 化墓：动爻变入空亡/被冲破/入墓——多主所化之事暂不成形、受困待时。
7. 入墓：爻入墓库——主受藏、阻滞、暂难施展；冲开墓库方有转机。
8. 六合 / 六冲：卦与卦、爻与爻的合冲关系——合主牵合和缓，冲主动荡分开。
9. 伏神：用神不上卦时，从本宫卦中借出者——主事藏于暗、需待引动。
10. 用神 / 原神 / 忌神 / 仇神：断卦聚焦的对象 / 生用者 / 克用者 / 生忌者——白话提示：看事先定用神，再看其得助受制。
