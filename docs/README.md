## 写作约定

1. 规范变更必须同步 `standards/05-版本迭代记录.md`，并在 PR 描述中引用条目。
2. 决策先写 ADR 再动手；ADR 一旦 Accepted，如需推翻应新建 ADR 并标注 `Superseded by`。
3. 引用 mingli skill 的章节号时，必须显式写明"章节号指 `reference/mingli/SKILL.md`"，避免与本仓库文档章节混淆。
4. 顶层文档的移动 / 新增 / 删除须同步更新本 README 索引。
