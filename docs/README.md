## 写作约定

1. **规范变更必须同步 `standards/07-版本迭代记录.md`**，并在 PR 描述里引用（注意：版本记录是 **07**，05 是前端组件库规范）。
2. **接口 / 数据字典的变更以 `standards/03-接口与数据字典.md` 为准**；运行形态与版本兼容判据以 `standards/08` 为准；库结构变更以 `standards/09` 为准。
3. 顶层文档的移动 / 新增 / 删除**必须同步更新本 README 索引**。
4. 面向用户的文字只在四处归口（见 `standards/01` §12）：`frontend/public/data/ui-copy.js`（界面词）、`frontend/public/data/content/`（正文）、`frontend/public/css/tokens.css`（视觉令牌）、`frontend/public/art/`（美术素材）。
