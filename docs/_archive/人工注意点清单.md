## 三、部署 / 运维注意（不动则出错）

| # | 事项 | 说明 |
|---|---|---|
| 11 | **双运行时** | 排盘引擎硬约束：镜像必须同时含 **Python 3.13 + Node 22**（Python 调 `backend/paipan-node` 的 ziwei.cjs / extra.mjs） |
| 12 | **不要 npm install / pip install** | lunar-python 已装；iztro/mingyu-core 已在 `backend/paipan-node/node_modules` 与 `vendor/`。依赖复用，勿重复安装 |
| 13 | **沙箱阻止 Vite/esbuild** | 前端走**免构建** CDN React（`frontend/public/index.html` + `vendor/`），不重启 Vite；`frontend/src/` 仅是参考源码 |
| 14 | **Node 依赖路径** | `engine.py` 用 `Path(__file__).resolve().parents[2] / "paipan-node"` 定位，移动目录会破坏 |
| 15 | **DB 迁移** | `ensure_schema()` 在 FastAPI lifespan 启动时对 `jobs` 表 `ALTER TABLE ADD COLUMN result_json`（幂等）；首次启动自动执行 |
| 16 | **真太阳时/经纬度** | 缺经纬度 → 占星/七政/奇门/五运六气 4 法降级（`degradedMethods`），九法只剩 5 法；前端已加内置 36 城坐标表 |
