## 0. 分类与占位约定

| 类别 | 含义 | 处理方式 |
|---|---|---|
| **A · 在线找** | 可引用 / 参考公开在线资源，改写后使用（规避版权，不逐字复制单一商业源） | 人工/Agent 搜集 → 改写 → 入库 |
| **B · 需要生成** | 无现成可参考、需原创的文案 | 自撰 / LLM 生成后人工审 |
| **C · 先占位** | 结构/字段先占位，正文待补 | 生产显示占位符 |

**占位符约定**：未补全的文案统一显示 `「文案待补充」`；纯展示位可用 `——`；并在代码处留 `TODO(文案)` 注释标记待补位置。

## 工作流约定

1. **A 类（在线找）**：先搜集→改写→入库；改写须注明来源、不逐字复制单一商业源（规避版权）。
2. **B 类（生成）**：自撰或 LLM 生成后人工审校，确保合规（禁宿命式断言，REQ-006 红线）。
3. **C 类（占位）**：先落地占位符，A/B 完成后再替换；替换时同步更新本册状态（占位 → 已补）。
4. 每次补全，把状态从「占位/待补」更新，并在 `docs/需求表.md` 对应 REQ 备注回填。

---

> 本册是文案补全的**跟踪清单**，不是文案正文本身；正文入库位置：星座/塔罗/雷诺曼文案 → 后端 data 或前端常量；全站 UI 文案 → `frontend/public/index.html`；生肖/星盘翻译 → 后端确定性代码 / 映射表。
