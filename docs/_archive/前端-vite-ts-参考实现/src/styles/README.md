# styles/ — 样式规范

设计令牌与全局样式的唯一来源。

| 文件（待建） | 内容 |
|---|---|
| `tokens.css` | 设计令牌：色板、字号、间距、圆角、阴影（CSS 变量） |
| `theme.css` | 主题：浅色为主，命理品类偏暖色调 |
| `global.css` | 重置样式、字体、全局排版 |
| `mobile.css` | 移动端适配：安全区、1px 边框、750 设计稿换算 |

## 约定

- 组件样式用 CSS Modules，**禁止**在组件内硬编码颜色与间距，一律走 `tokens.css` 变量。
- 新增令牌须同步本文件的令牌清单表。
- H5 首屏性能优先：字体子集化、图片走 CDN、避免全量组件库引入。
