# components/ — 组件

分三层，目录按层建子目录：

| 层 | 内容 | 依赖 |
|---|---|---|
| `base/` | 无业务语义的通用组件：按钮、卡片、弹层、加载态 | 仅 UI |
| `business/` | 业务组件：问卷卡片、断言条目、修正输入框、免责脚注 | 可依赖 `base/`、`types/` |
| `chart/` | 盘面渲染：四柱、大运流年、紫微宫位、星盘 | 可依赖 `base/`、`types/` |

## 约定

- 一个组件一个目录：`<Name>.tsx` + 样式文件 + `index.ts` 导出。
- 组件不直接发起请求，通过 `services/` 注入或由页面传入。
- 盘面渲染组件**只渲染 `chart.json` 已有的值**，缺失显示"数据缺失"，禁止前端推算或补默认值。
