# 太初 · UI 需求文档（交互改版，供 UI / 设计 Agent 独立使用）

> 定位：把需求表里**纯 UI / 交互改版类**需求抽出来，交给 UI / 设计 Agent 单独产出设计稿 / 视觉规范。
> 本文只描述「界面要长什么样、交互怎么走」，不涉及后端逻辑（后端契约见 `docs/架构设计-横向扩展.md`）。
> 关联：`docs/需求表.md`（REQ）｜ `docs/Bug管理表.md`（BUG）｜ `docs/UI元素清单-横向扩展.md`（现有 UI 元素清单）。

---

## 0. 交付物与验收口径

UI Agent 产出的东西应包含：
1. **每个模块的页面布局描述**（文字 + 结构，含层级、间距、按钮形态）。
2. **交互状态**（默认 / 悬停 / 选中 / 禁用 / 空态 / 加载 / 错误）。
3. **与现有皮肤体系的映射**（沿用 `data-skin` / `--skin-accent` / `--skin-banner` 变量，不另起炉灶）。

---

## 1. Hub 页方法列表改竖向单列（REQ-038）

- **现状**：国学预测 Hub / 西式占卜 Hub 的方法卡片是横向两列（grid）。
- **目标**：改为**竖向单列**排列，每个方法卡片横向拉通，选项内容（名称 + 副标题 + 图标）展示更充分，页面不拥挤。
- **范围**：国学 Hub（九法合一/生肖流年/临时起卦）+ 西式 Hub（星座/塔罗/雷诺曼/其他）。
- **关联**：REQ-020/027。

## 2. 档案详情页改版（REQ-040）

- **顶部标题**：显示当前档案的**用户命名**（非固定「我的命理档案」）。
- **页尾按钮重设计**：
  - 删除「退出登录」按钮。
  - 保留「回到档案列表」「回到首页」。
  - 新增「国学预测 / 西式占卜 / MBTI」三个**直达按钮**：携带当前档案进入对应模块**主功能**（非落地页）；该档案对应模块无数据时，页内引导生成、不自动生成。
- **关联**：REQ-027/028。

## 3. 生肖流年模块图标重设计（REQ-041）

- 统一整体产品风格，重做生肖流年模块的图标（当前图标风格不统一）。
- **待美术素材 / 设计方向**：用户提供后再启动。

## 4. 塔罗交互改版（REQ-042，P1）

1. **链路改**：`预测方向 → 问题文本框 → 牌阵`（未选方向则牌阵无效；方向/牌阵按钮大小对调、链路引导显眼）。
2. **抽卡页**：牌阵上方承接用户填的问题文本。
3. **牌义固定文案**：抽出的每张卡展示对应牌义固定文案（可复用文本，不依赖 LLM）。
4. **进入页顶部**：5 张扇形卡（封面 + 随机 3–4 张）；移除「牌库 1909 公版」字样，公版署名移至页脚小字。
5. **底部按钮**：「重新抽卡 / 重选牌阵 / 返回」改全宽并列大按钮。
6. **图片提速**：80 张牌图本地压缩 WebP + 分级缩略图（保留相对路径、懒加载、不引外部 CDN）。
- **关联**：REQ-023。

## 5. 雷诺曼改版（REQ-043）

- 整体 UI 与交互对齐塔罗新布局（链路、按钮样式一致）。
- 补充单张 / 3 张 / 9 宫格抽出牌的**细节固定文案**（可复用文本）。
- **关联**：REQ-024。

## 6. 临时起卦交互改版（REQ-044，P1）

- **链路**：先选卦法（六爻/梅花/小六壬/观音灵签）→ 输入问题文本框 → 点击开始起卦 → 展示卦象。
- **底部按钮**：「重新起卦 / 返回」改全宽并列大按钮。
- **关联**：REQ-022；六爻完整卦象缺陷见 BUG-004。

## 7. 星座页「太阳/月亮/上升」三格 + 布局（REQ-045，P1）

1. **新增三格**：星盘页新增「太阳 / 月亮 / 上升」三格，每格展示该档案对应星座的整体趋势描述（感情/事业等）。
2. **文案**：复用文案按男女各一套 = 12 太阳×2 + 12 月亮×2 + 12 上升×2 共 **72 篇**；**先以占位文本实现结构与布局，正文后续补全**（见文字需求文档）。
3. **星盘正中**：ASC/MC 字样去除。
4. **按钮位置**：「本命深度解读」按钮上移至三格下方、行星落座/落宫等详细信息上方。
- **关联**：REQ-025。

## 8. 新建档案入口与按钮路径（REQ-046，P1）

1. **MBTI 与西式占卜·星座页**补「新建档案」入口（进入建档流程）。
2. **从模块页进入「新建档案」**：建档完成后直接进入该模块主流程，显示对应主按钮（开始排盘 / 生成星盘 / 开始答题），**不显示其他模块按钮**。
3. **从右上角「档案管理」进入的档案页**：提供「选择档案进行修改/查看」与「回首页」，不显示模块主流程按钮。
- **关联**：REQ-026/028/039/040。

## 9. 星座/MBTI「选择已有档案」UI 明显化（BUG-006）

- **现状**：档案项像注释不可点，「选择档案」按钮过小（远小于「生成星盘」主按钮）。
- **目标**：档案项改为明显可选样式（卡片/列表带选中态），「选择档案」与主操作同尺寸层级、步骤引导清晰。
- **关联**：REQ-028/039。
