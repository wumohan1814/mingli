## 4. 偏差与说明

1. **背景改浅暖灰**：Q 版若用纯白底，纯白头发会被白键控误抠成透明；改用 #E6E2DA 浅灰底，色键控干净保留白发。
2. **Logo 方向变更**：需求方在样片确认阶段将 Logo 从「占星圆盘」改为「Q 版头像徽」，已按新方向重出。
3. **PNG 母版压缩**：Q 版 PNG 母版经 adaptive palette(200) 压至 ≤300KB（WebP 为线上资产，保留 RGBA 平滑透明）。
4. **可选批 #5–#8（背景图）**：按素材表「待需求方决定排期」，本轮未生产；空槽当前回退 CSS 渐变，非阻塞。
5. **可选增强 #1a/#2a**（小鸟/蝴蝶/星座/卡牌）：本轮未生产，可在确认本批后追加。
