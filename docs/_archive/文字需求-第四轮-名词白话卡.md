## 1. 交付对象与格式

- 交付给**文案 / 文字 Agent**（与既有 T1–T6 文案轮次同一通道）。
- 每个方法一个 JSON（或统一一个文件），结构：

```json
{
  "method": "liuren",                       // 或 taiyi/huangji/jinkoujue/qimen/almanac
  "cards": [
    { "key": "tianshen-zhugong",            // 卡位 key（开发建卡位时给出，文案对齐）
      "term": "十二天将",                    // 行话名词
      "plain": "……（1~2 句大白话：代表什么 / 偏吉偏忌 / 对用户意味着什么）……" }
  ]
}
```

- 每条 1~2 句大白话，**趋势参考话术、不作吉凶承诺**（对齐 REQ-006/037 合规口径）。
- 中文 UTF-8、`ensure_ascii=False`；注明来源/原创。
