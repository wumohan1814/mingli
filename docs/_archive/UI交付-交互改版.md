## 3. 逐 REQ 设计明细

### REQ-038 Hub 竖向单列
- **布局**：`.hub-grid { display:flex; flex-direction:column; gap:12px }`；`.hub-card` 改为横向：`flex-direction:row; align-items:center; gap:14px`，左色条 `.hc-bar` 保留（宽5px 竖条），图标 `.hc-ico` 左，文字区（`.hc-name`+`.hc-sub`）右，卡片 `width:100%`。
- **交互状态**：默认 / 悬停（轻微提亮+微阴影）/ 选中（同模块当前页可加 `.active` 描边）/ 禁用（「其他西式占卜」灰显 + toast）。
- **美术**：沿用现有 `Icon` 集（`nine`/`orbit`/`spark`/`flat`），不新增。

### REQ-040 档案详情页
- **顶部标题**：`case.name || '未命名档案'`（替代固定「我的命理档案」）。
- **页尾按钮**：删除「退出登录」；保留「查看解读」「回到档案列表」「回到首页」；**新增三直达按钮**（视觉权重等同主按钮）：
  - 国学预测 → `onNavigate('predict', { caseId })`（综合解读主功能）
  - 西式占卜 → `onNavigate('tarot', { caseId })`（西式主功能）
  - MBTI → `onNavigate('mbti', { caseId })`（判型主功能，需写回 `mbti_type`）
  - 「该档案对应模块无数据时」：进入后页内引导生成（如星座无 natal 数据则提示「生成星盘」），**不自动生成**。
- **美术**：复用 `btn-primary`/`btn-outline`，三直达可用 `.btn-primary` 强调。

### REQ-041 生肖流年图标（已产素材）
- **交付**：`frontend/public/art/zodiac/zodiac-icons.svg`，内含 12 个 `<symbol>`（id: `zx-rat/ox/tiger/rabbit/dragon/snake/horse/goat/monkey/rooster/dog/pig`）+ 1 个模块图标 `zx-taisui`。
- **规格**：画布 100×100/个；深墨蓝底 `#1B2A4A` + 金色环 `#C9A24B`（描边2）+ 星点（金，r1–1.5）+ 居中生肖汉字（金 `#E8C77A`，宋体/serif，40px）。星象式高奢、风格统一。
- **集成**：`<svg><use href=".../zodiac-icons.svg#zx-dragon"/></svg>` 或转 base64/雪碧图；开发可替换为精细动物插画（设计系统不变）。

### REQ-042 塔罗交互改版（P1）
1. **链路**：`预测方向(tag) → 问题输入框 → 牌阵(method-cell)`；方向未选时牌阵点击无效（置灰/提示）；方向 tag 与牌阵按钮大小对调、链路引导显眼。
2. **抽卡页**：牌阵上方承接用户填的问题文本（回显 `dir` + 问题）。
3. **固定牌义**：每张抽中卡展示对应牌义固定文案（`TAROT_DECK` 每卡补 `meaning` 字段，可复用文本，不依赖 LLM）；综合解读仍走付费 LLM（保留）。
4. **entry 顶部**：5 张扇形卡（封面 + 随机 3–4 张）；移除「牌库 1909 公版」字样，公版署名移至页脚小字。
5. **底部按钮**：「重新抽卡 / 重选牌阵 / 返回」改全宽并列大按钮（`.back-row` + `width:100%`）。
6. **图片提速（REQ-042.6，延后）**：80 张本地压缩 WebP + 分级缩略图（保留相对路径、懒加载、不引外部 CDN）。当前用 720px JPG 已可用，WebP 为优化项。

### REQ-043 雷诺曼改版
- 整体 UI/交互对齐塔罗新布局（方向→问题→牌阵→抽卡→全宽按钮一致）。
- 补充单张 / 3 张 / 9 宫格 抽出牌的**细节固定文案**（`LENORMAND_DECK` 每卡补 `detail` 字段，36 张各一份可复用文本）。
- 美术：复用 `./lenormand/` 已下载 36 张真实图。

### REQ-044 临时起卦交互改版（P1）
- **链路**：先选卦法（`method-cell`：六爻/梅花/小六壬/观音灵签）→ 输入问题文本框 → 点击「开始起卦」→ 展示卦象。
- **底部按钮**：「重新起卦 / 返回」改全宽并列大按钮。

### REQ-045 星座页三格 + 布局（P1）
1. **新增三格**：星盘页「太阳 / 月亮 / 上升」三格，每格展示该档案对应星座整体趋势描述（感情/事业等）。
2. **文案**：72 篇占位（12太阳×2 + 12月亮×2 + 12上升×2），先以占位文本实现结构与布局，正文后续补全（见文字需求文档）。
3. **星盘正中**：去除 `ASC`/`MC` 字样（保留四轴数据于详情区）。
4. **按钮位置**：「本命深度解读」上移至三格下方、行星落座/落宫等详细信息上方。
- 美术：星盘 SVG 复用（去文字）。

### REQ-046 新建档案入口与按钮路径（P1）
1. **MBTI 与西式占卜·星座页**补「新建档案」入口（进入建档流程）。
2. **从模块页进入新建档案**：建档完成（`onboarding` 携带 `returnTo`）后直接进入该模块主流程，显示对应主按钮（开始排盘/生成星盘/开始答题），**不显示其他模块按钮**。
3. **从右上角「档案管理」进入的档案页**：提供「选择档案进行修改/查看」与「回首页」，**不显示模块主流程按钮**。

### BUG-006 选择已有档案 UI 明显化
- **现状**：档案项像注释不可点，「选择档案」按钮过小。
- **目标**：档案项改为明显可选卡片/列表（带选中态高亮）；「选择档案」与主操作同尺寸层级、步骤引导清晰（如「① 选择档案 → ② 开始」）。
