# 03 · 竞品可用形式及其实现方法

> 配套：00-总览与证据账本.md ｜ 采集 2026-09-05
> 聚焦：竞品采用的"形态"（H5/小程序/App/独立站/公众号）与各自实现路径、技术取舍，映射到太初的 H5 轻量路线。

---

## 1. 形态图谱（按"上线难度 × 合规风险 × 成本"）

| 形态 | 代表 | 上线难度 | 合规风险 | 成本结构 | 适合太初? |
|---|---|---|---|---|---|
| 纯 Web/H5（自建） | FATE、BaziAI、FateForge | 低 | 低-中（离岸更低） | Serverless+API，边际低 | **是（规划首选）** |

## 2. 纯 Web/H5 + AI 对话（太初最近邻，重点拆解）

### 2.1 FATE 紫微（港台，离岸 H5）
- 实现：网站输入生辰 → 生成命盘 → Grok 生成报告 → 年费升级后 AI 互动问答（未来 3 月趋势）。
- 部署：港台节点，低延迟；Google AI Startups Program 资助。
- 收费：站内直接单次/月/年，港台支付通道。
- 对太初：证明"离岸 H5 + 大模型生成 + 订阅"跑得通；其"标精准 97%"是太初应避免的踩线点。

### 2.2 BaziAI（海外 Web）
- 实现：Next.js + Cloudflare + Supabase；DeepSeek R1 做八字解读；免费 3 次/天，付费无限。
- 技术要点：**Cloudflare 边缘函数 + Supabase 存用户档案**，正是太初 7.3"静态 H5 + 轻函数后端 + session 无状态化"的范本。
- 对太初：技术栈可直接借鉴（边缘函数降本、无状态 session 利于香港节点低延迟）。

### 2.3 FateForge（海外 Web，多系统综合）
- 实现：八字/紫微/西占/吠陀多系统排盘（确定性计算免费）+ AI 解读（付费）；一次性点数包。
- 对太初：验证"多流派综合"的产品形态，且用**一次性点数包**而非订阅，是太初可借鉴的付费变体。

### 2.4 太初规划形态（规划 6/7.3）
- 静态 H5 + 轻函数后端（边缘函数/Serverless），session 无状态化、token 鉴权。
- 排盘/演算为确定性规则引擎，本地/边缘执行，**不每次调 LLM**；仅"自然语言解读 + 修正对话"调模型。
- 每用户独立 session + 生辰 + 历史对话 = 可累积命理档案（数据资产，规划 7.2）。

## 3. 微信小程序形态（高风险，仅供避坑）

- 规则：纯占卜/算命类主体 **99% 驳回**，易封号、冻结商户资金（来源 S20，供应商合规清单，中）。
- 应用商店：含"卜卦、吉凶祸福"关键词直接拒审，"必死/大灾/暴富"永久下架（S20）。
- 抖音/公众号：测算类内容限流、下架，付费命理咨询易判违规（S20）。
- 历史案例：2019 年"AI 面相"小程序病毒式传播，上传照片生成不完整报告、付费解锁（28.8 元），靠发展代理分润；微信对封建迷信测试"能力限制至封禁"阶梯处罚（S21/S22，高）。
- **对太初**：规划已明确不做小程序，方向正确；即便未来想借微信流量，也应只做"内容种草 + 外链 H5"，交易留在自建 H5/持牌平台。

---

## 4. App 形态（重、慢、审，非太初方向）

- 头部（测测/问真/文墨/灵机）靠 App 沉淀千万用户，但需软著、ICP 备案、应用商店审核、持续迭代。
- 问真/文墨走"工具免费 + 内购"，文墨专业版内购 $9.99–24.99（S11）。
- **对太初**：第一阶段"由全 Skill 演化、轻量包装"的目标是低成本验证单位经济，App 的重资产与长审核周期与"小步快跑"相悖，规划弃 App 合理。

---

## 5. 公众号 + 小程序 + 源码部署（供应商生态）

- 顺企网/一讯等供应商提供"紫微斗数+AI""八字排盘+AI"源码，支持公众号/小程序/定制/源码部署，开发者采购现成排盘 API + 通用大模型 API 快速上线（S4/S5/S6）。
- 第三梯队 3000+ 小团队多走此路：同质化、文案照搬头部、无合规、靠低价投放，年均淘汰 20%（S6）。
- **对太初**：说明"排盘 API + 大模型 API"是成熟供应链，太初自研 Skill 等于把核心排盘能力内化，避免被供应商锁定、也利于"可修正"差异化；但不建议买现成小程序源码（合规雷）。

---

## 6. 海外独立站形态（出海延展参考）

- 建站：Shopify + 命理专用插件（Destiny Pro $29/月排盘、Tarot Master $15/月、Feng Shui AI $45/月）或 WordPress+WooCommerce（S12/S13）。
- 支付：PayPal 禁占卜类；Stripe 通过率约 40%（需报 MCC 5968 "Information Services"）；推荐 Adyen/Paddle（佣金 15%+VAT，成功率 85%+）（S12）。
- 合规：FTC 要求 "For entertainment purposes only" 免责，未标每条罚 $50,120；加州注册 Spiritual Advisor Business 年费 $100；欧盟 DSA 披露实际控制人（S12）。
- 利润率：独立站 ≥85% vs 平台 ≤60%；复购 34% vs 12%（S13）。
- **对太初**：若未来做英文/出海版，"香港节点 + 独立站 + Stripe/Adyen + 娱乐免责"是成熟模板；第一阶段聚焦中文 H5 即可。

## 7. 实现方法共性提炼（可复用的工程范式）

1. **计算与生成分离**：排盘/星盘/四柱等确定性计算全本地/边缘（零边际成本），仅解读调 LLM —— 行业高毛利（78–85%）的根因，也是太初单位经济铁律。
2. **边缘函数 + 无状态 session**：BaziAI 用 Cloudflare+Supabase，太初规划 7.3 同构，利于香港节点低延迟、弹性扩缩。
3. **用户档案沉淀**：Supabase/自建 DB 存生辰+历史，支撑复购与横向扩展（太初 7.2 数据资产）。
4. **免费层做流量入口**：基础排盘/简版趋势免费，深度/无限/修正付费（Freemium 主流）。
5. **合规包装前置**：产品定性为"民俗文化/性格测评/运势参考"，全页固定免责，禁绝对吉凶词（S20）。

---

## 8. 对太初的形态决策建议

- **坚持纯 H5 + 边缘函数 + 无状态 session**（规划已定，与 FATE/BaziAI 同构且最合规）。
- **排盘规则引擎必须本地化/边缘化**，这是成本与差异化的共同支点；"可修正"在本地维护用户命盘状态，修正只调解读模型。
- **交易不留在 H5 自收银**，走持牌内容平台（小鹅通/知识星球）按钮跳转，支付合规由平台承担（规划 4.3"聪明裸奔"）。
- **微信内只做内容与外链**，绝不在小程序内做付费测算。
- 出海版可延后用独立站模板（Shopify/Stripe/Adyen + 娱乐免责）。
