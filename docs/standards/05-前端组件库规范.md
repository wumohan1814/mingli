## 1. 组件分类与命名约定

### 1.1 组件分层

| 层级 | 说明 | 命名规则 | 示例 |
|---|---|---|---|
| **原子组件** | 不可再分的基础 UI 元素 | 大驼峰，名词 | `Icon`、`Btn` |
| **通用组件** | 可跨模块复用的复合组件 | 大驼峰，名词 | `Card`、`Modal`、`Skeleton`、`Tag` |
| **业务组件** | 特定业务域内的复用组件 | 大驼峰，带域前缀 | `CreditBalance`、`FourPillars`、`ZodiacMedallion` |
| **页面组件** | 路由级页面 | 大驼峰，以 Page 结尾 | `LandingPage`、`CasesPage`、`PredictPage` |
| **弹窗组件** | 模态弹窗 | 大驼峰，以 Modal 结尾 | `RenameModal`、`CreditInsufficientModal` |

### 1.2 组件 Props 约定

```
// 推荐：解构 + 默认值
function Btn({ variant = 'primary', size = 'md', disabled = false, children, onClick }) {
  // ...
}

// 禁止：props.xxx 散点式读取
function Btn(props) {
  const variant = props.variant || 'primary';
  // ...
}
```

## 2. 原子组件

### 2.1 Icon — 内联 SVG 图标

**位置**：`index.html` 约 2629 行

| Prop | 类型 | 默认值 | 说明 |
|---|---|---|---|
| name | string | — | 图标名称（见下方图标清单） |
| size | number/string | 18 | 图标尺寸（px） |
| color | string | currentColor | 颜色，默认继承父元素 |
| className | string | '' | 附加样式类 |

**设计原则**：
- 全部使用内联 SVG，不依赖图标字体
- 颜色通过 `currentColor` 继承，随皮肤自动适配
- 尺寸用 `em` 或 `px`，与文本对齐

### 2.2 Btn — 按钮（待统一）

**当前状态**：按钮样式分散在各页面，尚未抽出统一 Btn 组件。
**计划统一**：

| 变体 (variant) | 使用场景 | 对应 CSS 类（现状） |
|---|---|---|
| `primary` | 主操作（提交、下一步） | `.btn-primary` 或各页面内联样式 |
| `secondary` | 次要操作（取消、返回） | `.btn-secondary` |
| `ghost` | 幽灵按钮（文本+边框） | — |
| `danger` | 危险操作（删除） | — |
| `skin` | 皮肤色按钮（随主题变化） | 各模块页自定义 |
| `glass` | 磨砂玻璃按钮（悬浮于氛围图/深色背景） | 新增 |

| 尺寸 (size) | 说明 |
|---|---|
| `sm` | 小按钮（标签、辅助操作） |
| `md` | 默认尺寸（表单、弹窗） |
| `lg` | 大按钮（页脚主操作） |
| `block` | 块级按钮（全宽） |

**质感要求（v1.2 新增）**：
- 圆角：默认 `--taichu-radius-md`（14px），大按钮可用 `--taichu-radius-lg`（20px）
- 阴影：默认无阴影；悬浮/主操作可带 `--taichu-shadow-card`
- 按压反馈：`:active` 时 `transform: scale(0.97)`，时长 `--taichu-dur-fast`
- 聚焦光环：`box-shadow: 0 0 0 3px var(--taichu-ring)`（替代默认 outline）
- 玻璃按钮：使用 `backdrop-filter` + 半透明背景，文字用 `--taichu-skin-accent-ink` 保证对比度

```css
.btn {
  border-radius: var(--taichu-radius-md);
  transition: transform var(--taichu-dur-fast) var(--taichu-ease),
              background-color var(--taichu-dur) var(--taichu-ease),
              box-shadow var(--taichu-dur) var(--taichu-ease);
}

.btn:active {
  transform: scale(0.97);
}

.btn:focus-visible {
  outline: none;
  box-shadow: 0 0 0 3px var(--taichu-ring);
}
```

## 3. 通用组件

### 3.1 ModalBase — 通用弹窗基座

**组件定义**：`frontend/public/index.html` 约 2830 行
**状态**：✅ 已实现（2026-09-10 Phase 1.5）

#### Props API

| Prop | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `title` | string \| ReactNode | — | 弹窗标题 |
| `children` | ReactNode | — | 弹窗内容 |
| `footer` | ReactNode | — | 底部操作栏（不传则不显示） |
| `onClose` | function | — | 关闭回调（遮罩点击 / ESC / 关闭按钮均触发） |
| `closable` | boolean | `false` | 是否显示右上角 × 关闭按钮 |
| `maskClosable` | boolean | `true` | 点击遮罩层是否关闭 |
| `className` | string | `''` | 附加到 `.modal` 的自定义类名（如 `ask-modal`、`pair-modal`） |
| `width` | number \| string | `340px` | 弹窗最大宽度 |
| `align` | `'center' \| 'left'` | `'center'` | 内容对齐方式 |
| `scrollable` | boolean | `false` | 内容过高时是否可滚动（长内容建议设为 true） |
| `bodyClassName` | string | `''` | 内容区附加样式类 |

#### 内置能力

| 能力 | 说明 |
|---|---|
| ✅ ESC 键关闭 | 打开时监听 Escape 键，自动触发 onClose |
| ✅ 背景滚动锁定 | 打开时 `body.style.overflow = 'hidden'`，关闭后恢复 |
| ✅ 点击遮罩关闭 | 默认开启，可通过 `maskClosable={false}` 禁用 |
| ✅ 事件冒泡阻止 | 点击弹窗内部不触发遮罩关闭 |
| ✅ 无障碍 | 关闭按钮有 `aria-label` |

#### 用法示例

```jsx
// 简单确认弹窗
<ModalBase
  title="操作确认"
  onClose={handleClose}
  footer={<>
    <button className="btn btn-outline" onClick={handleClose}>取消</button>
    <button className="btn btn-primary" onClick={handleOk}>确定</button>
  </>}
>
  确定要执行此操作吗？
</ModalBase>

// 长内容表单弹窗
<ModalBase
  title="编辑信息"
  onClose={handleClose}
  align="left"
  scrollable={true}
  width={420}
  className="ask-modal"
  footer={/* 底部按钮 */}
>
  {/* 表单内容 */}
</ModalBase>
```

### 3.3 旧 Modal 结构对照（迁移参考）

迁移前的标准结构：
```jsx
<div className="modal-mask" onClick={onClose}>
  <div className="modal" onClick={e => e.stopPropagation()}>
    <div className="modal-title">{title}</div>
    <div className="modal-body">{content}</div>
    {/* 按钮 */}
  </div>
</div>
```

迁移后的等价结构：
```jsx
<ModalBase title={title} onClose={onClose} footer={buttons}>
  {content}
</ModalBase>
```

**注意事项**：
- 对齐方式：旧 Modal 默认居中对齐（`text-align: center`），与 `ModalBase` 默认值一致；左对齐的（如 `ask-modal`）需传 `align="left"`
- 自定义类名：旧实现的特殊样式类（如 `ask-modal`、`pair-modal`）通过 `className` prop 传入
- 特殊宽度：默认 340px，宽弹窗传 `width={420}` 或 `width="560px"`

### 3.2 Card — 卡片容器

**使用场景**：信息分组、模块入口、列表项

**结构约定**：
```
.card
  .card-header  // 卡片头部（可选）
  .card-body    // 卡片内容
  .card-footer  // 卡片底部（可选）
```

**变体**：
- 默认：白底 + 边框 + 圆角
- 悬浮态：hover 时提升阴影
- 皮肤色：`--skin-accent-soft` 背景
- **磨砂玻璃（v1.2 新增）**：半透明背景 + `backdrop-filter` 模糊，适合叠加在氛围图/深色背景上

**质感要求（v1.2 新增）**：
- 圆角：`--taichu-radius-lg`（20px）为主；模块入口/大卡片可用 `--taichu-radius-xl`（28px）
- 阴影：`--taichu-shadow-card`
- 悬浮抬升：`:hover` 时 `transform: translateY(-3px)` + `--taichu-shadow-elevated`
- 过渡：`transform var(--taichu-dur-normal) var(--taichu-ease-out), box-shadow var(--taichu-dur-normal) var(--taichu-ease-out)`

```css
.card {
  background: var(--taichu-card);
  border-radius: var(--taichu-radius-lg);
  box-shadow: var(--taichu-shadow-card);
  backdrop-filter: blur(var(--taichu-glass-blur)) saturate(var(--taichu-glass-saturate));
  -webkit-backdrop-filter: blur(var(--taichu-glass-blur)) saturate(var(--taichu-glass-saturate));
  transition: transform var(--taichu-dur-normal) var(--taichu-ease-out),
              box-shadow var(--taichu-dur-normal) var(--taichu-ease-out);
}

.card:hover {
  transform: translateY(-3px);
  box-shadow: var(--taichu-shadow-elevated);
}
```

> 玻璃效果必须提供 fallback：在不支持 `backdrop-filter` 的环境（旧安卓/低版本 WebView）中，半透明背景本身仍可读。避免在玻璃卡片上放置小字号正文（12px 以下）。

## 5. 质感与动效规范（v1.2 新增）

### 5.1 页面载入层级浮现

**目标**：页面主内容按区块依次浮现，营造高级感与可读性。

**实现**：
```css
@keyframes fade-up {
  from { opacity: 0; transform: translateY(24px); }
  to   { opacity: 1; transform: translateY(0); }
}

main > section,
main > article {
  animation: fade-up 0.6s var(--taichu-ease-out) both;
}

main > :nth-child(1) { animation-delay: 0ms; }
main > :nth-child(2) { animation-delay: 80ms; }
main > :nth-child(3) { animation-delay: 160ms; }
main > :nth-child(4) { animation-delay: 240ms; }
main > :nth-child(5) { animation-delay: 320ms; }
main > :nth-child(6) { animation-delay: 400ms; }
main > :nth-child(7) { animation-delay: 480ms; }
main > :nth-child(8) { animation-delay: 560ms; }
```

**约束**：
- 仅对 `main` 下直接子区块生效，避免嵌套子元素重复动画
- 每个区块动画时长 600ms，相邻区块错开 80ms
- 超出 8 个区块时，后续区块统一使用最后一段延迟或取消动画

### 5.2 卡片悬停抬升

**规则**：所有 `.card` / `.glass` / `.bg-popover` 默认带悬停抬升。

```css
.card, .glass, .bg-popover {
  transition: transform var(--taichu-dur-normal) var(--taichu-ease-out),
              box-shadow var(--taichu-dur-normal) var(--taichu-ease-out);
}

.card:hover, .glass:hover, .bg-popover:hover {
  transform: translateY(-3px);
  box-shadow: var(--taichu-shadow-elevated);
}
```

**例外**：
- 固定定位/底部悬浮按钮区不抬升（避免误触/遮挡）
- 触摸设备可保留 hover 样式，但不应依赖 hover 展示关键信息

### 5.3 按钮按压反馈

所有可点击元素（`button`、`[role="button"]`、`a`）统一带 `:active` 缩放反馈：

```css
button:active,
[role="button"]:active,
a:active {
  transform: scale(0.97);
  transition: transform var(--taichu-dur-fast) var(--taichu-ease);
}
```

### 5.4 聚焦光环

替代浏览器默认 outline，统一使用金色聚焦环：

```css
button:focus-visible,
[role="button"]:focus-visible,
a:focus-visible,
input:focus-visible,
textarea:focus-visible,
select:focus-visible {
  outline: none;
  box-shadow: 0 0 0 3px var(--taichu-ring);
}
```

### 5.5 减少动效偏好

必须尊重系统 `prefers-reduced-motion: reduce`：

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

### 5.6 插画使用规范

**资产来源**：本次设计产出位于 `太初三主题设计方向.design/assets/`，上线前需复制到 `frontend/public/art/` 或接入素材管理后台。

**使用场景**：

| 类型 | 比例 | 主题 | 用途 |
|---|---|---|---|
| 氛围图 | 16:9 | guoxue / xishi / psych | 首页 Hero 背景、主题宣传头图 |
| 空状态插画 | 1:1 | guoxue / xishi / psych | 空状态组件、无结果提示 |
| 装饰纹样 | 1:1 | guoxue / xishi / psych | 卡片衬底、页面角落装饰、loading 背景 |

**约束**：
- 插画必须按主题使用，禁止跨主题混用
- 氛围图作为背景时，必须叠加半透明遮罩/渐变，保证文字可读性
- 空状态插画容器宽度 120~160px，避免超过 200px
- 装饰纹样透明度建议 0.04~0.10，避免抢夺主体内容
- 所有图片必须带 `alt` 文本，空状态插画可描述为「XX 主题空状态插画」
