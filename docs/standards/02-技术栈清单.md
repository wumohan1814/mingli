## 3. 排盘引擎（确定性计算，零 LLM）

| 项 | 选型 | 版本 | 覆盖方法 | 归属 |

| 奇门终身局 | `mingyu-core` vendor 构建 | 0.2.2 | `qimen-lifetime` | 引入 |
| Node 运行时 | Node.js | 22.x | Python 胶水通过 `subprocess` 调用引擎 | 引入 |

### 依赖三层归属（ADR-0001）

| 层 | 归属 | 说明 |
|---|---|---|
| **引入** | 上述开源库 | 独立开源库，非 skill 仓库代码；排盘正确性由成熟库兜底 |
| **自研** | 排盘胶水与降级、切片映射、契合度打分、全部 method-prompts、shared 提示词、阶段 5 合并规则 | 在 `backend/app/` 内实现 |
| **参考** | `backend/reference/mingli/` | 仅作设计与契约对照，**不 import、不打包、不参与构建** |

> **双运行时是本项目的硬约束**：后端以 Python 为宿主，Node 仅作为排盘引擎的子进程依赖。
> 部署镜像必须同时具备 Python 3.13 与 Node 22。
> **代价**：自研后失去"上游升级自动惠及"红利，改为人工评估同步；需自建排盘回归基线。
