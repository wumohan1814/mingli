# 04 · 前端设计令牌（Design Tokens）规范

> 生效日期：2026-09-10
> 对应代码：`frontend/public/index.html` 中 `:root` CSS 变量
> 状态：✅ 已定

## 1. 概述

设计令牌（Design Tokens）是设计系统的最小原子单位，用于统一定义颜色、字体、间距、圆角、阴影、动效等视觉属性。
本项目通过 CSS 变量（Custom Properties）实现设计令牌，支持多皮肤切换。

### 1.1 命名规范

```
{类别}-{属性}-{变体}-{状态}
```

| 类别前缀 | 含义 | 示例 |
|---|---|---|
| `--ink-*` | 墨蓝主色 | `--ink-500`、`--ink-900` |
| `--gold-*` | 金色系 | `--gold-300`、`--gold-500` |
| `--jade-*` | 玉青色 | `--jade-500` |
| `--cinnabar` | 朱砂红 | `--cinnabar` |
| `--paper` | 宣纸色 | `--paper` |
| `--surface` | 表面色 | `--surface` |
| `--text-*` | 文本色阶 | `--text-1`、`--text-2`、`--text-3` |
| `--border` | 边框色 | `--border` |
| `--skin-*` | 皮肤色（随主题切换） | `--skin-accent`、`--skin-banner` |
| `--font-*` | 字体族 | `--font-serif`、`--font-sans` |
| `--radius-*` | 圆角尺寸 | `--radius-sm`、`--radius-md`、`--radius-lg` |
| `--shadow-*` | 阴影 | `--shadow-card` |
| `--art-*` | 美术资源 URL | `--art-ssgw-tube` |
| `--dur` / `--ease` | 动效参数 | `--dur`、`--ease` |

### 1.2 使用原则

✅ **推荐**：所有视觉属性优先使用 CSS 变量
```css
.btn {
  background: var(--skin-accent);
  color: var(--skin-accent-ink);
  border-radius: var(--radius-md);
  transition: background var(--dur) var(--ease);
}
```

❌ **禁止**：硬编码色值/尺寸
```css
.btn {
  background: #3E7C6B;     /* 应使用 var(--skin-accent) */
  border-radius: 12px;     /* 应使用 var(--radius-md) */
}
```

## 4. 间距与圆角

### 4.1 间距系统（4px 基准）

| 层级 | 数值 | 用途 |
|---|---|---|
| xs | 4px | 极小间距（图标与文字、标签内边距） |
| sm | 8px | 小间距（列表项内边距） |
| md | 12px | 中间距（卡片内边距、组件间距） |
| lg | 16px | 大间距（区块间距） |
| xl | 24px | 超大间距（页面级 padding） |
| 2xl | 32px | 页级大留白 |

> 当前项目间距未完全 token 化，建议 Phase2 统一为 `--space-xs/sm/md/lg/xl` 变量。

### 4.2 圆角

| 变量名 | 值 | 用途 |
|---|---|---|
| `--radius-sm` | `8px` | 小圆角（标签、按钮小号） |
| `--radius-md` | `12px` | 中圆角（卡片、输入框、按钮默认） |
| `--radius-lg` | `16px` | 大圆角（弹窗、大卡片） |
| `--radius-pill` | `999px` | 胶囊形（胶囊按钮、Tag） |

## 5. 阴影与动效

### 5.1 阴影

| 变量名 | 值 | 用途 |
|---|---|---|
| `--shadow-card` | `0 2px 12px rgba(26,33,56,.10)` | 卡片阴影（默认） |

> 建议补充：`--shadow-sm`（微悬浮）、`--shadow-lg`（弹窗、浮层）、`--shadow-xl`（全屏弹窗）

### 5.2 动效参数

| 变量名 | 值 | 用途 |
|---|---|---|
| `--dur` | `.22s` | 默认动效时长 |
| `--ease` | `cubic-bezier(.4,0,.2,1)` | 默认缓动曲线（Material 标准） |

**使用约定**：
- 所有过渡动画统一使用 `var(--dur) var(--ease)`
- 特殊时长（如长动画）单独定义，但缓动曲线保持一致

## 7. 新增 Token 流程

1. 确认是否可复用现有 token，避免冗余
2. 按命名规范命名（类别-属性-变体-状态）
3. 在 `:root` 中定义默认值
4. 在各皮肤 `[data-skin="xxx"]` 中覆盖（如需要）
5. 在本文件中登记
6. 更新 smoke-check 脚本的 token 统计

## 9. Phase2 优化建议

1. **补齐间距 token**：`--space-xs` ~ `--space-3xl`（共 7-8 档）

5. **z-index 层级规范**：`--z-dropdown` / `modal` / `toast` / `popover`
