# 04 · 前端设计令牌（Design Tokens）规范

> 生效日期：2026-09-12
> 对应代码：`frontend/public/index.html` 中 `:root` CSS 变量
> 状态：✅ 已定（v1.2 · 三主题视觉系统升级）
> 变更说明：本次在原有 `--ink-*` / `--gold-*` / `--skin-*` 等令牌基础上，补齐色阶、字号、间距、阴影、玻璃、动效，并统一三主题签名。落地时建议渐进迁移：新页面/新组件直接采用 `--mingli-*` 命名；旧页面维持现有 `--ink-*` 等不变，可在 `:root` 中补充别名映射避免硬编码。

## 1. 概述

设计令牌（Design Tokens）是设计系统的最小原子单位，用于统一定义颜色、字体、间距、圆角、阴影、动效等视觉属性。
本项目通过 CSS 变量（Custom Properties）实现设计令牌，支持多皮肤切换。

### 1.1 命名规范

```
{类别}-{属性}-{变体}-{状态}
```

| 类别前缀 | 含义 | 示例 |
|---|---|---|
| `--ink-*` / `--mingli-ink-*` | 墨蓝主色 | `--ink-500`、`--mingli-ink-900` |
| `--gold-*` / `--mingli-gold-*` | 金色系 | `--gold-500`、`--mingli-gold-400` |
| `--jade-*` | 玉青色 | `--jade-500` |
| `--cinnabar` | 朱砂红 | `--cinnabar` |
| `--paper` / `--mingli-paper` | 宣纸色 | `--paper` |
| `--surface` / `--mingli-surface` | 表面色 | `--surface`、`--mingli-surface-warm` |
| `--text-*` / `--mingli-text-*` | 文本色阶 | `--text-1`、`--mingli-text-2` |
| `--border` / `--mingli-border` | 边框色 | `--border`、`--mingli-border-warm` |
| `--skin-*` / `--mingli-skin-*` | 皮肤色（随主题切换） | `--skin-accent`、`--mingli-skin-glow` |
| `--font-*` / `--mingli-font-*` | 字体族 | `--font-serif`、`--mingli-font-latin-serif` |
| `--radius-*` / `--mingli-radius-*` | 圆角尺寸 | `--radius-md`、`--mingli-radius-xl` |
| `--shadow-*` / `--mingli-shadow-*` | 阴影 | `--shadow-card`、`--mingli-shadow-float` |
| `--art-*` | 美术资源 URL | `--art-ssgw-tube` |
| `--dur` / `--mingli-dur*` | 动效时长 | `--dur`、`--mingli-dur-slow` |
| `--ease` / `--mingli-ease*` | 动效缓动 | `--ease`、`--mingli-ease-spring` |

> **前缀约定**：`--mingli-*` 为三主题视觉系统升级后的目标命名；已有代码中的 `--ink-*` / `--gold-*` / `--skin-*` / `--radius-*` / `--shadow-card` / `--dur` / `--ease` 继续有效，可作为兼容别名指向同值。新写代码优先使用 `--mingli-*` 以语义清晰。

### 1.2 使用原则

✅ **推荐**：所有视觉属性优先使用 CSS 变量
```css
.btn {
  background: var(--mingli-skin-accent);
  color: var(--mingli-skin-accent-ink);
  border-radius: var(--mingli-radius-md);
  transition: background var(--mingli-dur) var(--mingli-ease);
}
```

❌ **禁止**：硬编码色值/尺寸
```css
.btn {
  background: #3E7C6B;     /* 应使用 var(--mingli-skin-accent) */
  border-radius: 12px;     /* 应使用 var(--mingli-radius-md) */
}
```

### 5.2 磨砂玻璃

| 变量名 | 值 | 用途 |
|---|---|---|
| `--mingli-glass-blur` | `20px` | 背景模糊半径 |

**使用模式**：
```css

  backdrop-filter: blur(var(--mingli-glass-blur)) saturate(var(--mingli-glass-saturate));
  -webkit-backdrop-filter: blur(var(--mingli-glass-blur)) saturate(var(--mingli-glass-saturate));
}
```

### 5.3 动效参数

| 变量名 | 值 | 用途 |
|---|---|---|
| `--mingli-ease` | `cubic-bezier(.4,0,.2,1)` | 默认缓动（Material 标准） |
| `--mingli-ease-out` | `cubic-bezier(.16,1,.3,1)` | 出场/展开缓动 |
| `--mingli-ease-spring` | `cubic-bezier(.34,1.56,.64,1)` | 弹性反馈（按钮按压回弹等） |
| `--mingli-dur` | `220ms` | 默认动效时长 |
| `--mingli-dur-fast` | `150ms` | 快速反馈（按压、焦点环） |
| `--mingli-dur-normal` | `250ms` | 常规过渡（悬停、颜色） |
| `--mingli-dur-slow` | `400ms` | 慢速过渡（页面入场、大卡片） |

**使用约定**：
- 所有过渡动画统一使用 `var(--mingli-dur) var(--mingli-ease)`
- 特殊时长单独定义，但缓动曲线保持一致
- 必须配套 `prefers-reduced-motion: reduce` 媒体查询，将动画时长压到 `0.01ms`

## 7. 新增 Token 流程

1. 确认是否可复用现有 token，避免冗余
2. 按命名规范命名（类别-属性-变体-状态）
3. 在 `:root` 中定义默认值
4. 在各主题 `[data-theme="xxx"]` / `[data-skin="xxx"]` 中覆盖（如需要）
5. 在本文件中登记
6. 更新 smoke-check 脚本的 token 统计
7. 同步更新 `07-版本迭代记录.md`

## 9. Phase2 优化建议

1. **字号 token 落地**：将现有 `12px / 13px / 14px / 16px / 18px / 24px+` 散点全面迁移到 `--mingli-fs-*`
2. **z-index 层级规范**：`--z-dropdown` / `--z-modal` / `--z-toast` / `--z-popover`
3. **行高 token**：`--line-height-tight` / `normal` / `relaxed`
4. **皮肤对齐**：统一 `data-skin` 与 `data-theme`，废弃 `astrology/tarot/xishi/xingzuo/mbti` 旧皮肤名或做明确映射
5. **插画资产 CDN 化**：当前 `.design/assets/` 为设计稿资产，上线前需复制到 `frontend/public/art/` 或素材管理后台 slot
