# standards/ — 工程规范

| 文件 | 约束对象 | 何时必须读 |
|---|---|---|
| `01-命名与变量约定.md` | 全仓：目录、代码、数据库、接口、事件、环境变量、Git | 新建任何文件 / 分支前 |
| `02-技术栈清单.md` | 各版块选型与版本、待决技术项 | 引入新依赖前 |
| `03-接口与数据字典.md` | REST / 事件契约、表结构、缓存键、配置项 | 改接口或表结构前 |
| `04-前端设计令牌.md` | CSS 变量、皮肤体系、字体/间距/动效参数 | 改视觉样式或新增主题前 |
| `05-前端组件库规范.md` | 组件分层、ModalBase/Icon 等通用组件 API、命名约定 | 新建或重构组件前 |
| `06-环境与部署说明.md` | 环境划分、环境变量、部署步骤 | 本地起服务或发布前 |
| `07-版本迭代记录.md` | 变更历史 | 每次发布 |
| `08-运行形态与版本契约.md` | 渠道开关（web / APK 单机 / APK 客户端）、能力清单、`api_version` 与兼容矩阵 | **加任何形态专属功能前**；改接口契约或发版本前 |
| `09-数据迁移与版本化.md` | 表结构变更 / 库版本号 / 老库与 APK 端升级 | **改任何表结构前**；发布服务器端或 APK 端前 |

## 变更流程

规范即契约。修改上述任一文件需在 PR 中说明「改了什么 / 影响哪些模块 / 是否需要数据迁移」，
并在 `05-版本迭代记录.md` 追加条目。

## 现状提示

方法模块为 **9 个**（8 命盘类 + 1 八字专题，ADR-0003）；断前尘与预测为**异步端点**（ADR-0005）；
校验**仅在断前尘阶段**执行（ADR-0002）。三者共同决定成本口径与排期，改动前先读对应 ADR。
