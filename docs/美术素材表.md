## 0. 总体美术方向

### 0.1 风格定位

太初的整体视觉 = **东方玄学 · 国风 · 水墨 · 星空**，关键词：**克制、雅致、非卡通**。动效素材必须与现有界面同源，不要出现日漫/欧美奇幻画风、高饱和霓虹、贴纸质感。

| 世界系 | 覆盖素材 | 气质关键词 | 对齐对象 |

### 0.3 质感与光照（对所有素材的统一要求）

1. **质感三件套**：丝绢/纸墨底（哑光低反差）+ **金箔描线**（描金色见 0.2，线宽在显示级约 0.8–1.5 CSS px）+ 玉瓷/星空的柔光；避免塑料高光、避免纯黑纯白大块。
2. **光照方向统一**：主光源在**画面左上方约 45°**（对应 `index.html` 背景径向光心 12% 8% / 星点高密区 18% 28%）。规则：
   - 器物主高光落在**左上缘**，呈细长柔光带；右下缘转入暗部（约降 15–25% 明度）；
   - 暗部接受一点点暖色地面反光（`--gold-600` 5–8% 透明度），避免死黑；
   - 阴影统一**柔焦、落在器物正下偏右 2°**，黑度 ≤35%、不锐利。
3. **光影笔触**：水墨器物用 1–2 层灰阶润染，不用噪点/颗粒质感（粒子素材除外）。
4. **运动模糊**：器物本体不要预画动态模糊/拖影 —— 位移动画由 CSS `transform` 完成，静态素材加拖影会与动画叠加出错（#13 辉光等特效帧除外）。
5. **动画硬件约束**（美术只需知道，保证素材够用）：前端只对 `transform/opacity` 做动画，所有"飞、抖、翻、滚、落"都由 CSS 完成 —— 因此**绝大多数素材是静态单图**，只有粒子/辉光等需要帧图（§1 总览"动效"列有标注）。

### 0.4 输出规范（美术 Agent 的统一要求，先读）

| 项 | 规范 |
|---|---|
| **格式** | 主体器物 = 透明底 PNG（24-bit alpha）；体积敏感场景可交付 **WebP+Alpha**（无损或高质量有损，二选一，不要交无 alpha 的 JPG）。JPG 仅限**无透明需求的全幅氛围背景**（#8、#14）。动效位图序列 = **精灵图 PNG**（`<steps()>` 逐帧播放），帧内不加间距；若该效果确有连续渐变需求且美术管线支持，可改交付 APNG / 动画 WebP（在清单注明"循环/一次性"，见下）。不做 Lottie（当前无矢量接入管线） |
| **倍率** | 统一按 **@2x 及以上超采样交付**：本表"出图尺寸"列为最终文件像素（均 ≥ 2× 逻辑尺寸，器物多给到 2.4–4.6× 保证清晰）；前端按"逻辑尺寸（@1x，CSS px）"缩放显示 |
| **画布/安全区** | 透明底素材：主体距画布边缘 ≥4% 画布宽（防切）；有边框纹样的牌面类素材：外框内容距边 ≥ 6% 画布宽（防显示裁切，见 §2 卡 #3 的数值）；氛围背景图：内容铺满整张画布、无安全区要求（纯氛围可任意裁） |
| **命名** | 全小写英文 + `-` 分隔（不用空格/中文/大写/下划线），数字序号两位 `01` 起；帧序列 `<basename>-<nn>.png`。**文件清单另用一列注明循环性**：`loop`（无限循环）/`once`（播一次即停）/`hold`（末帧停留） |

| **体积** | 器物/牌背/粒子单文件 ≤ **300KB**；全幅氛围背景 ≤ **800KB**；帧精灵图整张 ≤ **500KB**（卡面正片按 REQ-059⑤ 约束另定） |
| **文字禁忌** | 器物主体**不画文字**（签号、宫名、牌位标等一律由前端 DOM 叠字，避免改文案重出图）；唯一例外 = 铜钱"字面"的铸文（拟物内容，见 #5）与掌诀图可带六宫小字（可选） |
| **交付物** | 每个素材交付：最终文件 + 命名/循环性说明行 + **锚点清单**（若该素材有"前端要叠加/起算的动画点"，如签筒筒口中心、落签点、掌诀六宫坐标，需以画布百分比给出，见各规格卡） |

### #1 观音签筒（筒体）

**名称/编号**：观音签筒（tube）· #1 · 必备
**出现位置与用途**：观音灵签自动抽签的**全屏演出层主体器物**（REQ-061 §3.1 签筒舞台）。用户点它或摇手机触发摇签；签（#2）从它筒口弹出。它在演出层水平居中、位于中部偏下（签要有上方飞行空间）。

**静态效果描述**
- 材质/造型：推荐 **A 方案：玉青瓷釉筒身 + 描金线纹**（釉色取 `--skin-accent` #3E7C6B 系，深浅从 `#2E5F52` 到 `#5B8A7D`，带釉面高光条）——筒身主色与国学皮肤强调色同系，全场最和谐；备选 B 方案：深褐木胎描金（`#6B4A2F` 系木纹 + 金线）。造型为**观音签筒**形制：微束腰直筒、**筒口外敞喇叭沿**（签从此弹出）、底足略收，线条简雅圆润，无把手无盖。
- 装饰：筒身中上带 1 圈浅浮雕纹样（**缠枝莲 / 祥云纹二选一**，低对比线刻，不抢造型），筒口沿与底足各一道描金细线（`--gold-500` #B8893E，高光处提 `--gold-300`）；筒身**无任何文字**。
- 光影：左上 45° 主光，釉面高光在左上缘呈竖向细长柔光；筒口**内壁为深色**（`--ink-900` 60–80% 不透明渐变），保证 #2 签在口内时隐没。
- 氛围：整体哑光雅致，禁卡通大眼/笑脸/拟人化，禁大标语。

**动态表现**（不涉及素材分帧，供理解节奏）
- idle：整筒上下浮沉呼吸（translateY ±4px，2.4s 循环）＋口内签尾若隐若现（#2 表现）。
- 触发：筒身左右晃动＋微旋转（S3，0.5s，往复 3 次，幅度 ±10px / ±7°）。
- 出签时筒身保持微倾不动（S4/S5 由 #2 演出）。
- 注意：**不需要**桶壁变形/挤压的逐帧动画。

**画面内容（要画的清单）**
1. 完整筒身 360×520 画布内（正视角、中轴对称、微俯 5°）；2. 筒口外敞沿 + 深色内壁（内壁必须画，签在口内时缺口感）；3. 束腰/直身曲线；4. 缠枝莲或祥云浮雕纹 ×1 圈；5. 描金沿口/足线；6. **筒口中心锚点**：交付时注明"筒口中心（签弹出原点）"在画布上的百分比坐标（预期 ≈(50%, 10%)）。

**交互状态**

| 状态 | 视觉（美术提供静态造型；状态差异由 CSS 完成） | 触发/备注 |
