## 1. 各阵示意（ASCII · 序号 = 抽牌位次，对应牌位语义）

### 1. 单张（1）· 居中大卡
```
        ┌──────┐
        │  ①   │  ← 核心
        │ 核心 │
        └──────┘
```
竖屏：正中偏上 1/3 处。

### 2. 三张（3）· 一行（过去-现在-未来）
```
 [①过去]  [②现在]  [③未来]
```
### 3. 圣三角（3）· 三角
```
       [①过去]
   [②现在]  [③未来]
```
### 4. 身心灵（3）· 一行
```
 [①身]  [②心]  [③灵]
```
### 5. 爱情（5）· 一行（两端略弧）
```
[①你的内心] [②对方内心] [③关系现状] [④发展建议] [⑤未来走向]
```
### 6. 万能（5）· 小扇
```
         [①]
      [②] [⑤]
   [③]        [④]
```
> 扇轴心在下，序号按 1→5 顺时针展开（待确认，见 §3）。

### 7. 四元素（5）· 一行
```
[①火] [②水] [③风] [④土] [⑤精神/核心]
```
### 8. 财富（5）· 一行
```
[①现状] [②资源] [③机会] [④阻碍] [⑤建议]
```
### 9. 问题解决（5）· 小扇
```
         [①]
      [②] [⑤]
   [③]        [④]
```
### 10. 事业（6）· 对排（两排三列）
```
[①当前状况] [②优势] [③挑战]
[④机会] [⑤行动建议] [⑥结果]
```
### 11. 选择（6）· 对排
```
[①现状] [②选择A] [③选择A结果]
[        ] [④选择B] [⑤选择B结果] [⑥最佳建议]
```
> 简化：上排 ①现状 ②选择A ③A结果；下排 ④选择B ⑤B结果 ⑥最佳建议（3+3 对齐，待确认）。

### 12. 关系（6）· 对排
```
[①你] [②对方] [③互动]
[④优势] [⑤挑战] [⑥走向建议]
```
### 13. 马蹄（7）· 倒 U 弧（1→7 自左往右沿弧）
```
[①过去] [②现在] [③近期未来]
    [⑦结果]      [④态度]
        [⑥阻碍] [⑤外部影响]
```
> 开口朝下（倒 U），1 在左上、7 在右下（待确认弧向，见 §3）。

```
     [⑦核心]
   [④原因] [⑤环境]

```
### 15. 七脉轮（7）· 竖列

```
 [①海底轮]

 [④心轮]
 [⑤喉轮]
```

### 16. 四牌四季（4）· 四方格（2×2）
```
[①春] [②夏]
[③秋] [④冬]
```
### 17. 凯尔特十字（10）· 十字 + 旁柱
```
            [⑩结果]
      [④根基]  [⑤近过去]  [⑥临近未来]
            [②交叉]（横压①上）
            [①现状]
   [③目标]  [⑦立场]  [⑧环境]
            [⑨希望与恐惧]（右旁柱下端）
```
> 简化示意：中心为 ①现状 + ②交叉（横压）；十字四臂 ③目标（左）④根基（下）⑤近过去（左上）⑥临近未来（右上）；右旁柱 ⑦立场 ⑧环境 ⑨希望恐惧 ⑩结果（自上而下）。精确摆位以官方 Waite 十字为准（编码时按官方坐标，此图表意）。
