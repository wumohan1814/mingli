# Agent ⇄ Agent 对话通道（docs/exchange/）

本目录是**项目内部 Agent 之间的对话通道**：A 写需求 → B 接需求出活 → C 验收/知悉。

## 规则

| 项 | 说明 |
|---|---|
| 命名 | `<类型>-<第N轮>-<主题>.md`，类型用「素材需求文档 / 美术交付回执 / 开发交付 / 验收 / 文案交付 / 设计交付」等 |
| 状态字段 | 每篇必带「状态：草稿 / 待评审 / 待美术生产 / 已交付 / 验收中 / 已验收」 |
| 关联需求 | `../需求表.md` REQ-XXX |
| 关联资产 | `frontend/public/art/...` 路径 |
| 归档 | 交付并接入完成后移动到 `../_archive/`（保留可追溯） |

## 内容范围

- 跨 Agent 流转的**素材需求文档**（美术 Agent 入站）
- 美术/文案/开发**交付回执**（其它 Agent / 开发入站，**需要开发知悉的交付物**也归这里）
- 设计/架构决策讨论纪要
- Agent 间的验收记录

## 不放在这里

- 单一 Agent 的内部思考过程
- 与具体需求无关的闲聊
- 最终归档文档（归档后进 `_archive/`）
