## 1. 素材规格

### M1 · 三只化身待机循环动作帧（sprite sheet ×3）

| 项 | 规格 |
|---|---|
| 内容 | 每只化身一段**自主动作待机循环**（建议动作构成，美术按 Q 版风格自由发挥）：<br>· **国学**（打坐）：呼吸起伏 + 眨眼 + 微摆头/捻珠等小动作；<br>· **西式**（观星）：仰望 + 眨眼 + 轻摆手等小动作；<br>· **MBTI**（摇椅）：摇椅前后轻摇 + 眨眼 + 手部小动作。 |
| 帧规约 | **10 帧/循环**（8~12 帧皆可，偶数便于网格排布）；单帧 **256×256**（可选 @2x 512×512 超采样，美术自行决定采样但交付按 256 规格）；**第 1 帧与末帧须动作回环、可无缝循环播放** |
| 网格 | 建议 **2×5**（两行五行）横向排布（开发按实际排布适配，交付时注明行列即可） |
| 循环节奏 | 3.2~3.6s/循环（对齐现有节奏） |
| 格式/体积 | WebP（优先）或 PNG 透明；**≤400KB/张** |
| 命名/目录 | `frontend/public/art/taichu-pet/mascot-guoxue.webp` / `mascot-xishi.webp` / `mascot-mbti.webp`（新目录，**不覆盖** `module-mascot/` 旧静态图） |
| 约束 | 动作幅度适中（待机感、不夸张）；单帧角色居中、四周留白 ≥8%；不画文字 |

### M2 · 周边互动元素（纯氛围 · 不可点击 · 静态小图）

> 路径动效（环绕 / 落肩 / 飞走）由开发 CSS keyframes 实现，**美术只产静态小图、无需做帧动画**。

| 元素 | 归属 | 数量 | 画面建议 |
|---|---|---|---|
| 小鸟 | 国学 | 1 | Q 版小鸟（可飞落肩头） |
| 蝴蝶 | 国学 | 1 | Q 版蝴蝶（环绕飞） |
| 星星 | 西式 / MBTI | 2~3 | 闪光小星星（观星氛围） |
| 星座连线 / 神秘符号 | 西式 | 1 | 简洁星座连线或星月符号（与塔罗神秘学视觉一致） |

| 项 | 规格 |
|---|---|
| 尺寸 | 每枚 64~128px 方形透明底（按元素实际占比，最小边 ≥64px） |
| 格式/体积 | PNG/WebP 透明；**≤50KB/枚** |
| 命名/目录 | `frontend/public/art/taichu-pet/fx-bird.webp` / `fx-butterfly.webp` / `fx-star.webp` / `fx-constellation.webp`（其余按语义命名） |
| 约束 | 装饰性、低饱和不抢主体；不遮挡导航按钮与主操作；不画文字 |

## 2. 交付与接入说明

- 交付进 `docs/exchange/`（待接入交付物中心），开发接入后归档 `docs/_archive/`。
- 接入点（开发侧，素材回传后执行）：
  1. 化身：落地页三按钮（`.landing-mascot`）内 `<img>` 换 sprite sheet + CSS `steps()` 逐帧循环（替换 4334c33 的整体浮沉/晃动 keyframes）；
  2. 互动元素：按钮容器内叠加绝对定位元素 + CSS 路径动画（环绕/落肩/飞走）；
  3. 交互不变：点击进「太初先生」会话、跟随功能设置「太初先生」开关（agent_enabled）、`prefers-reduced-motion` 停循环降级（均已实现，直接沿用）。
- 开发先用占位（现有静态形象 + 现有 CSS 动画），素材回传后替换即生效；旧 `module-mascot/` 文件保留供回滚。

## 3. 待确认单（带默认建议，需求方确认后锁单）

1. **动画实现形态**：默认 **序列帧 sprite sheet + CSS steps()**（免构建最稳、体积小、美术门槛低）；备选 Lottie JSON（需引入 lottie-web CDN、美术需产 Lottie，复杂度高）→ 默认建议：**序列帧**。
2. **帧数 / 单帧尺寸**：默认 **10 帧 × 256×256**（2×5 网格）→ 美术如按 8 或 12 帧制作亦可，交付时注明行列即可。
3. **互动元素清单**：默认 **小鸟×1 + 蝴蝶×1 + 星星×2~3 + 星座连线×1** → 美术可增删（如为 MBTI 增加音符/飘带），增删须回填。
4. **动作内容**：默认按上文 M1 建议（眨眼 + 呼吸/轻摇 + 小幅动作）→ 美术按 Q 版风格自由发挥，**不要求动作逐帧对齐需求方描述**，只要自主动作感、非整体平移晃动。
