# 积分系统 · UI 元素清单（给 UI 生产）

> 状态：待生产｜ 日期：2026-09-06
> 换算：**1 积分 = 1000 tokens**
> 视觉：**沿用现有国学皮肤**（内部玉青 `#3E7C6B`、顶栏/胶囊朱砂 `#B23A3A`，即 `--skin-accent` / `--skin-banner` 令牌），移动优先（480px 容器）。
> 说明：`+` 入账用玉青/绿，`-` 消费用朱砂/红，与现有「吉=玉青、凶=朱砂」语义一致。

---

## 1. 积分余额组件 `CreditBalance`

**位置**：档案页「我的命理档案」卡片顶部 + 预测页「综合解读」卡片右上角。

**视觉**：
- 小胶囊（pill），背景 `--skin-banner`（朱砂）或 `--ink-900`，文字白色。
- 左侧一枚星印/玉 icon（沿用现有 SVG `Icon`），右侧「积分 123」。
- 余额为 0 或负数：文字/胶囊改警示红（`--cinnabar`）。

**内容**：`积分 {balance}`。

**交互**：点击整颗胶囊 → 跳转「积分明细页」。

**状态**：
- 加载中：骨架屏（`.skeleton` 小胶囊）。
- 正常：显示余额。
- 余额 ≤ 0：红字警示 + 点按进入明细页（引导充值）。

**数据来源**：`GET /api/credits/balance` → `data.balance`。

---

## 2. 积分明细页 `CreditTransactionsPage`（新页面）

**位置**：新增页面，从余额胶囊点击进入；底部返回。

**结构**（自上而下）：
1. 顶部大数字卡片：当前余额（大号 `--ink-700`）+ 右侧「充值」按钮。
2. 流水列表：每条一行。

**流水行**：
```
[图标]  充值 / 断前尘推演 / 预测推演 / 修正对话 / 单法直问 / 手动赠送
        （时间，如 09-06 14:30）
右侧：  +100（玉青） 或  -23（朱砂）
        结余 123（小字灰）
```

**图标映射**：充值/赠送 = ↑（玉青）、消费 = ↓（朱砂）。

**状态**：
- 加载：骨架屏列表（`.skeleton sk-line`）。
- 空态：无流水时显示「暂无积分记录」。
- 错误：`.error` + 重试。
- 分页/加载更多：列表底部「加载更多」（`offset` 递增）。

**数据来源**：`GET /api/credits/transactions?limit=20&offset=0` → `data.items[]`（字段 `delta/type/tokens/note/createdAt`）。

## 3. 积分不足弹窗 `CreditInsufficientModal`

**触发**：后端返回错误码 **5002**（在 `api()` 响应拦截统一捕获）。

**视觉**：居中模态，遮罩半透明，卡片圆角 16px。

**内容**：
```
标题：积分不足
正文：本次推演约需 N 积分，当前余额 M 积分。
      （N/M 来自后端 detail；若拿不到具体数，用通用文案「积分不足，请充值后再试」。）
按钮：[取消]（outline）  [去充值]（primary 玉青）
```

**交互**：去充值 → 跳小鹅通充值链接；取消 → 关闭弹窗。

**数据来源**：错误信封 `{code:5002, message:"积分不足", detail:"余额 3 积分，本次需 12 积分"}`。

## 4. 充值入口 `RechargeButton`

**位置**：三处复用同一样式：
1. 积分余额胶囊旁（小号文字按钮）
2. 积分明细页顶部
3. 积分不足弹窗内

**视觉**：primary 按钮（`--skin-accent` 玉青），文案「充值」。

**交互**：点击 → `window.location.href = <小鹅通充值链接>`（链接由后端配置下发，前端不硬编码）。

**触发**：充值成功后（前端从小鹅通返回，或轮询余额变化检测到增加）。

**视觉**：顶部 Toast（沿用现有 toast 组件），玉青成功色。

**内容**：「充值成功，积分已到账」。

## 9. 后台运维空间 UI（管理端，非 C 端）

> 运维空间是**管理端界面**（独立于 C 端，复用后台管理系统风格，可更朴素、信息密度更高，不强制国学皮肤）。

### 9.1 运营配置页 `AdminConfigPage`

**位置**：后台「系统配置」菜单。

**内容**：
- 表格式配置列表，含两行：
  - `recharge_rate`（充值折算率）：展示「1 元 = 10 积分」，**可编辑**（改数字即改折算，实时生效）。
  - `free_credit_on_register`（新用户赠送积分）：可编辑。
- 每行：「key + 描述 + 当前值 + [编辑]」。

**交互**：点编辑 → 输入新值 → 保存 → 写审计日志 + 提示「已生效」。

**数据来源**：`GET /admin/config`、`PUT /admin/config/{key}`。

### 9.2 手动赠送积分表单 `AdminManualCredit`

**位置**：后台「积分管理」页。

**内容**：
- 输入：用户标识（用户名/userId）+ 赠送积分数量 + 备注（必填，说明原因）。
- 按钮「确认赠送」+ 二次确认弹窗（显示将赠送 N 积分给 用户X）。

**交互**：确认 → 调 `POST /admin/credits/manual` → 成功提示 + 审计日志。

**数据来源**：`POST /admin/credits/manual`（入参 user_id/delta/note）。
