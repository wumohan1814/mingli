## 二、各文件字段结构与接入指引

### C1 · 生肖流年五行关系确定性文案
- 结构：`relations[生肖][关系标签] = 固定解读文案`
- 关系标签（严格对齐 `zodiac/index.js` 的 `getElementRelation` 输出，同标签同文案，便于引擎直接查表）：
  `年干五行生生肖地支本气` / `生肖地支本气生年干五行` / `年干五行克生肖地支本气` / `生肖地支本气克年干五行` / `年干五行与生肖地支本气同类`
- 接入：在生肖引擎中段回填逻辑中，按 `relation`（即上述 label）查表取文案；文案不点名流年天干具体五行，避免与计算耦合。

### C2 · 生肖贵人静态解读文案
- 结构：
  - `zodiacs[生肖].六合 = {partner, explain}`
  - `zodiacs[生肖].三合 = {partners, explain}`
  - `zodiacs[生肖].天乙贵人 = {note}`（天乙贵人随出生年天干而定，不固定属相）
  - `tianyiByGan[年干] = "生肖、生肖"`（甲戊庚牛羊 / 乙己鼠猴 / 丙丁猪鸡 / 壬癸兔蛇 / 辛马虎）
- 说明：六合/三合 partner 严格对齐 `ZODIAC_ANNUAL_COPY`，保证与既有标签一致；`explain` 解释关系之「质」而非断言「必得贵人」。

### C3 · 免费静态卦理文案
- 结构：
  - `hexagrams[卦名] = {本卦大意:'文案待补充', 变卦大意:'文案待补充'}`（64 卦全占位）
  - `genericRules = {动爻, 世应, 互卦, 本卦, 变卦}`（原创通用规则）
- 接入：结果页免费区先渲染 `genericRules` 五条；`hexagrams` 正文按卦象分批补全，字段为空时显示「文案待补充」。

### C4 · 梅花易数 / 小六壬 免费现代汉语解释
- 结构：
  - `meihua.patterns = {体克用, 用克体, 体生用, 用生体, 比和}`（5 格局）
  - `xiaoliuren.shens = {大安, 留连, 速喜, 赤口, 小吉, 空亡}`（6 神）
- 接入：免费解读区按引擎算出的体用关系 / 落掌神名，渲染对应解释。

### C6 · 五行关系 / 风险关系 通用解读（已落地 index.html）
- 本轮新增（2026-09-07 追加）：为生肖结果区的「五行关系明细」卡与「风险关系」卡各补一段确定性通用解读正文。
