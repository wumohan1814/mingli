## 1. 运行环境与沙箱（Windows 本机）

### 1.1 Python 环境
- 依赖装在**系统 Python**（`C:\Users\wumoh\AppData\Local\Programs\Python\Python313`），
  `backend/.venv` **没有 pytest**，跑测试用系统 python：
  ```bash
  cd backend
  python -m pytest tests/ -q
  ```
- 一键体检（Python 依赖 / pytest / Node / iztro / mingyu-core / fixtures / .env）：
  ```bash
  python backend/scripts/env_doctor.py
  ```

### 1.2 ⚠️ DSH 沙箱限制（关键）
- **workspace-write 模式跑 pytest 会大面积报错**：
  `sqlite3.OperationalError: unable to open database file`（99 个 setup error）。
  根因：`tests/conftest.py` 用 `tempfile.mkdtemp()` 建 0o700 临时目录给测试库，
  沙箱拒绝在该类目录内创建 SQLite 文件。**不是项目问题**。
- **解决**：pytest 一律在 `danger-full-access` 下执行（临时库可写可清理）。
- `git status` 中 `backend/paipan-node/server.mjs` / `vendor/mingyu-core/dist/zodiac/*`
  可能显示 ` M` 但 `git hash-object` 与 HEAD 一致——属沙箱 stat 噪声，**无真实差异**，
  用 `git diff --stat` 复核即可，勿误提交。

### 1.3 Node 侧
- 本机 node v24；`*_node_endpoint_*` 若偶发 `RemoteProtocolError`/`WinError 10054`
  是 node v24 + Windows 特定交互问题（交接文档 §4.2），生产镜像 node v22.14.0 无此问题，
  不要当 Bug 报。
- `mingyu-core` 是 **ESM-only** 包（`exports` 只提供 `import`），CJS `require.resolve`
  探测会误报 MISSING；正确探测用 `import(pathToFileURL(...))`（已固化进 env_doctor.py）。

## 2. 测试代码约定（新增用例前必读）

### 2.1 覆盖骨架
- 所有测试模块顶部 `pytestmark = pytest.mark.usefixtures("orchestration_env")`
  （conftest 的会话级临时库夹具；绝不碰 `backend/data/*.db`）。
- 建用户/档案/记录用文件内 `_new_user()` / `_new_case()` / `_new_reading()` 直插
  （绕过 API 造前置数据），风格见 `tests/unit/test_astrology.py` 头部工具段。
- 鉴权 header：`{"Authorization": f"Bearer {create_access_token(uid)}"}`。

### 2.2 ⚠️ 后台（admin）测试特有约定（REQ-048 首例）
- **写盘动作（PUT/rollback）会真实改写 `backend/prompts/*.md`**：测试必须把
  `app.admin.router.PROMPT_BASE` monkeypatch 到 `tmp_path`，并预置测试 prompt 文件，
  否则污染真实提示词（会直接影响线上 LLM 输出！）。见
  `tests/unit/test_admin_prompts.py::admin_env` 夹具。
- admin 账号直插 ops 临时库（`AdminUser` + `hash_password`），token 用
  `create_admin_token(admin_id, role)` 直签（绕过 login 端点，专注端点契约）。
- 版本/审计断言用 ops 临时库查询（`_version_rows` / `_audit_rows`）。

### 2.3 ⚠️ 错误码≠HTTP 状态（易踩坑）
项目错误码体系（`backend/app/errors.py` `code_to_http`）：
| 错误码段 | HTTP | 例 |
|---|---|---|
| 1xxx 通用（含 1002 不存在） | **400** | `ERR_NOT_FOUND=1002` → HTTP 400 |
| 2xxx 认证鉴权 | 401/403 | — |
| 3xxx case/档案 | **404** | case 不存在 |
| 4xxx 排盘 | 422 | — |
| 5xxx LLM/积分 | 502 | — |

**断言"资源不存在"时按 body `code` 判断**（如 `assert resp.json()["code"] == 1002`），
不要按 REST 直觉断言 HTTP 404——那只在 3xxx case 段成立。

### 2.4 SPA fallback（REQ-047 引入）
- 未匹配前端路由会回退 `index.html`（200）；dev 已修复（`e22c0b3`）排除 `/api`、`/admin`
  前缀——未注册接口 / 非法 key **不再**回退 index.html。
- 防路径穿越的机制是 **key 白名单静态映射**（`_prompt_path` 只查 `PROMPT_FILES`，
  调用方 key 不拼文件路径），不是对 `..` 的路径过滤；映射表外 key 一律 400。
