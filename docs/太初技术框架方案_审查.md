## 3) 优化建议（合并 v1 残留 + v2.2 新增）

- §4.2 显式："单方法直问不经事件分发器、不经主模块，直接 in-process 调用方法模块X（落库走用户档案模块）"；与 §4.1 事件驱动全用分发器并列说明"单进程内两机制皆无网络跳转"。

**B. 成本与闸门机制（C18/C22）**
- §6 区分 phase 缓存："首跑 = 断前尘 phase（8 法）+ 预测 phase（主/辅法）各一次"。
- §11/R9 定义 `COST_GATE_MODE` 配置 + 触发方（实测校准后手动或运行时开关）+ 阈值标 TODO；明确"自动降级"落地形式（非空承诺）。

**C. 隔离实现约束（C20）**
- §3.2/§5.3 增"多用户隔离实现约束"：网关中间件从 JWT 提取 `userId` → 注入所有模块调用与 DB 查询作用域；禁止任何绕过 `userId` 的直查；集成测试：用户 A 持 token 请求用户 B 的 `caseId` 必须 403/404。

**D. 职责与窗口对齐（C19/C23）**
- §3.5 重写主模块职责为"跨方法合成器（断前尘问卷提取 + 预测阶段5 裁决）"，统一两阶段来源；聚合窗口按 phase 区分：断前尘串行→放宽至 5min 或仅作单法卡死保护，预测并行→60s。
- §4.1 步骤3 标注"主模块从 8 法结果提取高置信断言合成问卷"。

**E. 表述与结构（C17/C21/C26）**

- R8/"零成本搬运"软化为"已最小化迁移成本"，并将 §12.7 的跨进程鉴权/追踪/迁移清单前置强调。

## 4) 决策评估（R1–R10，风险 + 依据 + 替代）

### R1 完整断前尘进 MVP（方案 B）
- 合理性：差异化强；"盘对了才预测"体验好，契合 mingli 核心卖点。
- 风险（高→受控）：8 法串行 LLM token 成本最高，与"先量单位经济"第一优先级张力。
- **缓解（R9）**：成本实测前置为开发期闸门（self-run 10× 与开发并行），超阈自动降级 方案C→方案A。R1 不推翻，但风险已转为可观测、可降级。
- 替代：方案A（裁剪）/方案C（2–3 法）。结论：保留为目标路径，闸门控风险。

### R2 / R6 / R8 架构（微服务形态 + 模块化单体 MVP）
- R2/R6 原始诉求：微服务形态、方法互不知对方、加方法零改动、双库逻辑隔离——合理且为用户强诉求。
- **R8 最终落地（用户三选一，比审查原建议"轻量总线"更保守）**：MVP **模块化单体**（单进程、服务形态模块 + 进程内事件分发器）；Phase2 拎成物理服务 + 真实总线。
- 风险（原中-高，MVP 已消解）：MVP 无分布式开销（无网络跳数/至少一次重投/跨进程排障），"过度架构"风险在 MVP 阶段显著下降；**残余风险在 Phase2 拆分**（C21：进程内→Kafka 真实迁移 + 跨进程鉴权/追踪），已在 §11/§12 标注。
- 替代：逻辑微服务+轻量总线（审查原建议，用户未选）/ 真·分布式（最重）。
- 结论：方向可接受；MVP 物理形态定为模块化单体，边界服务化保 Phase2 易拆。R8 相对 R2/R6 是**物理落地细化**，非推翻。

### R3 批量卡片问卷 + 多轮修正
- 合理（省 LLM 轮次、UX 快、贴合可累积档案）；风险低-中（多轮修正累积 token，已由 C10 兜底）。无更优替代。保持。

### R4 REST/JSON + C1 复用契约
- 优秀决策（零契约漂移、REST 投影去冗余、最低 bug 面）。保持。

### R5 双层合规护栏 + 不接支付
- 合理且必要（命理合规刚需 + 与"先量单位经济"一致）。保持。

### R7 用户名/密码 + JWT + 多用户隔离 + 无找回
- 多用户隔离：必要且合理。
- 纯用户名/密码：合理（最基础）；风险=无找回（运维负担）+ 无真人验证→已 R10 加限流/锁/captcha 覆盖。
- JWT 无状态：合理；风险=无吊销，受短访问令牌约束。
- **R10 安全加固**：登录限流+失败锁定+注册 captcha，覆盖 R7 残留风险。结论：整体合理，缺口已补。

### R9 成本闸门前置（R1 配套）
- 合理且必要；唯一待补=阈值校准 + 降级机制落地（C22）。保持方向。

### R10 安全加固（R7 配套）
- 合理；限流/锁阈值与 captcha 选型留实现阶段。保持。

### 决策评估总体
- R1/R2/R6/R7/R8/R9/R10 自洽；R4/R5 优秀。
- 原两大张力（R1 成本、R2/R6 过度架构）经 R9/R8 闭合，不再构成开发阻断。
- 唯一需补强的是**实现层机制**（C19/C20/C22/C23），不影响架构决策本身。
