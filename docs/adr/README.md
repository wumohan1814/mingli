### 关键连带影响（务必记住）

1. **成本口径已变**：首跑 LLM 调用从 ~13 次 → **~23 次**（9 法分析 + 9 法校验 + 预测 ~5 次）。
   校验用便宜模型折算后约 15.5 次分析当量。**原阈值 ¥0.3–0.5/case 作废**，
   建议上修 **¥0.5–1.0/case**，以 self-run 10× 实测为准。
2. **方法模块 8 → 9 法**：`bazi-hunyin-caiyun` 常驻，断前尘串行时长上升约 12%。
3. **契约归属自主**：`chart.json` / `method-result v2` 由太初定义，兼容 mingli 关键字段
   属**选择**而非义务（mingli 同为本人复刻产物，无第三方包袱）。
4. **失去上游自动惠及**：改为人工评估同步（ADR-0001 代价）；排盘回归基线与案例库锚点由
   Phase2 提前到 MVP 必做。
