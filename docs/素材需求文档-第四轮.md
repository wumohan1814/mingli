## 1. 必做美术（需要找美术组）

### M1 · 小六壬卦象结果图 UI 重做（REQ-106）

- **背景**：小六壬卦象结果页现有图像 UI 与全站风格不协调，需求方要求美术重做（REQ-106，P3）。
- **交付对象**：小六壬结果页的**掌诀 / 六宫结果图**（大安·留连·速喜·赤口·小吉·空亡六宫位 + 手指掌诀示意图，若结果页存在则替换；若现无则按全站风格产出结果主视觉）。
- **风格硬约束**：对齐全站「高贵 / 奢华 / 内涵」基调与其余占卜模块（塔罗 / 六爻 / 梅花 / 观音灵签）的视觉语言；暖米金国学皮肤配色（见 `docs/美术素材表.md` §0.2 色板）。
- **内容红线**：图内**不画文字**（宫名 / 释义由前端 DOM 叠字，便于中文化与后续词条调整）；可画掌诀纹路 / 六宫分区 / 装饰元素。
- **格式**：透明底 PNG/WebP α（24-bit），@2x 超采样；单文件 ≤300KB；宫位定位（六宫中心点）以画布百分比给出「锚点清单」。
- **命名 / 目录**：`frontend/public/art/xiaoliuren/`（新建），`xiaoliuren-palm(.png/.webp)`。
- **参考**：开发会给出一张现有结果页结构 / 截图说明供美术对照改版。

> 替换点：前端小六壬结果区组件预留 `--art-xiaoliuren-palm` 槽位；美术交付后接入即生效（走 REQ-059 素材热更亦可，但此图为模块默认素材，直接进 `art/` 静态更稳）。
