# 50_痕 · 凭的存放处（证据 / 视觉记忆）

> 本目录 = 跨 session 的视觉记忆：每轮「破竹」的真实产物（凭）都放这里，人眼一看就懂，不用翻代码、不用信口头汇报。

## 什么是凭

凭 = 用户能直接看 / 点 / 听的、由**真实运行**产生的东西：

| ✅ 算凭 | ❌ 不算凭 |
|---|---|
| 截图 / 录屏（真实页面的样子） | 「已完成」的自述 |
| 可点开的地址（http://… 真能打开） | 「测试通过了」的汇报 |
| 真实命令输出（贴出来的终端结果） | 口头承诺 / 计划 / 推测 |

一句话：**「完成了」不算数，能看 / 能点 / 能听才算凭。**

## 命名

`{{节编号}}-{{日期}}-改前/改后/{{说明}}.{{ext}}`

| 部分 | 含义 | 例子 |
|---|---|---|
| 节编号 | 对应的 `40_节/` 迭代节号 | 节101 |
| 日期 | 产出日期 | 2026-09-10 |
| 改前 / 改后 | 对比场景标明阶段 | 改前 / 改后 |
| 说明 | 一句话说清这是什么 | 首页轮播图 |
| ext | 文件后缀 | png / mp4 / md / txt |

示例：`节101-2026-09-10-改前.png`、`节102-2026-09-11-改后-首页轮播.mp4`

## 覆盖声明（每份凭必附）

每份凭都要跟一句：「**证明了什么 / 未证明什么**」。

示例：这张截图证明了首页改版后的布局已生效；**未证明**它在安卓真机上的滚动表现。

## 脱敏红线（进 git 前必查）

| 情况 | 做法 |
|---|---|
| 截图含账号 / 手机号 / 真实用户数据 | 打码后再归档 |
| 输出含 key / token | 截断打码 |
| 涉密输出 | 不进本目录 |

判据一句话：**这张凭如果被 push 到 GitHub，我会后悔吗？会 → 先遮。**

## 保留策略

本目录**进 git**（凭 = 跨 session 视觉记忆，删了就无法回看），因此一律存**脱敏版**；原始敏感文件不落盘、不进库。
