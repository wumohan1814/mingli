# 50_痕 · 痕的存放处

> **定位（2026-09-10 对齐破竹 v0.9–v0.11）**：痕 = 一次会话的足迹。**默认留痕是文字（节文件必写、0 成本）**；本目录只存放「用户明确要求的一次性截图 / 归档件」。

## 留痕规则（破竹 v0.9 最终版）

| 规则 | 说明 |
|---|---|
| **文字留痕 = 唯一机制、必写** | 节文件本身就是留痕（现状坐标 + 变更摘要 + 用户结论），收尾必写 |
| **截图不是机制** | 只有**用户明确要求**（存档案 / 发给别人看 / 交付单据）才截一次 |
| **禁止主动截图** | Agent 不为留痕 / 自检 / 视觉记忆主动截图；禁止无头 CLI 自我验收；禁止为截图拉起浏览器 |
| **版本对比用 Git 做底** | 用户说「看看上一版」→ git 切回 → 刷新环境 → 用户亲自体验，不用截图 |

## 放什么（用户要求截图时）

- 命名：`{{节编号}}-{{日期}}-{{说明}}.{{ext}}`（例：`节101-2026-09-10-首页轮播.png`）
- **覆盖声明**：每份附一句「证明了什么 / 未证明什么」——没有声明的凭 = 虚假的安心
- **脱敏红线**（进 git 前必查）：截图含账号 / 手机号 / 真实数据 → 打码后归档；判据——"这张图被 push 到 GitHub 我会后悔吗？会 → 先遮"

## 保留策略

本目录**进 git**（跨 session 可回看），因此一律存**脱敏版**；原始敏感文件不落盘、不进库。
